# 治愈档视频封面设计规范

适用于「醒木不响」治愈系列（深夜助眠档／单元短篇档）。所有坐标按**成品尺寸 1280×720** 给出。

---

## 一、设计前提：封面和片内画面职能相反

片内画面的任务是**让人不想切走**，所以要无聊、要低对比、要几乎不动。
封面的任务是**在一屏十二个视频里被点开**，必须显眼。

同一套插画语言，三处必须拉开：

| 项 | 片内画面 | 封面 |
|---|---|---|
| 窗框 | 有（五件固定构件之一） | **去掉**，画面顶到边 |
| 主体占比 | 近景不超过画面高 60%；留白档更小 | 放大约一倍 |
| 色阶层数 | 同色相 2–3 层，柔和 | 4 层以上，明暗拉开 |
| 文字 | 竖排小字，19px @680 宽 | 书名 104px @1280 宽 |

### 三条硬约束

1. **右下角 240×100 留空**——YouTube 时长角标压在那里。
2. **不放人脸、箭头、红圈、夸张表情。**这套刺激型缩略图语法会招来错的观众，点进来两分钟就走，对完播率的伤害比没人点更大。
3. **元素总数不超过三个**（插画主体 / 书名 / 印章）。手机首页缩略图实际只有约 210px 宽，第四个元素必糊。

## 二、版式：左条 + 右画

```
┌─────────────┬───────────────────────────────────┐
│  0          │ 384                          1280 │
│  米白竖条    │  插画满幅（无边框，四边出血）        │
│  384 宽      │                                   │
│             │                                   │
│  竖排书名    │                                   │
│  作者小字    │                                   │
│  副题钩子    │                                   │
│             │                                   │
│  朱砂印      │                        （此区留空）│
│  档位标      │                                   │
├─────────────┴───────────────────────────────────┤
│  底部色带 12px 通栏 y=708                         │
└─────────────────────────────────────────────────┘
```

**二十期不动的部分**：竖条宽度、分隔线、书名基线、作者与副题坐标、印章坐标、色带高度。
**每期变的部分**：右侧插画、书名文字、副题文字、书名墨色、底部色带色。

## 四、字体与字号

### 字体

| 用途 | 字体 | 字重 |
|---|---|---|
| 中文书名 | 思源宋体 / **Noto Serif CJK SC** | Medium (W5) |
| 日文书名（武蔵野、方丈記、枕草子等含日文字形） | **Noto Serif CJK JP** | Medium (W5) |
| 作者名 | Noto Serif CJK SC | Regular (W4) |
| 副题钩子 | Noto Serif CJK SC | Regular (W4) |
| 印内「醒」 | Noto Serif CJK SC | Medium (W5) |
| 档位标 | Noto Serif CJK SC | Regular (W4) |

**日文那条不是讲究，是必须。**「蔵」「記」「絵」这类字在 SC 与 JP 字形不同，用 SC 排日文书名会出现字形错误，日本观众一眼看得出。凡书名保留日文汉字的，整个书名走 JP。

字体本身可商用、可嵌入（SIL OFL 授权）。

### 字号（1280×720 成品）

| 元素 | 字号 | 字距（竖排行距） | 色 |
|---|---|---|---|
| 书名 3 字 | 104px | 124px（1.19×） | 见色表 |
| 书名 4 字 | 96px | 118px（1.23×） | 见色表 |
| 书名 5 字 | 92px | 112px（1.22×） | 见色表 |
| 作者小字 | 30px | 40px | #8A9184 |
| 副题钩子 | 26px | 34px | #A8A294 |
| 印内「醒」 | 40px | — | #FDF6EC |
| 档位标 | 24px | 32px 行距 | #9AA294 |

**书名字号下限是 92px。**低于这个值，缩到手机首页的 210px 宽时笔画会并。书名超过 5 字的，不要缩字号——改用简称（《我的心灵史》可用《心灵史》，《塞尔伯恩博物志》可用《塞尔伯恩》），全称放副题位。

## 六、副题钩子：这套封面真正的卖点

「相模滩的落日」「林子里的三个月」「三米见方的屋子」——这三句都不是书名，是**内容钩子**。

同类频道的缩略图普遍只有书名加「助眠」两个字，多这一行，点击理由就具体了。

**写法**：6–8 字，具体名词优先，不用形容词，不用问句。直接从《治愈系旁白书目_选题稿件.md》里那二十条开场句摘——那批已经按「第一句就要有画面」写过一遍。

## 七、待定与风险

**档位标的时长要不要留。**目前写的是「深夜档 / 50 分钟」两行。时长跟 YouTube 自带角标重复，建议**只留「深夜档」，去掉时长**——档位是系列信息，时长系统已经给了。这条待定。

**留白款是风险项。**《方丈记》那张符合设计逻辑（内容越接近减法，画面越空），但在缩略图网格里「空」往往被读成「没内容」。它可能表现最好（一片满当当里唯一的空白），也可能最差。**建议单独 A/B，不要跟着系列一起定**。

**已验证的三款**：自然与人生（远景·落日）、武藏野（林中路）、方丈记（留白）。其余两个镜位的封面还没出样。

## 八、生产

- 出图流程：SVG 模板 → 1280×720 PNG。可参数化的入参为：`书名`、`书名字数`、`作者`、`副题`、`镜位`、`档位`。镜位决定书名墨色、色带色和调用哪套插画。
- 与公众号那套 `cover_studio.py` 是两套东西（尺寸、职能都不同），但参数化思路一致，可并入同一目录管理。
- 上传前必检一项：**把成品缩到 210px 宽看一眼**，书名笔画是否还分得开。这是唯一必须做的检查。
