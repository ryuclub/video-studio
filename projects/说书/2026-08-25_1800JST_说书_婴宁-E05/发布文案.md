## 标题

```

```

## 中心思想

> 这一期的说破句。发片前拿它对一遍标题和简介 —— 三样说的要是同一件事，标题才不算超发。

```
让一个人不笑的，从来不是那件事本身，是有人告诉她——这一笑，是要有人替她赔的。
```

## 简介

```
《聊斋》写了几百个女子，只有一个是靠笑出名的。

她从上元节那天出场就在笑，见了生人笑，被人说也笑，拜堂拜不下去还是笑。
婆家拿她没办法，邻家的媳妇隔三差五找借口来逗她。后来官司上了门。
然后有一天，她不笑了——一辈子再没笑过，可也不见她愁。

按原文讲全本：上元灯市那一枝梅花、「个儿郎目灼灼似贼」、
一个人往西南山里走三十里、墙头上那一笑、老太太认亲、袖子里那枝枯了的梅、
婚后满院子的花、木香架、墙下那段空心的枯木、一纸状子、
婆婆叫她过去说的那段话，以及她后来对着丈夫哭的那一夜。一段不删。
```

## 发片前核对（机器查不了的）

- [ ] **整片听一遍。** 说书人 277 段，其余五个角色加起来只有 31 段 ——
      这一期几乎全靠主讲人撑。重点听幕五（80% 非常规）：
      婆婆那三段话**是好意，不是训斥**，念成刻薄这一期就废了。
      整篇的力气在「她听完就不笑了」，不在「她被骂了」
- [ ] **婴宁的笑不能靠音效，也不能靠演。** 笑是写在文本里的（「她说着说着又笑了」由说书人交代），
      笑娘那 12 段台词要**平着说**——她说「我不习惯跟生人一块儿睡」的时候是真不懂，
      不是害羞也不是调情。这一句念歪，全篇的「憨」就立不住
- [ ] **笑娘是这一期新增的音色**（`cast.ts`，晓伊底 / +12% / pitch 1.16）。
      它跟艳鬼同一个基础音色，只是更小更快 —— **要确认它撑得住 12 段**，
      以及跟妇人（王母）、老太太（鬼母）分不分得开。两个女性长辈都是晓晓底，
      靠「平稳 vs 颤抖 + 语速差 6%」分，这一条只有耳朵能判
- [ ] **人名前后一致**：王子服 / 婴宁 / 吴生，全片不能换叫法。
      山里那个老太太，前面一律叫「老太太」或「姨」，**只有幕五自陈那一段才出现「鬼母」**——
      这是故意的（那一段才揭底），听的时候确认没有提前漏出来
- [ ] **西邻子那一段够不够克制**：以木代己、蝎藏木中、人夜里去了、第二天死了。
      稿子里没有细描，听感上也不能因为节拍推得太狠而变成猎奇
- [ ] **收束的论断在正文里演过没有**：「这一笑是要有人替她赔的」——
      幕四（墙头一笑 → 死了人 → 状子）演过，幕五（婆婆算账 → 她当场发誓不笑）演过，
      收束里「拜堂那天笑没人跟她算」也回指得到幕四开头。**三处都要指得回去**
- [ ] **成片第一帧现在是新版式**（主字「不笑」，不再是繁体竖排的「嬰寧」）。
      开片那 1.5 秒看着立不立得住 —— 这是这一期第一次这么出，**要用眼睛确认一遍**
- [ ] **YouTube 缩略图看 `YT_预览210.png`**（不是 1280 那张）：主字「不笑」在信息流大小上
      跳不跳得出来，右边那个「笑 → 一条直线」认不认得出。
      `ship` 现在包这一步了（`npm run yt:cover -- --ep E05` 可单跑）
