# 老牛 · 交接说明

给本地项目用。`bull_stand.svg` 现在和 `horse_only.svg` 结构对等，同一套驱动逻辑能跑，
**但支点坐标不同**——老牛的脸比老马宽，照抄老马的数字会错位。

---

## 一、资产状态

`bull_stand.svg`：透明背景、外接框裁紧、分组齐全。

```
#bull
├ #body                    躯干+双臂+双腿（一条连续轮廓）
└ #head          transform 钩子，扭头缩放这一层
  ├ #head-shape            耳、头、口鼻、鼻孔、额毛
  ├ #face        transform 钩子，扭头时额外横移做视差
  │ ├ #eye-white-l / -r
  │ ├ #pupil-l / -r        transform 钩子，转眼珠
  │ ├ #mouth-closed        默认显示
  │ └ #mouth-A / -I / -O / -E   默认 display:none
  └ #head-front            牛角，压在最上层
```

---

## 二、支点坐标（和老马不同，必须换）

| 项 | 老牛 | 老马 | 说明 |
|---|---|---|---|
| viewBox | `74 22 752 1444` | `184 43 366 1028` | 老牛更宽更高 |
| 扭头垂直轴 | **x = 450** | x = 352 | 头部中线 |
| 左眼中心 | **(340, 362)** | (282, 257) | 眨眼绕这里纵向压扁 |
| 右眼中心 | **(560, 362)** | (422, 256) | |
| 口型中心 | **(450, 594)** | (352, 410) | |
| 眼珠位移上限 | **±32 / ±26** | ±26 / ±22 | 牛的眼白更大，可动范围也更大 |
| 视差系数 | **56** | 46 | 脸更宽，扭头时五官横移量更大 |

**眨眼要眼白和眼珠同步压扁**，只压眼白的话眼珠会飘出眼眶。

**扭头是假的**：整个 `#head` 横向乘 `cos(角度)`，`#face` 再额外横移 `56 × sin(角度)`。
±25 度以内可信，再大牛角不会转到三维正确的位置，会穿帮。

## 三、双人构图数字

画布 1080 × 1920。三档景别，**默认用中景**。

| 景别 | 左位 | 右位 | 桌沿 y | 主角高 | 次角高 | 主角头顶 y | 次角头顶 y |
|---|---|---|---|---|---|---|---|
| 远景 | 0.27 | 0.70 | 1620 | 940 | 1080 | 640 | 600 |
| **中景** | **0.26** | **0.72** | **1530** | **1120** | **1280** | **520** | **470** |
| 近景 | 0.24 | 0.80 | 1430 | 1330 | 1520 | 400 | 340 |

位置是画布宽度的比例，高度是像素。次要角色再乘 0.88、头顶下移 50，用近大远小分主次。

### 四条规则

**一、默认中景。** 牛角展开 660px、加老马 516px 超过画布宽度，
**两人按等高近景并排放不下**。中景是唯一同时满足「两人完整不裁」和
「脸大到能看清眨眼扫视」的一档。近景只在落点用，那时牛的外侧角被裁掉无所谓。

**二、别退到比远景更远。** 眨眼和扫视的位移只有十几个像素，脸一小这两个动作就白做了。

**三、说话标记挂在说话者头顶正上方**，不是头侧。
外侧被角色占满没有空白，挂头侧会和鬃毛、牛角叠在一起，读着糊。
头顶那片墙永远是空的，而且正上方的归属最不会被认错。

**四、桌子压在最上层。** 半身加前景遮挡就读作坐着，不用画坐姿。
桌沿以下那片留白是字幕区，不要填满。

## 四、合成方式（不要做成合成好的双人 SVG）

双人画面是**渲染时合成**的，不是一个资产。理由有两条：

**一、两人要交替说话。** 合成好就锁死了，每换一个口型都得重出一张。

**二、id 会冲突。** 两个角色内部都有 `#pupil-l`、`#mouth-A`、`#face`。
拼进同一个文件后，按 id 查找会**抓到第一个匹配的** —— 你想让老牛张嘴，张嘴的是老马。

所以顺序必须是 **先各自驱动，再合成**：

```
老马 SVG ──驱动(口型/眼珠/眨眼/扭头)──┐
                                       ├── 拼进场景 ── 输出这一帧
老牛 SVG ──驱动───────────────────────┘
```

反过来「先合成再驱动」一定出问题。

### 图层顺序

```
1  背景场景
2  后面那个角色（次要，缩 0.88）
3  前面那个角色（主角）
4  说话标记
5  桌子           ← 必须在角色之上，这是「坐着」的关键
6  字幕
```

说话标记放在桌子之下，这样它不会盖到字幕区。

## 五、老牛没有的东西

- **走路**。只有站姿，四肢是一条连续轮廓，拆不出可旋转的腿。要走路得另做装配。
- **手上的道具**。老马握着咖啡杯，老牛是空手。要拿东西得单独画。
- **侧面**。只有正面，转身需要另画。
