## 二、字数是怎么定的：卡片的 3300 是错的，但每幕的分配是对的

卡片第一节写「建议 3200–3400 字 → 15.4–16.3 分钟，按 208 字/分」。**三个数没有一个能用：**

**① 208 字/分是 v1 的系数，而且当时就对不上账。** v1 是 2868 字 / 752.8 秒，反推 226 字/分，
不是 208。这个数已经在 E01 方案.md 第九节划掉了。

**② 拿 v2 重算是 228 字/分**（稿件汉字 3832 / 成片 1007.6 秒）。口径写清楚：
按**稿件正文汉字**算，不是含标点字符（264.6），也不是去掉停顿的纯发声语速（267.5）。
换算就一句话：**目标分钟数 × 228 = 稿件汉字数。**

**③ 卡片自己的每幕字数加起来是 3670，不是它标题里写的 3300。**
180 + 320 + 620 + 820 + 780 + 700 + 250 = 3670。差了 370 字。

三条合起来，结论反而干净：**每幕的分配不用动，动的只是那个作废的表头。**
3670 字按 228 换算是 16:06，正好落在卡片本来想要的「15.4–16.3 分钟」里——
**卡片的分幕设计一直是对的，是那个系数把它算歪了。**

| 幕 | 汉字 | 累计 | 累计时刻 |
|---|---|---|---|
| 冷开场 | 180 | 5% | 0:47 |
| 引入 | 320 | 14% | 2:12 |
| 幕一 · 荒寺 | 620 | 31% | **4:55** ← 试听切到这儿 |
| 幕二 · 夜叩 | 820 | 53% | 8:31 |
| 幕三 · 实情 | 780 | 74% | 11:56 |
| 幕四 · 剑光 | 700 | 93% | 15:00 |
| 收束点评 | 250 | 100% | **16:06** |

写稿时**按幕对字数**，不要只对总数——某一幕超了 200 字，是把别的幕挤掉，
而卡片里每一幕该占多少已经是想过的（幕二立人、幕三是芯）。

## 三、选角：七个原型够用，一个新的都不用做

E02 要五个说话的角色，**现有的成熟音色全部对得上**，不新增、不调参：

| 角色 | 音色 | 参数（`cast.ts` 现值） | E01 里的成色 |
|---|---|---|---|
| 叙述 | `说书人` | 云健 +19% / 0.92 / 0.94 | v2 返工定稿，203 段 692 秒，**别动** |
| 宁采臣 | `书生` | 云希 −2% / 0.94 / 0.96 | 8 段 24 秒，注释里本来就写着「宁采臣」 |
| 聂小倩 | `艳鬼` | 晓伊 −2% / 1.10 / 1.13 | 3 段 21 秒 |
| 燕赤霞 | `老道` | 云扬 −10% / 0.86 / 0.91 / aged | 17 段 62 秒 |
| 老魅 | `厉鬼` | 晓伊 −16% / 0.95 / 0.97 + 22ms 梳状 | 1 段 7 秒 |

**三个男角色三个不同底子**（云健 / 云希 / 云扬），这一点比 E01 轻松——
E01 因为多一个二郎，四个男角色挤三个底子。E02 没有二郎。

**宁母不给台词**，卡片这条守住：一期出场角色不超过四个（老魅只出声，算半个）。

### 但有两处必须先用耳朵过，不能直接开跑

**① 燕赤霞 ↔ 说书人。** 这一对的红线是**不过**的（Δ基频 9Hz / Δ低高频 3.7dB，
红线要 ≥25Hz 或 ≥6dB）。E01 定案走「丙」——靠 28% 的语速差分辨，听过对照确认分得清。

**但那个结论是在老道全片 17 段 62 秒的前提下做的。**
E02 的燕赤霞是幕一和幕四的主角，戏份估计 **3–4 倍**，而且幕一会出现
「说书人叙述 → 燕赤霞说话 → 说书人叙述」的连续交替。
**同一个结论撑不到这个戏份上，必须重新听一遍。** 真不行就走「甲」的变体：
新增一个 `剑客` 原型（云扬 base，pitch 压到 0.80 左右 ≈ 88Hz，跟说书人拉到 24Hz），
**不要去改 `老道` 本身**——那会把 E01 重渲时的音色一起改掉。

**② 老魅 ↔ 聂小倩。** 这条卡片没看出来，**是 E02 独有的坑**：

`厉鬼` 的设计意图写在 `cast.ts` 的注释里——「跟艳鬼**刻意分不开**，它俩本来就是
同一个角色的两个状态」，方案.md 第二节还专门把这一对**排除在分离度检查之外**。
那是为《画皮》定的，题眼是「那个美人就是那个东西」。

**到了 E02，小倩和老魅是两个不同的存在**，而且是对立的——老魅胁迫小倩杀人。
把一个「设计成跟小倩分不开」的音色安给她的加害者，语义正好拧了。

**建议：老魅不给台词，全部由说书人转述。** 三条理由：
它在 E02 本来就只有一两句，删掉成本为零；卡片自己的「出场角色不超过四个」也支持；
`厉鬼` 那套配置是 E01 建立的一层联系，挪作他用等于把它花掉。
要是坚持留声音，**就必须先出一条「小倩 → 老魅 交替」的对照**，跟男声那条一样用耳朵定。

## 五、封面：数据可以现在就填

`MOTIFS` 里**已经有 `孤灯`**（兰若寺的孤灯，焰向左偏暗示门外有人），E02 不用写新符号。
`scenes.json` 里加这一段就能出图：

```json
"cover": {
  "series": "liaozhai",
  "title": "聶小倩",
  "hook1": "她殺過兩個人",
  "hook2": "沒人要她償命",
  "accent": "殺",
  "seal": "其二",
  "epLabel": "夜聽說書 · 第二則",
  "motif": "孤灯"
}
```

钩子是按铁律拟的（写故事里最反常的事，不写形容词），**但这两句要你定**。
拟的时候刻意避开了 E01「他明知她是鬼 / 還是帶她回家」的句式——
同一个构造用第二次就成了套路，第二期还不到用套路的时候。
选的是收束点评的题眼：**没有人追究她杀过人。**

三字标题走 `titleByLength[3] = 0.245`，字号比《畫皮》小，按左缘定位所以边距不变。
字体现在是仓库 `fonts/` 里的 Noto Serif CJK SC 静态字重，900 拿到真 Black。
