# 老马 · 长片稿件规范

> 从长片 001 的三轮返工里提炼的，适用于所有五分钟以上的老马稿件。
> 短片规范另见 [单点式](单点式_出片方案.md)、[累积式](累积式_出片方案.md)，**互不参照**。
> 怎么出片看 [长片_出片方案.md](长片_出片方案.md)。
>
> 稿源：素材包 `E:\ryu\laoma\老马长片_稿件内容规范.md`（2026-08-25 整合进来，以这一份为准）。

## 一、支点是「说破一次」

短片里老马从不说破，那是他的姿态。**长片如果还是不说破，五分钟就只有姿态没有事。**

```
一件事发生了 → 老马讲这件事 → 讲到某处他说破一句 → 收回来
```

说破那一下是长片唯一能给而短片给不了的东西。观众看了三十条他不说破，
突然听他说破一次，**这个反差本身就是长片的价值**。

三条约束：

- **全片只说破一次。** 说两次就不值钱了。
- **说破之后要收回来。** 不能说完就升华，要有一句「说完我就有点后悔」那样的往回缩。
- ⚠ **对方不能接得太稳。** 老牛回一句「那你现在知道了」就够了，
  不许出现「你别这么想」「其实你挺好的」这类安慰 —— **安慰会把说破的重量卸掉。**

## 二、语言：去掉分析腔

返工最多的一处。**AI 味的根源不是用词高级，是把话说得太整齐、太像结论。**

### 1. 能用口语词就不用书面词

| ✗ | ✓ |
|---|---|
| 他没说话 | 他没吭声 |
| 他不是为了结果干的 | 他不图什么 |
| 他不是不确定 | 他不是没主意 |
| 我不是看破了 | 我那不叫看得开 |
| 这段对话我们重复过十几次 | 这话我俩来回说过十来次 |

⚠ **书面概念词一个都不许有**：看破／执念／意义／本质／状态／机制。

⚠ **名单以 `用语规范.md` §7.2 为准**（那边是 12 个，比这儿多「认知／内耗／能量／磁场／底层逻辑／情绪价值」）。
2026-08-26 之前这儿和闸门里各存了一份 6 个词的表，现在合并到 `laoma-diction.ts` 一处 —— **这行留着是给上下文用的，别当名单抄。**
「看破」是佛经武侠词，**工位上的人不这么说话**。

### 2. 能说半句就不说整句

人在难受的时候话是不利索的。**要给一处说不下去的地方**：

```
我哪明白啊。我就是……      ⏸0.5
我就是没敢试。
```

那 0.5 秒是全片最重的半秒 —— **他要说的话自己都嫌难听，卡了一下才说出来。**
有了这个磕巴，前面那些句子才像从嘴里出来的。

### 3. 不该整齐的地方别对仗

三句排比、前后对称、末句总结 —— **那是写作的手艺，不是说话的样子**。
说破段最初写成三句整齐论证，读起来像做报告；拆成七句长短不一的才对。

### 4. 判断句改成认输句

| ✗ | ✓ |
|---|---|
| 我是不敢 | 我就是没敢试 |

前者是给自己下定义，后者是承认。差一个字，一个像结论，一个像认输。
**老马不给自己下定义。**

### 5. 台词要接住上一句

不许凭空起一个新概念。老牛刚问完「你怎么一直不换个地方」，
老马就该接着那个说 ——「我**那**不叫看得开」的「那」，指的正是他刚才那套说辞。
**接得上才像对话；接不上就是各说各的。**

## 三、比喻之后必须跟一句人话

比喻可以留，但下一句必须把它说成人话。**听众在半睡状态，不会自己翻译。**

```
✗  他说的时候一点也不硬，就是陈述
✓  他说的时候一点劲儿都没使，就跟说今天有点冷似的
```

后者也是比喻，但它本身就是人话；前者那句「就是陈述」是分析，读起来像论文。

## 四、情感落在物件和动作上

不写心理，写动作。

| 要表达的 | ✗ | ✓ |
|---|---|---|
| 想念 | 他很想念老牛 | 他把鱼缸从窗台挪到桌上，因为窗台冬天冷 |
| 说不出话 | 他心里五味杂陈 | 我举了下杯子，说了句一路顺风 |
| 认真 | 他做事非常认真 | 最后半天他写了份交接文档，十一页 |

**全片的 object 要贯穿。** 001 是那条鱼：老牛桌上（远）→ 楼下交接（中）→ 老马窗台（近）。
**它的位置变化就是故事线** —— 出片那头也照这个走（`长片_出片方案.md` §二）。

## 五、结尾：给变化，但要小

长片跟短片的另一个差别是**允许有一点点真的变了**。但变化必须小到不像变化。

```
我没变成老牛。
我就是每天换点水。
```

⚠ 不许出现「从那以后我明白了」「我决定改变」「这件事教会了我」——
**不总结，不升华，不许诺。**

结尾要回到开篇那个东西。开篇是鱼缸，结尾就落在换水上 ——
**开篇换了，结尾也得跟着换。**

## 六、配角不能完美

长片 001 差点犯的错。

最初的老牛勤恳、体面、不抱怨、临走还写十一页文档 ——
**观众会敬他，但记不住他。没有缺陷的角色不好看。**

给他留了一处：他说走是因为老家有事，但**不全是**，去年他提过一次涨薪没成。
老马知道，从头到尾没说破。

这样一来「不说破」就不只是老马对自己的姿态，**而是他对朋友的一次沉默** ——
分量完全不同，而且给全片装了个悬念：观众会一直等老马会不会戳穿，最后他没有。

## 七、静场：不靠演

老马是一张几乎不动的脸。**画面不动的地方，静场超过 1.5 秒就是卡住，不是留白。**

| 情况 | 上限 |
|---|---|
| 画面无变化、**声音也是干的** | **1.5 秒** |
| 同时给一次镜头切换或声音层变化 | 2–3 秒 |
| 说破段的句间 | 见下 |

⚠ 原来定的 8 秒静场**作废** —— 那是给真人表演片的做法。
改成切窗外空镜 2 秒、环境音换一层：观众感觉到「停了一下」，但画面一直在给东西。

### 说破段的句间：**取决于那段静音里有没有东西**（2026-08-26 定）

这一条原来写的是「**1.0 秒，一秒都不能压**」。
**001 实测跟它对不上** —— 说破段八句是 `0.8 / 1.0 / 0.6 / 0.8 / 0.5 / 0.6 / 0.5 / 1.5`，
**八句里六句低于 1.0**。

用户 2026-08-26 听完的判断：**「001 的音频还可以，可能因为有场景音，没听出静场。」**

> **所以这条规矩的前提被找出来了：它是在「声音是干的」那个假设下写的。**
> 001 铺了分场景床音（−43 ～ −50 dBFS，人声 −22）——
> **那半秒里耳朵是有东西听的，所以不读作「停住了」，读作「他在想」。**

| 那段静音里 | 说破段句间下限 |
|---|---|
| **干的**（没有床音） | **1.0 秒** —— 原来那条，一秒都不能压 |
| **有环境床音** | **0.5 秒**就够 —— 001 走的是这一档 |

⚠ **这一档有个能把它作废的陷阱：`npm run build` 出的成片里没有床音。**
环境音是 `tools/long-ambience.mts` 在 mixdown **之后**外挂上去的
（出片方案 §三 那条），`cfg.ambience` 在 json 里是 `'none'`。
**所以同一份稿子，走 ambience 那条路听着好，走 `build` 那条路就是干的**，
那六处 0.5 秒会真的变成六处静场。

**体检查不出走的是哪条路** —— json 里看不见床音有没有铺上。
所以 `laoma-long-check` 那一条是 **warn 不是 error**，措辞里点名了这个前提。

## 八、稿子怎么标（给出片用）

配音稿要把两件事标死，出片链一条规则都不发明（`tools/long-parse.mts`）：

```
【马】      老马旁白      ← 老马不写后缀 ＝ 旁白
【马·台】   老马现场台词
【马·破】   **说破段**      ← 分层上就是台词，多标一个 shuopo 给体检查
【牛】      老牛的话      ← 老牛不写后缀 ＝ 现场台词
【马·回忆】【牛·回忆】   回忆段（音质另加一层）
⏸0.5       这一句之后静音几秒（也可以单独一行：> ⏸**2.0 — 说明**）
## 一、早上  章标题：换场景、换环境音都按它切
```

⚠ **缺省值按人分，两个人反着来。** 老马大部分时间在讲，不标就是旁白；
**老牛从不旁白** —— 他每一句都是当面对老马说的，不标就是台词。
头一版两个人共用「旁白」缺省，老牛 14 句全标成了旁白。画面上看不出来
（出帧先按谁在说分流），但现场混响那一层一接上去，**漏掉的正好是他那 14 句** ——
错在缺省值上的东西，要等到下一个功能上线才现形。

⚠ **一段一句，别按句号拆。** 稿子把几句排成一段，是因为它们要一口气读下去
（旁白句长、台词句短，长短对比本身就是两个人的区分）。

⚠ **说破必须标 `【马·破】`**（2026-08-26 加）。**说破是这条线的支点**（§一），
可稿子里原来没有任何办法把它标出来 —— 于是「全片只说破一次」「说破后往回收」
「句间不许压」这三条**根本无从查起**。现在标了：`long-parse` 写成 `shuopo: true`，
`laoma-long-check` 拿它查那三条。**分层不变** —— 说破段在画面上仍旧走台词那一层。

⚠ **标记会一路传到画面**（`_layer`）：旁白走底部字幕条、台词走头顶那一层。
头一版没传这个字段，出帧脚本按句长猜，「老牛在这儿待了六年」11 个字当场被摆到头顶上。
**稿子里标死的东西，别在中途丢掉。**

## 九、出稿检查表

> **✅ 有代码在守的那些跑 `npm run laoma:long-check -- jokes/<id>.json`**（2026-08-26 立）。

**结构**

- [ ] 👤 对方没有给安慰
- [ ] 👤 有一个贯穿全片的物件，且位置有变化
- [ ] 👤 结尾回到了开篇那个东西
- [ ] 👤 配角有一处不完美

**语言**
- [ ] 🤖 没有书面概念词（名单见 `用语规范.md` §7.2，12 个）
- [ ] 🤖 有一处说不下去的停顿（找「……」）
- [ ] 👤 说破段不是整齐排比
- [ ] 🤖 没有判断句式的自我定义（半查：认几个常见句式）
- [ ] 👤 每句台词都接住了上一句

**平读测试**

**写闸逼着把「差不多是这个意思」变成「机器能判」**，三处因此改了：

| 原来写的 | 改成 | 为什么 |
|---|---|---|

| 「旁白无语气词」 | **加引号的引述排除** | 001 那两句「命中」的（`你不累啊`、`这个我来吧`）**全在引号里**，那是他引别人的话 |
| 「估片长用 5.6 字/秒」 | **净语速 5.2，而且要加停顿** | 见下 |

### 说破段的句间停顿：定了（2026-08-26）

原来写「1.0 秒一秒都不能压」，跟已出片的 001 对不上（八句里六句低于 1.0）。
**用户听完定：001 整体挺好，就这样。** 理由是**有场景音，没听出静场**。

所以规矩改成分两档（**干声 1.0 ／ 有床音 0.5**），详见 §七。
体检那一条留作 `warn` —— **json 里看不出床音铺没铺**，
而 `npm run build` 那条路是不带床音的。
