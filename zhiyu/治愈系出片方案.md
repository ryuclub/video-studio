## 一、跟说书线的关系

**能整套搬过来的**（这条线最大的省事之处）：

| 能力 | 在哪 | 为什么能直接用 |
|---|---|---|
| 单人旁白的稿件结构 | `script.json`：`no / act / text / who / beat` | 说书本来就是一个说书人讲到底，治愈线只是**角色数退化到 1**，结构完全一样 |
| **房间底噪**（−62dBFS 粉噪） | `shuoshu-build.ts` 的 `pinkNoise` | 见下，这是治愈线的**前提条件**，不是可选项 |
| 实测式响度归一 | `shuoshu-build.ts` 的 `loudnorm(src,dst,target,ceiling)` | target 是参数，传 −21 就是治愈档。它不用 ffmpeg 的 loudnorm 滤镜（说书线试过，`linear=true` 在这种素材上不行） |
| **静态图 + ffmpeg concat 出片** | `shuoshu-video.ts` | 45–60 分钟的助眠档**必须**走这条。逐帧管线（joke-video）渲 50 分钟 = 9 万帧，按实测 60ms/帧要 1.5 小时，而且没有意义——治愈线的画面本来就是静止的 |
| SRT / 封面 / 发布文案 / 出片总装 | `shuoshu-srt.ts` `shuoshu-cover.ts` `shuoshu-ship.ts` | 换套模板即可 |

**必须另做的**：

| 要做 | 为什么不能共用 |
|---|---|
| **节拍表数值** | 说书的停顿被压到 ≤1.0s（频道规范「停顿不要太久」）；治愈档要求句间 0.8–1.2s、段间 2.5–3.5s、硬切 4.0s。两条线的节奏观是相反的，`BEATS` 不能共用，要新建一张 |
| **画面模块** | 说书是水墨（`style/inkwash.ts`），治愈是清新画风：米白和纸底、浅色木格窗框、左侧竖排标题、左下朱砂印、底部细进度线。这是新的一套 scene，不是改 inkwash |
| **主讲音色** | 聊斋那套多角色音色派生全部作废。见下 |

### 一条关键的因果：长停顿依赖底噪

治愈档的规范要求段间停 2.5–3.5 秒、硬切 4 秒。**说书线当年恰恰把停顿从
1.2–2.2s 压到了 1.0s 以内**，反馈是「停多了，不舒服」。

根因不是长度，是**TTS 插的空白是绝对静音**（实测 −227dB），现实里不存在这种东西。
没有底噪时，停顿越长越像「卡带」，不像「酝酿」。

后来说书线正面补上了这一层：全片垫 −62dBFS 粉噪，停顿里就有了「房间」。
**所以治愈线的长停顿现在是可行的** —— 但它的可行性完全建立在底噪那一层上，
谁要是把底噪关了再按这份规范停 4 秒，出来就是卡带。

## 二、主讲音色（已定稿）

```
cast「夜读」　zh-CN-XiaoxiaoNeural
pitch 0.83 / formant 0.83 / tempo 1.0　朗读速度不动（无 rate）
句间停顿 1.1s（《方丈记》1.25s）　房间底噪 −62dBFS 粉噪
后期：highshelf 8kHz −3dB → 窄压缩 2:1 (30ms/200ms) → 响度 −21 LUFS
实测：基频 202Hz　整期均速 225 字/分（《方丈记》218）
```

**全季只用这一条音色。** 期与期的差别写在各期稿件配置里（主要是停顿），
不要为单期新开音色 —— 调试用的临时变体听完就从 `cast.ts` 删掉。

### 定下来之前排除掉的，别再走一遍

| 试过 | 结果 |
|---|---|
| 小艺 / 晓萱（公开列表外，能合成） | 都比小晓更高更亮，不是成熟女声。晓萱另有随时被撤的风险 |
| 只压 pitch 不压 formant（0.78/0.83） | "年轻姑娘捏着嗓子往低了说"，不是阿姨 |
| formant 压到 0.79 | 同样 202Hz、数字上更厚，但**听感带回响** —— rubberband 拉狠了。**0.83 是底** |
| pitch 压到 0.7834（190Hz） | 偏沉、闷 |
| `rate −38%` | 每个字都被拉长，六条候选一起不正常。那个数是把稿件的「190 字/分」当成**说话速度**算的，而它是**整期含停顿的均速** |
| `aecho=...:12:` | 12ms 是梳状滤波不是房间反射（joke-video 的艳鬼预设用 22ms 做"一个人说话带出两个"）。已去掉 |

### 一条没解决的

**半音标准差 4.2，目标 1.5–2.5。** 这是 Edge 中文女声的韵律本底，
逐句测和整段测一致，压音高压不动（压了 3.2 个半音只从 4.47 到 4.25）。
唯一干净的解法是接 `mstts:express-as` 的 style（`calm`/`gentle`/`narration-relaxed`）
和 `styledegree`，但管线现在没这个接口。听感上不碍事就先不动。

### 字数配额（用实测语速反推，稿件要求的第 3 步）

| 片长 | 《方丈记》（218 字/分） |
|---|---|
| **45 分钟** | **≈ 9800 字** |
| 50 分钟 | ≈ 10900 字 |
| 60 分钟 | ≈ 13100 字 |

比稿件原估（190 字/分 → 8500–11400）多约两成。

## 三、《方丈记》这一期的特殊约束

这一期在整份书目里是**画面可承载度最低的一本（★★☆☆☆）**，而且——

> **画面反过来锁死稿件结构，只能倒叙。**

- 前半的大火、旋风、迁都、饥荒、地震**一格都画不了**（这套画风不画人、不画事件、不画冲突），
  而且深夜档讲灾异会压人
- 所以结构是：**先讲小屋里的日子 → 中段回溯他为什么搬进来 → 末段回小屋**
- 画面全程锁在草庵一景，用五种镜位里的**「留白」**那一种
- 饱和度规则的**下限锚点**：内容越接近无常、越接近减法，饱和度越低、主体占比越小。
  这一期是全系列最低的那一档
- 音色再慢 8%、再低 1 个半音（已落进候选参数）

试听稿（`projects/2026-08-19_hojoki/试听稿.md`）就是按倒叙写的开头，
443 字，正片会直接用。

### 调试纪律（这一轮踩出来的）

- A/B 变体加进 `cast.ts` 之后，**那一轮听完就删**，不留在共享库里 ——
  `voicedoc.ts` 会遍历全部 `CASTS`，留着会把调试音色渲进《音色音调手册》
- `cast:check` **永远读输出**再 `--update`，不要管道到 /dev/null。
  那道守门的全部意义就是让人确认「改动是不是你打算改的」
- 治愈线自己的东西（`zhiyu-*.ts`、`zhiyu/`）都是新文件，不碰别的线
