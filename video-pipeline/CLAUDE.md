# 视频动效：必须调用 ./video-pipeline，禁止另起炉灶

本项目已有一套经过实测验证的动效管线。生成任何图表、数字、时间轴、金句卡、
序号卡、地图动效时，**一律通过 `./video-pipeline` 生成**。

## 禁止事项

- ❌ 不要 `pip install` 任何东西。**本机没有 Python 环境**
- ❌ 不要 `npm i` matplotlib 替代品、node-canvas、puppeteer、headless browser、
  fabric、konva 或任何绘图库。管线是零运行时依赖的，只需要 ffmpeg
- ❌ 不要用 ffmpeg 的 `drawtext` / `drawbox` 手搓动画。折线图和地图做不出来，
  而且中日文字号和排版会失控
- ❌ 不要自己写运镜、拼接、字幕烧录的 ffmpeg 命令。管线里已经有，
  且处理了几个不实测发现不了的坑（见下）
- ❌ 不要修改 `THEME` 常量以外的视觉参数来「调好看一点」。
  配色和缓动是全片统一的，改一处会让系列片视觉语言漂移。
  **唯一的例外是 `glitchTitle`** —— 它用 `scenes.ts` 里的 `GLITCH` 常量
  （fx-kit 原色：正红 #E5484D / 蓝绿 #4FB8A8 / 纸白 #F5F3EE），
  故意不跟 THEME。换成本项目的橙红 + 蓝，两路色相差不够，分离感就散了。
  **别顺手把它改回 THEME**

## 四个必须知道的坑

改动 `src/assemble.ts` 或 `src/layers/layerA.ts` 前先读文件顶部注释。

1. **xfade 的 duration 小于约 0.1 秒会静默丢弃前一段** —— 不报错、退出码 0，
   43 秒的片子会变成 5 秒。所以拼接用的是「分段 concat + 段间 xfade」策略，
   不是一条 xfade 链
2. **运镜必须超采样** —— `zoompan`/`crop` 按输入图整数像素取样，
   直接对 1080p 图缓推会一格一格抖。倍率是自适应的，别改成固定值
3. **转场会让后续镜头整体前移** —— 字幕时间按 `build/timeline.json` 对齐，
   **不要用 storyboard 里的 `start` 字段**
4. **改了 `scenes.ts` 的代码，重渲必须加 `--force`** —— 缓存键（`util/cache.ts` 的
   `shotKey`）只哈希 shot 对象、输出规格和引用到的**素材文件**，不包含渲染代码。
   改完代码直接重渲会秒过缓存、拿到旧画面，而且日志显示「✓ 完成」，看不出来。
   2026-08-17 就这么把改好的故障标题渲丢过一次

## 数据的硬规矩

**图表里的数字错了比不做图糟糕得多。** 观众记住的就是那个数字。

稿件里的数字是散文式的（「从不到两成涨到将近一半」「三年翻了两番」），
自动提取成 `series` 一定会错。所以：

> **LLM 只负责标出候选位置和建议图型，数据字段留空由人填。**

```jsonc
{ "id": "ov3", "at": null,        // ← 由音频对齐结果填
  "scene": { "kind": "barChart",
    "hint": "稿件此处提到六大城市地价指数变化",   // ← 你写这个
    "series": null,                              // ← 留空，人来填
    "labels": null } }
```

`src/layers/validateScene.ts` 会硬拦截：`series` 为空直接中断，不出片。
不要为了让它跑通而编造数据。

## 动效密度

一篇 1000–1200 字的稿子能识别出十几个「可以做图」的点。全做出来成片就变成
数据大屏了。**宁可漏，不可满。**

- 4 分钟主片总共 **4–6 个动效上限**
- 同类动效不超过 **2 个**
- 相邻两个至少间隔 **25 秒**
密度分三轨各自计数 —— 转场和面板根本不冲突，混在一张表里会互相挤掉：

| 轨 | 成员 | 4 分钟片的上限 |
|---|---|---|
| **面板类** | 地图 / 时间轴 / 左右对照 / 柱状 / 折线 / 数字 / 序号卡 / 三级字幕 / 金句 / 遮罩上滑 | **4–6 个**，同类 ≤2，相邻 ≥25 秒，同一 20 秒窗口只 1 个 |
| **转场类** | 交叉溶解 / 横扫 / 闪白转场 | 横扫 ≤2 且相邻 ≥25 秒；交叉溶解不限 |
| **全幅类** | 闪白打点 / 聚光 / 箭头 / 颗粒漏光 | 闪白 ≤3、聚光 ≤2、箭头 ≤2；与面板类错开 ≥2 秒；颗粒常驻不占额度 |

面板类同窗口的优先级：
`地图 > 时间轴 > 左右对照 > 图表 > 数字 > 清单 > 三级字幕 > 金句 > 遮罩上滑`。
故障标题不参与排队 —— 它是封面 / 章节首屏专用，位置天然不跟别的重叠。

`overlay.ts` 会对超标情况告警，但不会阻止 —— 看到告警就该删掉几个。

## 什么时候上什么特效（触发标准）

词面信号只是**捞候选**，最终留几个由下面的「动效密度」砍。两者缺一不可 ——
只有触发词就是数据大屏，只靠手感就还是随缘。

**「自动」= 光看稿件文本就能判；「人工」= 位置可以看出来，但内容/坐标必须人给。**

| 特效 | 词面信号 | 附加条件 | 判定 |
|---|---|---|---|
| 03 横扫 | 然而 / 但是 / 反过来说 / 问题在于 / 没想到 / 直到 | 须在句首 8 字内 | 人工 |
| 04 闪白 | 一夜之间 / 蒸发 / 腰斩 / 归零 / 彻底 / 答案是 / 一刀切，或感叹号 | 须同时是结论句 | 人工 |
| 06 逐字 | 引号句；从来不是 / 没有人 / 所有人都 / 说到底 / 代价 | ≤24 字，非引号句须独立成段 | 人工 |
| 07 标红 | 13.8% / 六成 / 三倍 / 翻番 优先，其次 全部 / 唯一 / 毫无 / 史上 / 首次 | 每句最多 2 个 | 人工 |
| 08 三级字幕 | 据 / 根据 / 统计 / 总务省 / 国交省 / 日经 / 数据显示 | 须同时句中有数据 | 人工 |
| 09 遮罩上滑 | markdown 标题；第X章；段落首句 | 段落首句须 ≤14 字 | 自动 |
| 10 故障标题 | 危机 / 崩盘 / 失控 / 泡沫 / 破裂 / 暴跌 / 爆雷 / 挤兑 | 须同时是标题，否则归 04 管。**封面 / 章节首屏专用** | 人工指定 |
| 11 柱状图 | 同段 ≥3 个同量纲数字 + 类别标签 | `series`/`labels` **人填** | 人工 |
| 12 折线图 | 数字序列带时间维度，点数 ≥4 | `series` **人填** | 人工 |
| 13 数字滚动 | 孤立大额数字（≥4 位或带「万 / 亿」） | `from`/`to` **人填** | 人工 |
| 14 时间轴 | 同段 ≥3 个年份 + 事件描述 | `events` **人填** | 人工 |
| 15 地图 | 东京 / 大阪 / 名古屋 / 福冈 / 札幌…（简繁都收） | ≥2 个不同地名，且在 `japan-geo.ts` 的 CITIES 里 | 自动 |
| 16 左右对照 | 相比 / 对比 / 前者后者 / 同期 / 反观 / 差距 | 按量词分组配对，须 ≥2 组，`rows` **人填** | 人工 |
| 17 聚光 | 注意看 / 画面中 / 这里 / 左上 / 右下 | 须有 focus 坐标（人给） | 人工 |
| 20 箭头 | 这栋 / 这块地 / 箭头所指 / 圈出来 / 就是它 | 须有 arrow 坐标（人给） | 人工 |
| 序号卡 | 行首 `第[一二三四五]` 或 `[一二三四五]，` | 连续递增 2–5 条，跨度 ≤30 秒。详见 RUNBOOK | 自动 |

**两条已知的撞车，判据定死：**

1. `一、二、` **归序号卡**（连续递增 ≥2 个时）；孤立一个且是段落首句才归 09 遮罩上滑。
   序号卡承载的信息多得多。
2. **横扫只给强转折，单字「但」不算。** 写稿风格明确鼓励口语连接词（RUNBOOK），
   实测四份稿子里「但」出现 12 次 —— 挨个上横扫的话 4 分钟片里会有 10 次硬转场。
   挑的时候只认「然而 / 但是 / 反过来说 / 问题在于」这类强转折，且全片 ≤2 次。

**词表按现有稿子实测过**（219 行 / 4 份）：03 的原词表零命中（我们写「但」不写「但是」），
04 的「蒸发/腰斩」属崩盘题材、政策题材不出现，20 零命中是因为这类稿子没有指画面的话。
换题材（人物、灾害）大概率还要补词 —— 补在这张表里，不用改代码。

## 两种用法

### A. 叠加到已有视频（推荐，用于现有片子）

```bash
node dist/build.js overlay-onto <底片.mp4> --spec overlays.json --out final.mp4
```

底片不动，动效在指定时间点浮出、播完消失。底片只重编码一次，音轨原样搬运。

```jsonc
{
  "fps": 30,
  "overlays": [
    { "id": "ov1",
      "at": 134.0,          // 底片的第几秒。跟随解说词音频，不要拍脑袋
      "duration": 8,        // 覆盖「念这段数据的那几句话」的完整区间
      "scale": 0.55,        // 占底片【宽度】的比例。竖版用 0.85~0.92
      "x": "center",        // '6%' | 像素数 | 'center'
      "y": "8%",            // 默认靠上 —— 屏幕下 1/3 被三级字幕占满了
      "fadeIn": 0.5, "fadeOut": 0.5,
      "scene": { /* 见下 */ } }
  ]
}
```

### B. 整屏切换（用于从零走完整管线）

在 storyboard 的镜头上写 `"tier": "B", "pseudo": "render", "scene": {...}`，
然后 `node dist/build.js render storyboard.json`。

## 场景清单（15 种）

字段以 `src/types.ts` 的 `SceneSpec` 为准。带 ★ 的是 2026-08-17 从 `../fx-kit`
移植过来的 —— fx-kit 是 DOM/CSS + 无头浏览器的实现，这边搬的是**规格**不是代码，
对应关系见仓库根目录的 `FX-PORT.md`。

```jsonc
// 折线图 — 曲线生长
{ "kind":"lineChart", "title":"…", "subtitle":"1992 — 2002",
  "series":[12,18,15,27], "unit":"単位：兆円" }

// 柱状图 — 逐根延迟入场。labels 数量必须与 series 一致，8 根以内
{ "kind":"barChart", "title":"…",
  "series":[100,128,164,210], "labels":["1985","1987","1989","1991"] }

// 数字滚动 — 单个
{ "kind":"counter", "title":"三年内破产企业",
  "from":0, "to":18704, "suffix":" 社", "subtitle":"1997 — 1999" }

// 数字滚动 — 并排（2-3 个，同时滚动。subtitle 在滚完后才浮出）
{ "kind":"counter", "title":"损失规模",
  "values":[ {"label":"不良债权处理额","from":0,"to":100,"suffix":" 兆円"},
             {"label":"公的资金注入","from":0,"to":47,"suffix":" 兆円"} ],
  "subtitle":"相当于当年 GDP 的两成" }

// 时间轴 — 节点交错入场、上下交替。4-5 个最佳，超过 6 个报错
{ "kind":"timeline", "title":"危机时间轴",
  "events":[ {"year":"1997","text":"山一证券破产"} ] }

// 金句 — typewriter 逐字打出，打完 emphasize 的词变红放大
// emphasize 必须与 text 中的字**完全一致**，写错会报错（静默不高亮等于白写）
{ "kind":"quote", "typewriter":true,
  "text":"泡沫破裂之后真正漫长的，不是股价的下跌，而是资产负债表的修复。",
  "emphasize":["资产负债表的修复"], "cite":"辜朝明《大衰退》" }

// 序号卡 — 几条并排，逐条从下往上浮进来。2–5 条
// 序号只是徽标内容：ordStyle 换成 dot/none 就是要点卡，check:true 就是核对清单
// itemAt = 各条入场的秒数（相对面板起点），由 timeline.json 的行起点减 at 得到；
// 不给就在面板时长里均分。正文 14 字以内，超了报错（折行会把固定行高撑乱）
{ "kind":"steps", "title":"有四种情况要留神", "ordStyle":"cn",
  "items":[ {"text":"转职当年的年收洼地"}, {"text":"自由职业 · 个人事业主"},
            {"text":"派遣与 SES"}, {"text":"配偶进入扶养 · 育儿假"} ],
  "itemAt":[0, 6.9, 16.6, 24.8] }

// ★ 日本地图 — 城市依次亮起，所属都道府県同刻填色。6 个以内
// 城市名须在 japan-geo.ts 的 CITIES 里有经纬度；没有对应城市的县写进 highlight
// 标签挨得近会自动下推并画引线
{ "kind":"japanMap", "title":"地价跌幅",
  "cities":[ {"name":"東京","value":"-68%"}, {"name":"大阪","value":"-74%"} ],
  "highlight":["北海道"] }

// ★ 三级字幕 — 主句 / 补充 / 出处依次升起并保持堆叠。最多 3 行，主句 20 字以内
{ "kind":"subtitleStack",
  "lines":["访日客五年来首次减少","上半年 2108 万人，同比 -2.0%","日本政府观光局 · 2026-08 速报值"] }

// ★ 遮罩上滑 — 逐行从行框下方滑出。段落首句、标题级文字用；每行 16 字以内
{ "kind":"maskTitle", "lines":["制度在收紧","但收紧不等于关门"] }

// ★ 故障标题 — RGB 错位 + 切片抖动。**全片最多 1–2 次，连用立刻廉价**
// 12 字以内；slices 3–4、amp 不低于 10，30fps 下才分得出层次
// **选词：笔画方向要混杂。** 错位是横向的，全横笔画的词（「二十三天」这种）
// 横着错开只会在笔画两端露出方块，读不出「彩色鬼影」；带竖笔/撇捺的词
// （「失控的二十三天」「第三章 · 失控」）才是参照里那个观感。
// 这不是参数问题 —— 位移加到 60px 照样是方块，实测过
// 居中、字号按「整串占内容区 62% 宽」自动算，不用给
// dur = 抖动持续几秒（默认 1.0）。**别跟镜头时长绑一起** —— 铺满 3 秒的镜头
// 就成了一帧帧的错位图，不是「信号坏了一下」
{ "kind":"glitchTitle", "text":"二十三天", "subtitle":"1997.11.03 — 11.26",
  "slices":4, "amp":14, "seed":7, "dur":1.0 }

// ★ 左右对照 — 成对数值从中线向两侧生长。2–5 行，左灰右红
// l / r 跟 series 同一条规矩：**人工确认后填，不许从稿件自动提取**
{ "kind":"compareBars", "title":"配偶者特例", "leftLabel":"现行", "rightLabel":"改定案",
  "rows":[ {"label":"婚姻","l":3,"r":5}, {"label":"在留","l":1,"r":3} ] }

// ★ 箭头注记 — 圈选 / 箭头描出 + 标签。**全幅**，坐标是相对整幅画面的 0–1 归一值
// 不做画面识别，不会自动对准物体，坐标必须由人给
{ "kind":"arrowAnnotate", "circle":{"cx":0.62,"cy":0.45,"rx":0.11,"ry":0.14},
  "arrow":{"x1":0.34,"y1":0.76,"x2":0.52,"y2":0.56}, "label":"这一栋", "labelX":0.24, "labelY":0.8 }

// ★ 闪白打点 — 全幅。只在音频重音 + 结论句上砸一下，duration 给 0.18，超过 0.25 就廉价
{ "kind":"flash", "peak":0.85 }

// ★ 聚光引导 — 全幅。除光斑外整体压暗，光斑可沿 path 移动
{ "kind":"spotlight", "path":[{"x":0.35,"y":0.5},{"x":0.68,"y":0.45}], "radius":0.15, "dark":0.78 }

// ★ 颗粒漏光 — 全幅，压 AI 素材的塑料感。可以整片常驻
// 颗粒是 ffmpeg 的 noise 滤镜（不渲 SVG 帧，否则 4 分钟的 RGBA 序列有几个 GB），
// 漏光是 SVG 层；脉冲靠 fadeIn/fadeOut 各取一半时长
{ "kind":"grain", "strength":14, "leak":true, "seed":11 }
```

**全幅类**（`flash` / `spotlight` / `arrowAnnotate` / `grain`）由 `overlay.ts` 的
`FULL_FRAME` 自动按底片尺寸铺满、关掉衬底，`scale` / `x` / `y` 对它们无效。

## 转场预设

storyboard 的 `transition` 可以直接写预设名，等价于写完整的 `{ type, duration }`：

```jsonc
"transition": "crossfade"   // 02 交叉溶解 fade 0.7s —— 同一段落内换镜头
"transition": "whip"        // 03 横扫切换 slideleft 0.38s —— 跨大段落，或稿件出现「然而/但是/问题在于」
"transition": "whipRight"   // 反向
"transition": "flash"       // 04 闪白当转场用 fadewhite 0.18s
```

xfade 做不出 whipPan 的方向性动态模糊（那是 CSS filter 的活），所以横扫靠更短的滑动来补。

## 加新场景

在 `src/layers/scenes.ts` 里写一个返回 `FrameFn` 的函数：

```ts
(t: number, index: number, total: number) => string   // 返回 SVG 字符串
```

不用碰 ffmpeg。规矩：

- 用 `fz(c, 基准字号)` 而不是硬编码字号 —— 面板尺寸会变，字号要跟着缩
- 用 `shell(c, body)` 包外层 —— 它负责透明/不透明两种模式和衬底
- 用 `easeOut` / `easeInOut` / `stagger` —— 线性动画看起来很廉价
- 入场统一用 `enter(a, dir, dist)`（在 `svgRender.ts`），它返回可直接塞进 `<g>` 的
  位移 + 淡入属性串。**方向默认上浮** —— titleBlock、counter 说明行、steps、
  PPT 风的时间轴和数字全是上浮，这是全片的母语。`quote` 的左滑是历史遗留的唯一例外，
  为了不让已出片的观感漂移保留着，不要顺手统一掉；`japanMap` 的横移和 `timeline`
  的上下交错是为了避让轮廓和防止文字打架，也不要动
- 中日文折行用 `wrapCJK`，它做了行头禁则（「，」不能出现在行首）
- 在 `validateScene.ts` 里加对应的校验分支
- 在 `overlay.ts` 的 `PANEL_ASPECT` 里加宽高比（宽高比要随内容条数变的，
  写进同一个文件的 `aspectOf()`，`steps` 就是这么做的）

node dist/build.js doctor
