# 治愈系稿件规范

> 这条线**怎么写稿**。选书看 [治愈系旁白书目_选题稿件.md](治愈系旁白书目_选题稿件.md)，

> **这条线不适用，而且是反着来的** —— 理由写在下面 §五 末尾，别照搬。
>
> 下面每一条都是**做《方丈记》和《枕草子》时踩出来的**，不是事先想好的。
> 带「实测」两个字的都有数，别凭感觉改。

> 而且机器基本查不了。

## 一、文本闸：每一句都要过

来自主讲员设定，**写的时候就得守，不能指望后期救**。

| 闸 | 为什么 |
|---|---|
| **感叹号全删** | 文本里没有的情绪 TTS 演不出来，标点只会让它把语调抬起来，抬得很假 |
| **问句改陈述** | 同上。「有人问他，不闷吗。」——问号去掉，语气自然落下来 |
| **形容词减一半** | 形容词是「我替你判断了」，这条线要的是「我把看见的放这儿」 |
| **长句改短、一句一事** | 同样的音色，句子结构一变，二十分钟听下来的疲劳感差很多 |
| **主语常复现** | 深夜听众会走神，代词一多就跟丢了。宁可重复「他」「她」 |
| **不写数字堆砌** | 「三十七年」「一丈二尺」这种听过就忘，只留必要的 |
| **不写人名地名清单** | 原文爱一口气报四五个地名，念出来是负担。**一个都不留也行** |
| **文言一律自译写** | 不碰任何现成译本、白话本、校注本的措辞 |

**列举体额外一条**：一段里的**物象不超过三样**。原文动辄数七八样，
读起来是快的；念出来、还是深夜念，第四样开始就记不住了。
挑三样，剩下的删掉 —— **删掉的比留下的多，这是常态**。

## 二、只记事，不评论

这条线的调子是一句话：**把事写下来，心情放在事的后面，让它自己出来。**

```
✗ 他很孤独，但他享受这种孤独。
✓ 他说，山里没有别人听，弹坏了也没人笑。
```

- **情绪靠转述递出去**：「他说」「她说」是这条线用得最多的三个字，
  它把判断挂回原作者身上，叙述者只负责搬运
- **不总结**。总结等于替听众听完了
- **不给答案**。《方丈记》结尾他问自己是不是在自欺，然后没答上来 ——
  那一段照原样留着，是这一本最值钱的地方

## 三、段落与停顿

### 数值（实测，别改）

| | 值 | 出处 |
|---|---|---|
| 平均段长 | **18–25 字** | 方丈记样章 18，枕草子 25，都通过了 |
| 最长段 | **不超过 48 字** | 超过这个，一口气念不下来 |
| ⏸ 密度 | **每 100–130 字 / 28–35 秒一个** | 方丈记通过的是 35 秒 |
| 段间停顿 | 1.25s | 见 `zhiyu-beat.ts`，**稿子里不写秒数** |
| ⏸ 停顿 | 1.6s | 同上 |
| 幕末停顿 | 2.2s | 同上 |

### ⏸ 放在哪儿

**每个 ⏸ 前一句必须是收得住的句子**，不能停在半截意思上。

⏸ 是「这一节说完了」，不是句读。**别拿它断列举条目** ——
枕草子第一版给单子里每一条都加了 ⏸，密度掉到 13 秒一个，
⏸ 就从结构记号稀释成了普通停顿。

三个常见的错：

1. **太密**：13 秒一个（枕草子 v1），全片变成一串短句
2. **太疏**：稿件原写「每 3–4 分钟一个」，那是按 ⏸ 长达 2.5–3.5 秒定的；
   收到 1.6 秒之后它不再是硬切而是换气，密一点反而自然
3. **切在半截**：前一句还没说完就停，听感是「卡了」

---

## 四、换气句（列举体专用）

列举体（枕草子、幽梦影这类）**连读三段就腻**。解法是两段之间插一句
叙述者自己的观察，当作换气。节奏是两拍一循环：

```
列举段（原作者写的）→ 换气句（叙述者说的）→ 列举段 → 换气句 …
```

**换气句怎么写**：

- **一句到两句，不要成段。** 它是标点，不是内容
- **说眼前的东西，不说道理。**「她没有说为什么」比「这说明她很敏感」好
- **可以点时间距离**（一千年前 / 今天），但一期不超过三次，多了变说教
- **绝不总结上一段**
- **不做记号。** 要是能一眼挑出哪句是换气，那就说明它没做好

## 五、共鸣：挑那些没过时的

**这是选段的第一标准，不是第二。**

古典随笔里最容易接上现代人的，是那些具体到琐碎的日常。抽象的感慨反而接不上。

```
✓ 困得不行刚躺下，一只蚊子在耳朵边上细声细气地绕，怎么赶都不走
✓ 只读过前半的一个故事，一直惦记着，后来把剩下的那半找齐了
✓ 写出去的信，很快就有了回信
✓ 急着出门的时候，找不着要穿的那件

✗ 人生如白驹过隙
✗ 世事无常，唯有内心的宁静
```

选段时先问一句：**这件事今天还会发生吗。** 不会的，跳过。

**段落里不要顺手点破。** 写完那条就走，别加「你看，一千年了还是一样」——
段内说破一次是提醒，两次就是说教。这一条没有变。

**变的是一期的落点。**

> **2026-08-21 改：这条线现在也说破。**
> 原来这儿写的是「不点破」，理由是判断句会把人拉醒。**那一条作废了** ——
> 可以点破、可以诊断、可以给教训，**那才是中心思想，也是听众的听点**。
> 一期没有落点，听众听完什么也带不走。
>
> 新写法两步，**顺序不能反**：
>
> 1. **先说破** —— 诊断词 ＋ 重新定义，落在幕末。
>    用观察式，不用建议式：讲「会怎样」，不讲「该怎样」。
>    造句的三个模子见[说破层规范](../说破层规范.md) §三。
> 2. **再拉远** —— 说破之后**必须落回一个景**收尾，不许停在判断句上。
>    《陶庵梦忆》第一期说完「痴不是傻，是明知换不来什么还是要去一趟」，
>    最后三句回到幕一开头那场雪。
>
> 护栏三条：**一期一个诊断词**（中间不反复点）；**不喊口号、不用感叹号问句**
> （文本闸照旧，机器会拦）；**说破是确认不是告知** ——
> 听众听到第三则还没自己连起来，说破就落空了，那是选段没选对，不是说破写坏了。
>
> **已出片的《方丈记》《枕草子》是旧写法，不回改。**

## 六、前后连贯

一期二十分钟，听众多半在中途睡着。**连贯不是给追情节的人做的，
是给醒着的人做的** —— 让他任何时候醒过来都知道自己在哪儿。

### 幕与幕之间

- **上一幕收在收得住的地方**，下一幕第一句直接接住。
  《方丈记》幕一收在「但他没有搬走」，幕二第一句是「他不是一开始就住在山里的」
- **不做悬念**。这是助眠档，听众多半在上一期就睡着了；
  下一期是给醒着听完的人准备的，不是给追更的人准备的

### 跨期（上 → 下）

切点落在**内容本来就收口的地方**，不是字数正好的地方。
《方丈记》切在幕二末尾（来路交代完了），《枕草子》切在夏秋之间（一年过了一半）。

### 回扣

**末幕原样重现首幕的几处细节**，给醒着听完的人合上一个圈。
《方丈记》回扣了四处：泉眼、蕨草上挪的光、屋顶很低、河水开篇。

回扣要**原样重现**，不要改写 —— 改了就认不出是同一处。

### 一条贯穿的线

整本要有一两句反复出现的话，当骨架。
《方丈记》是「河水一直在流」；《枕草子》是「她只写事，不写心情」和
四季那一段（春是拂晓 / 夏是夜 / 秋是黄昏 / 冬是清早，拆成四幕的开头）。

## 七、幕表与配额

| | |
|---|---|
| 语速 | **226 字/分**（含停顿，整幕实测，不是样章外推） |
| 单期 | **20 分钟上下 ≈ 4500 字** |
| 结构 | **四幕两期**，每期两幕 |
| 每幕 | ≈ 2300 字 |

**配额是用来核片长的，不是用来凑字数的。**
《方丈记》写下来 9049 字，比估的 9800 少 750，两期时长仍达标就没补 ——
硬凑就是注水，而注水正好毁掉这条线最值钱的东西（慢、留白、不赶）。

反过来也一样：**够不够长看时长，不看字数**。

## 八、流程：先出样章，再补齐

**每本书都先写一份 600–950 字的样章，出试听件，确认调性，再动剩下的。**

现在改比写完再改便宜得多 —— 这跟当初调音色是同一个道理，
《方丈记》的六轮音色和三轮停顿都是这么省下来的。

```
选书（书目文档给的判断）
  → 幕表（结构 + 配额 + 这一本特有的约束）
  → 样章（600–950 字）→ 试听 → 确认调性
  → 补齐四幕 → 整期音频 → 画面 → 出片
```

样章要**带上这一本最难的那一段**，不是挑好写的写。
枕草子的样章里放了列举体和换气句，因为那正是这一本会翻车的地方。

## 九、每本书都不一样的那部分

规范管的是共通的。**每本书自己的约束写在各期的 `幕表.md` 里**，
因为它们往往是相反的：

| | 方丈记 | 枕草子 |
|---|---|---|
| 画面可承载度 | ★★☆☆☆ 最低 | ★★★★★ 最高 |
| 形态 | 一篇长文，独白 | 约 300 段短章，列举体 |
| 结构 | **画面锁死稿件，只能倒叙** | 按季串编 |
| 难点 | 内容太薄，要往厚里写 | 内容太散，**连读三段就腻** |
| 画面 | 全程锁一景 | 远景与近景轮换 |

写新书之前，先去书目文档看那一本的「改编注意」——
那一句往往就是这本书的全部难点。

## 十、写完跑一遍机器检查

```
npx tsx src/zhiyu-check.ts --ep <书>
```

查得了的：叹号问号、编辑记号、段长、⏸ 密度、字数与预计时长、跨幕重复。

**查不了的**（只能人听）：调子飘没飘、腻不腻、共鸣接不接得上、
换气句是不是恰好落在你要喘气的地方。所以样章那一步不能省。

## 十一、人味儿：这一条比上面十条加起来都重要

> 2026-08-20 加。起因是《已读不回》——形式全对、字数够、停顿对、
> 文本闸一条不犯，**听完不知道说了啥**。

机器能查的是「有没有犯规」，查不了的是「值不值得听」。
这一节讲后者。判据都是可以逐句对照的，不是感觉。

### 先说什么是 AI 味儿

不是文笔差。AI 味儿的稿子往往**文笔挺好**，问题在别处：

| 症状 | 长什么样 | 《已读不回》里的例子 |
|---|---|---|
| **精确的空洞** | 细节密度很高，但每个细节都可替换 | 「下午三点十二分」「一件需要对方点头的事」—— 时间精确到分钟，内容是占位符。谁发的、发给谁、什么事，一个都没有 |
| **中心思想是个名词** | 落点是一个术语／概念，不是一个发现 | 「能拿走的只有一样：那四十九分钟里发生的事情有名字」—— 稿子自己承认了，知道名字不改变任何事 |
| **通用模板段** | 整段可以原封不动搬到别的选题 | 「在一个只有几十人的群体里…被排斥就是断粮」—— 这段搬到嫉妒、社恐、朋友圈焦虑都成立，它不是为这一期写的 |
| **链条太顺** | 每段恰好接上上一段，没有一处卡壳 | 现象→命名→进化→代价→归位，五段严丝合缝，没有一句「但这么说也不全对」 |
| **对称** | 三条一组、正反对照、首尾呼应，工整得不像真事 | 首尾同一句引文，中间一句，三处均分 |
| **没有一句只有你会说** | 通篇找不到一句带个人指纹的话 | —— |

**共同点：形式上每一条规范都满足了，但没有一处是「非这么写不可」的。**
这正是照着规范写、而不是照着一件真事写，会得到的东西。

### 四条硬判据

写完，拿这四条逐条问自己。**答不上来就是没写好，不是风格问题。**

**① 有没有一个具体到不能替换的人和事。**

```
✗ 一件需要对方点头的事
✓ 问领导下周三能不能调休，因为孩子那天要体检
```

抽象是为了「普遍适用」，可听众记住的从来是具体的那一个。
**越具体越普遍** —— 你写「孩子体检」，没孩子的人想到的是自己那件事；
你写「需要对方点头的事」，谁也想不到任何事。

**② 听众能带走什么，一句话说清。**

带得走的是**一个动作**或**一个新的看法**，不是一个名词。

```
✗ 这件事叫「镜中我」，1902 年就有人写下来了
✓ 你在等回复的时候会自己填空白，而且填的通常不是最好的那种可能。
   可以试着填一条：对面那个人，很可能也在斟酌怎么说才不显得敷衍
```

判断方法：**把落点那句念给一个没听过的人，他会不会说「哦，那我下次可以试试」。**
他要是只说「哦，原来叫这个」，那这一期白做。

**③ 有没有一处你自己也没想通，并且说出来了。**

真人讲一件想明白的事，中间一定有一处是绕回来的、或者承认「这儿我也说不准」。
一篇从头顺到尾的稿子，听感就是「有人在给我讲解」，不是「有人在跟我说话」。

这一处不用长，一两句就够，但**必须是真的没想通**，不能是装出来的犹豫。

**④ 有没有一句只可能出自这个人。**

一句就行。它可以是个偏门的观察、一个不合群的判断、一句自嘲。
通篇找不出这样一句，说明写的时候没有人在场。

### 发现要从材料里长出来，不要外加

《已读不回》最好的那句已经在稿子里了：

> 「也就是说，对面那个人，很可能同时在做一模一样的推算。」

它现在只是个过场，**本该是落点**。而且它能接上前面「人填空白时填进去的通常不是
最好的那种可能」——把「他也在斟酌」填进去，就是一个当场能用的动作。

**这不是我外加一个道理，是把稿子自己的材料重新排了个序。**
下次觉得「没有中心思想」，先别急着加新东西：
通常那句话已经写出来了，只是埋在中间当过场用了。

### 引经据典是解释层，不是落点

心理洞察线要引古典文本，治愈线要引原著。**但引句只负责解释，不负责收尾。**

引一句古文然后收尾，听感是「作者引完就撤了」。
落点必须是**你自己的那句话**，引句只能给它垫台阶。

### 这一条机器基本查不了

`zhiyu-check.ts` 加了两个小检查（占位词、跨期重复整段），
但那两个只拦得住最粗的。**真正的判断只能人做**，方法是：

1. 稿子放一天再读（当天读会自动脑补自己想写的意思）
2. 只念落点那三句给别人听，问他「所以呢」
3. 挑一段随机搬到别的选题下面，看看还成不成立 —— 成立的就是模板段

## 十二、简介栏（2026-08-24 加，跨线共用）

**简介栏的写法立在另外三条线的文档里**，这条线照抄同一套 ——
规范正文见 [`禅佛典向_小故事大道理_书目与稿件.md`](禅佛典向_小故事大道理_书目与稿件.md)
的「简介栏规范与人称尺度」一节（心理洞察向、禅佛典旁白两份里也各有一份，正文一样，只是范例换成本线的）。

四段，缺一段就不算写完：

1. **第一句是翻转句，不是概括。** 推荐流折叠位只露第一句，「本期讲……」在那个位置等于放弃
2. **第二段给一个具体到身体或物件的现象**，一两句
3. **写一句「这期不做什么」**（「不急着给方法」「不劝你珍惜」）——先卸掉「又要被教育了」的戒备
4. **结尾给使用场景**，最好是情绪发生的当下，不只是睡前／通勤

两条跟这条线直接相关的：

- **送别句（「愿……」）只进简介栏，不进音频。** 这条线的收尾是话说完了就停，
  后面挂一句「愿你……」，静音的质感当场垮掉
- **软方向句**（「这一刻，可能会宽一点」）**全篇最多一次**，且在收束段。
  给方向不给保证，跟「不承诺会好起来」不冲突
