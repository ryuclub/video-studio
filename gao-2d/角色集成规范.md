# 主讲人角色 — 集成规范

高总这个 2D 角色**怎么变成 B 层帧序列**。角色本身怎么渲（五官、表情、点头摇头、踩过的坑）
在 `README.md`；一条片子怎么写怎么合成在《英文频道出片方案》。这份夹在两者中间，只管帧序列。

**一句话**：`node gao-2d/出帧.mjs` → `projects/高总/_帧/<组>/00000.png…`，
1080×1920，**全频道共用，出一次到处用**，不进 git。

---

## 1. 这个频道用不到什么

素材里的**两套走路和侧面站立都用不上**。

主讲人在这个频道里的角色是「锚点」，不是「演员」。他每次出场 2.5–4 秒，站在那儿说话，
观众需要的是「有个人在跟我讲话」这个信号，不是表演。走路会把注意力从数字上拉走，
而且竖屏构图里横向移动很别扭。

侧面素材留着，以后做 T2（两国对比）那类需要「转向另一边」的篇目可能用得上。
⚠ 侧面姿势**渲不了点头摇头** —— 头部层只对正面有效，传侧面直接抛错（README §四之二）。

## 2. 七组帧序列

| 组 | 姿势 | 景别 | 动作 | 帧数 | 实渲 | 用在哪 |
|---|---|---|---|---|---|---|
| `ms_talk` | 正面站立 | MS | 说话 | 96 | 8 | 主力，主讲人开口的所有时刻 |
| `mcu_talk` | 正面站立 | MCU | 说话 | 96 | 7 | 转折句收紧一档 |
| `ms_idle` | 正面站立 | MS | 待机（眼珠微动＋眨眼） | 150 | 76 | 结尾抛问题、听感留白 |
| `mcu_nod` | 正面站立 | MCU | 点头 | 48 | 24 | 转折句，一条最多一次 |
| `ms_gesture` | 正面站立-抬单手 | MS | 说话 | 96 | 8 | 全片最多一次 |
| **`ms_doubt`** | 正面站立 | MS | 说话 ＋ **斜看半睁** | 96 | 18 | **反面事实句**（To be fair…）—— 一本正经说反话的脸。一条最多一次 |
| **`ms_read`** | 正面站立 | MS | 说话 ＋ **往下看** | 96 | 19 | 念档案、报数字 —— 跟 DOC 层切换时视线是连着的 |

**后两组是 2026-09-09 加的。** 表情系统一直都在（嘴型、眨眼、待机的眼珠微动），
但说话组全程正视 —— `画.mjs` 支持的 `眼x` / `眼y` / 半睁一个都没用起来。
组表里加一个 `眼: { x, y, 眨底 }` 就够，`排()` 会应用到整组。

⚠ **眼神要在首尾各 6 帧渐入渐出。** 循环首尾必须回到中性，
不然每转一圈眼神跳一下 —— 跟 §4「循环接不接得上」是同一条约束。
`眨底` 跟眨眼动画**取大的**：眨到一半时不能被半睁的底值拉回去。

⚠ **带 `punch` 或 `lower` 的块只能用 MS 系**（方案 §7.3）：
MCU 特写的脸占到 y1150，数据条在 920–1120、punch 中心在 1020，
字必然盖住嘴或眼睛。所以 MS 系可用的只有 `ms_talk` / `ms_gesture` / `ms_doubt` / `ms_read` 四组轮换。

「实渲」是真正过 resvg 的张数 —— 循环里不同的画面只有那么几张（口型 × 眨眼几档），
其余按参数做 key 去重，直接文件拷贝。**486 帧实际只渲 123 张。**

`ms_idle` 是个例外：150 帧渲了 76 张。眼珠微动是逐帧变的正弦值，两帧同值的机会只有一半 ——
待机组要想再省，得把正弦量化成几档。现在不值当，出一次就完了。

```bash
node gao-2d/出帧.mjs            # 全部五组
node gao-2d/出帧.mjs ms_talk    # 只出一组
node gao-2d/出帧.mjs --底 dark  # 换黑底（默认纸底，理由见 §3）
node gao-2d/出帧.mjs --验       # 另出接缝图 projects/高总/_图/帧-接缝.png
```

⚠ **`ms_gesture` 是硬切换姿势，不是抬手的过程。** 2D 分层画不出抬手 —— 手臂是整条 path，
中间态得美术画。所以那一下是切进去的，只能放在句子之间。

## 3. 帧规格

| 项 | 要求 |
|---|---|
| 尺寸 | **1080 × 1920**，与成片一致 |
| 格式 | PNG，`00000.png` 起，五位补零连续编号 |
| 帧率 | 30fps |
| 背景 | **纯色不透明**，`#f4f4f2`（纸底） |
| 循环 | **首尾必须无缝接上** |

**背景为什么是纸底不是黑底**：方案说角色用数字卡的底色（`#111111` 或 `#ffffff`）。
实渲之后只剩一个选择 —— 高总穿的是近黑的外套，压在 `#111111` 上**人和底融成一块、只剩一圈描边**。
不报错，就是难看。纸底 `#f4f4f2` 顺带跟 DOC 层压过的纸底同色，两层切过去不跳。
黑底仍留着（`--底 dark`），换角色或换服色时再试。

**为什么不能配实拍背景**：一配上，他就脱离字卡的世界，整条片子会散成两半（方案 §6.5）。

---

## 4. 循环接不接得上

`build.mjs` 的 B 层是 `loop: true` 循环填满时长的，**首尾接不上会每隔几秒抖一下**。

做法：每组的第 0 帧和最后两帧都是**嘴闭、眼睁、不动头**的同一张，眨眼和口型全排在中间。
待机组的眼珠微动走正弦、点头走半个正弦，两端都自然回到 0。

⚠ **这一条机器查不了。** `--验` 出的那张接缝图（每组前三帧 ｜ 后三帧并排）是用来拿眼睛看的。

---

## 5. 景别怎么切

角色是 SVG，**动 viewBox 就是无损变焦**。**按脸高算，不按整体墨高** —— 抬单手那两张
手举过头，墨高里含着手，按它算一换姿势人就矮一截。系数与余量见方案 §6.2，实现是
`出帧.mjs` 的 `取景()`（`export` 出来的，别在别处再写一份）。

⚠ 裁切**只能改顶层 viewBox**，套嵌套 `<svg>` 会让 resvg panic（README §六）。

## 6. 口型与表情

**口型**：四种嘴（闭 / 小 / 大 / 扁）按一张固定谱轮换，每种停 3–5 帧。
不做音素级对口型 —— 景别不大、出场短，观众不会去核对嘴形。**首尾一定是闭**，循环才接得上。

**眨眼**：四帧一次（0.45 → 1 → 1 → 0.5），约 0.13 秒。位置由各组自己钉，
**故意不规律** —— 规律眨眼会显得机械。

**表情**：只用两个。中性占九成；转折那一次可以用眼睑压一点。
**不要笑脸** —— 这个频道的语气建立在「说话的人一点都不觉得好笑」上，角色一笑，讽刺就塌了。

## 7. 接进管线

```bash
node gao-2d/出帧.mjs                          # 帧序列（一次性）
node gao-2d/build.mjs uk_potholes --check     # 八项自检，第 6 项会报哪块缺素材
node gao-2d/build.mjs uk_potholes             # 全量合成
node gao-2d/build.mjs uk_potholes --only 7    # 只重建第 7 块
```

时间表里 B 层写**组名**（`frames: 'ms_talk'`），不写路径 —— 帧序列全频道共用。

---

## 8. 一次性的事

这五组是**全频道复用**的，不是每条视频重做。后续新片只在需要新动作时才补导。
所以第一次出的时候把帧数给足、循环接顺，比赶时间重要。

**美术重导 SVG 之后必跑 `node gao-2d/查.mjs`** —— 五官和对位全按 path 下标算，
重导一次下标全变**且不报错**（README §五）。查完再重出帧。
