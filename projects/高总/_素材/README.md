# C 层共用素材库

**全频道共用，不进 git**（跟 `_帧/` 一样 —— 删了还能重新找回来，所以不进；判据见仓库《交付包与 projects 留什么》）。

## 为什么有这一层

DOC 层录屏跟本期数据绑死，攒不了 —— ALARM 2026 那两页只有《英国路面坑洞》要用。
但 C 层通用空镜不一样：**路面、车流、街景、排队、货架，多期反复要**。
一期一份等于每期重新找一次料，而 C 层每期预算 60 min，是单条里第二贵的素材工序
（方案 §17 工时表）。方案末尾那句「可复用资产是唯一的降本手段」漏了 C 层，这一层是补上它。

## 怎么引用

时间表里 `clip` 以 `_素材/` 开头就走这儿，其余写法仍然相对本条的工作目录：

```js
{ id: 6, layer: 'C', clip: '_素材/road/asphalt_crew_01.mp4', in: 1.0 }   // 共用
{ id: 4, layer: 'DOC', clip: 'media/alarm2026_potholes.mp4', in: 0 }     // 本期专用
```

路径解析在 `gao-2d/自检.mjs` 的 `素材路径()` —— **只有那一处**，`build.mjs` 和汇总页都 import 它。

## 存什么

**存原件，不存调好色的。** §6.5 那道统一调色（`hue=s=0.18, eq=contrast=1.15…`）是出片时过的滤镜，
存调色后的会调两遍，画面发灰发闷。

**入库前必须过 §6.4 素材红线**，三条一条都不能破：

| 不要 | 为什么 |
|---|---|
| 可辨识的真人面孔 | 肖像权；图库里大量素材踩这条，是最常见的退货原因 |
| 任何新闻画面（含截图） | 版权 ＋ 频道定位不是新闻频道 |
| 商业品牌标识 | 暗示关联；货架、店招、车标都要看清楚 |

拍手、拍背影、拍脚、拍物件都安全。人多的街景要么远到认不出脸，要么别用。

## 目录

按题材域分，不按国家分 —— 一段柏油路的特写哪国都能用，按国家分会重复攒。
真正有国别的（地标、街景、路牌）放 `street/` 底下按国家二级分。

| 目录 | 装什么 |
|---|---|
| `road/` | 路面、坑洞、施工、沥青、车流、封路牌 |
| `civic/` | 政府建筑外观、市政厅、法院、议会、办公楼走廊 |
| `queue/` | 排队、窗口、叫号屏、候诊厅、空椅子 |
| `retail/` | 货架、锁柜、自助结账、收银台、价签 |
| `housing/` | 住宅街区、工地、脚手架、空置房、门牌 |
| `paper/` | 纸堆、表格、盖章、信箱、账单、文件柜 |
| `street/<国>/` | 城市街景、天际线、地标外观（有国别的放这儿） |
| `hands/` | 签字、刷卡、按按钮、翻页 —— 不露脸，最安全的一类 |

## 命名

`<主题>_<序号>.mp4`，全小写下划线，例：`asphalt_crew_01.mp4`、`self_checkout_03.mp4`。
序号留两位，同一主题攒多条时好挑。**别在文件名里写国家**（除 `street/`），
攒着攒着就会发现同一段路谁都能用。

来源和授权记在同目录的 `来源.md` 里，一行一条：文件名、图库、许可、下载日期。
这条不是形式主义 —— 出片时置顶评论要放来源，法务那栏也要填（方案 §14）。
