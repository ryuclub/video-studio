## 一、它跟段子线是什么关系

**同一条管线**（`joke-video/src/*`），不是新起一条。角色、场景、漫符是外挂的
（`horse/`，纯 `.mjs`，能独立跑摆拍工具），出片链完全复用。

复用的部分一个字都没改缺省值：

| 复用的 | 在哪 |
|---|---|
| 稿件 → 时间轴 | `beats/typeA.ts`（对话反转那套，单角色独白照样成立 —— 它只认「有且只有一句 punch」，不数人头） |

| TTS ＋ 选角 ＋ 变声 | `tts.ts` / `cast.ts` |

## 二、链路

**顺序是有讲究的：发布文案排在出片之前，不是之后。**

```bash
cd joke-video

npm run laoma:check  -- jokes/laoma-001.json   # ① 稿件体检（见 §六）
npm run plan         -- jokes/laoma-001.json   # ② 出片思路：生成方案骨架，人填 §一 和 §四
npm run laoma:publish -- jokes/laoma-001.json  # ③ 发布文案 ← **在这儿就定下中心思想了**
npm run lines        -- jokes/laoma-001.json   # ④ 看音色与时间轴
npm run voice        -- jokes/laoma-001.json   # ⑤ TTS
npm run align        -- jokes/laoma-001.json   # ⑥ 回填真实时长
npm run still        -- jokes/laoma-001.json 6 18 27   # ⑦ 抽几帧看画面
npm run build        -- jokes/laoma-001.json   # ⑧ 出片（带声音）
npm run laoma:publish -- jokes/laoma-001.json  # ⑨ 重跑一次，片长换成实测
npm run laoma:check  -- jokes/laoma-001.json --commit   # ⑩ 数字入账（见 §六）
```

⑪ **定发布日**：出片的时候目录叫 `projects/老马/段子/_待发/未排期_段子_<栏目>_<稿件内容>_<天数号>/`
（成片、封面、方案、发布文案都在里面）。定了日子把它 `mv` 成
`<日期>_2100JST_段子_<栏目>_<稿件内容>_<天数号>/`，补一个 `publish.json`，再 `npm run laoma:schedule` 扫一遍。
命名和字段见 [horse/SCHEDULE.md](horse/SCHEDULE.md)。

⚠ **成品目录 2026-08-23 搬过家**：从 `projects/段子与儿童故事/<日期>_<id>/`
搬到了 `projects/老马/段子/{_待发,_已发}/`，**成片也改名了**（`out.mp4` / `thumb.png` /
`audio.wav`）。老马从「段子与儿童故事」那张汇总页里分出来，自己一张
（`projects/老马/index.html`）。**排期不拦出片** —— 它管发布那头，跟 ①⑤⑧ 那道稿件闸是两回事。

⚠ **天数号 2026-08-23 起改成跳号 2–4 天**（原来是一稿一天 +1）。
`laoma-001`–`009` 是 +1 时代的，收尾卡已经烧进成片，不回改；**010 起按新的走**。

### ⚠ ①不是「记得跑」，⑤和⑧会自动跑它

**2026-08-22 之前 `laoma-check` 只是个独立命令**，谁忘了跑，一条带硬伤的稿子
就能一路 voice → align → build 出片。而这个文件自己顶上抄着心理线那句
「文档拦不住人，体检才拦得住」—— 反过来一样成立：**要人记得跑的体检，也拦不住人。**

现在 `voice`（⑤）和 `build`（⑧）前面各有一道闸，有硬伤直接停，
`--anyway` 放行（跟「方案.md 没填完」那道闸同一个开关）。

- 拦 `voice`：稿子有硬伤就得改，改完配音全作废，先拦住省一轮 TTS
- 拦 `build`：四分钟的渲染不值得为一条已知有硬伤的稿子花
- **`draft` / `still` / `layout` 不拦** —— 那几个是看画面的工具，
  稿子还在改的时候正该用它们，拦了等于逼人先把文字弄干净才能看构图
- **只对老马线生效**（按 `rig === 'horse'` 判），段子和《一页故事》一个字都没变

⑩ 是新的：**出片之后**把这一条的数字写进 `horse/used-numbers.json`，
下一条撞了同一个数体检会报。放在最后是因为体检本身只读 ——
一条稿子定稿前会跑很多遍，每跑一遍就入账的话，它第二次跑就撞自己了。

### 为什么 ③ 在出片之前

`plan.ts` 里早就写着「**发布文案要在写稿阶段填，不是成片后补**」：
标题、封面大字、收尾金句是**同一个钩子的三种长度**，分开想必然对不齐 ——
等片子渲完再回头凑标题，要么标题跟金句打架，要么发现封面大字根本没法从标题里截。

更要紧的一条：填 §四 的时候就得把「**这一条的中心思想是什么**」想清楚。
想不清楚的稿子，渲完片子还是想不清楚，只是多花了一次渲染。

**但这条主张原来做不到** —— `yiye-publish.ts` 硬要成片才肯跑（为了量片长），
于是想提前看一眼中心思想，得先渲一遍。现在没有 mp4 就按时间轴估，
并在文档里标明「片长是估的」；⑨ 再跑一次换成实测。

### ⚠ `draft` 是无声的，**这不是 bug**

```ts
const withVoice = cmd === 'build';
const { raw, tracks } = withVoice ? loadVoices(cfg) : { raw: new Map(), ... };
```

`draft` 按设计不载配音，它是「只看画面」的快版。**要听声音必须 `build`。**

坑在于：`align` 已经把真实 `dur` 写回 json 了，所以 `draft` 出来的片长是对的，
只有音轨是空的 —— 时长对得上，人就不会怀疑音频。第一次出片就栽在这儿。

`build` 会拦「方案.md 没填完」，填完再出；急着看加 `--anyway`。

## 三、音色：老马（定稿）

```
云希（zh-CN-YunxiNeural）· rate −6% · pitch 1.20 / formant 1.20 · 不加音染
```

参数是**在音色实验室的地图上拖出来的**（`cd voice-clone && npm run lab` → localhost:5178），
不是算出来的。**pitch 和 formant 同幅**，跟治愈线「夜读」的 0.83/0.83 是同一个手法、
反方向：等比移动＝整个人变小，而不是「捏着嗓子往高了说」。

判据只有一个：**像「讲」不像「念」。** 落选的五条和理由写在 `cast.ts` 的注释里，
一句话版本：

- **云扬直接出局** —— 新闻播报底，F0 范围 246Hz 最宽，那不是「有感情」是播报腔
- **丁戊（云健细声）落选不是不够细，是不够平** —— 云健自带解说腔起伏，
  抬高之后那份起伏跟着放大，听感是「一本正经地急」，像在演
- 定稿这条 F0 188Hz 全组最高、标准差还是 6Hz 跟本色一样：**又高又平**

**全季一条，不为单条新开。**

## 四、画面：跟段子线不一样的八处

### 1. 角色 rig：`horse`

原稿 `horse/horse_only.svg` 是画好的，rig 只替换四处分组的 transform
（`pupil-l/r` / `mouth-*` / `head` / `face`）。**代码这层改不了长相，要改先改 svg。**

- **口型**从配音包络来（`frameEnvelope` → `mouthFrom`），三态 → `null / "I" / "A"`。
  **没有音节表，也不需要**：音节表对齐的是文本，包络对齐的是实际发出来的声音。
- **眼睛是这条线唯一的表演**（人设不做表情，脸上不能有戏，出口只有眼珠）：

  | | |
  |---|---|
  | 说话时 | **定住**，落在正前方 |
  | 停顿时 | **沿一个圈走整一圈，再回到中心** —— 那是「在想」 |
  | 稿子点了表情 | 按表情定住，**说完就松开**（见下） |

  第一版是「低频漂移 ＋ 每隔几秒往右扫一下」。那读起来不是思考，是**飘忽**：
  视线没有目的地，一直小幅乱挪，看久了像走神或者心虚。
  **想是有方向的** —— 一整圈有始有终：推出去、绕一周、收回来，
  正好占满一次停顿，停顿结束眼睛回到正前方接着说话。

  半径按 sin 起落（首尾各 14%），所以起点终点都在中心，不会「啪」地跳到圈上。
  **短于 0.35 秒的停顿不转** —— 0.3 秒里转一圈是抽搐不是思考。
  实测这条片子六次停顿里有两次太短（0.15 / 0.30 秒），跳过了。

  ⚠ 转圈要知道「这次停顿从哪到哪」，rig 只看得到当前时刻，
  所以由渲染层按时间轴算好 `think`（0..1）递进来。
  **边界取配音波形真正在响的区间**（`start + dur`），不是段的 end ——
  段的 end 含 padAfter，按它算会把落点前那半秒吃掉，而那正是最该「在想」的地方。
- **渲染高度锁死 1120**（`horse/scenes.mjs` 的参考人高 U）。场景里所有家具都按
  「距地多少个人高」摆的，改这个数等于改整套场景比例。

⚠ **2026-08-21：把角色的实心色块改成了真的实心。** 原稿是 Illustrator 导出的，
几个大色块带着 `opacity:0.94 / 0.95 / 0.9 / 0.96 / 0.88`（跟 `enable-background:new` 一起，
是导出残留不是画法）。后果是**场景会从他身上透出来** —— 6% 听着可以忽略，
但透出来的是一条**连续笔直的边**，人眼对连续边极其敏感。

稿 6 用 `rental-living` 才炸出来：那个落地灯的杆子在 x≈330，正穿过他的脸
（角色框 114–465）。实测脸的底色 (141,132,123)，杆子那一列 (131,122,114) ——
**差 10 级，4%**，但它是一条从额头贯到胸口的直线，第一眼就看见。
前五条不是没有，只是撞上的都是低对比的横线（004 的台面带就在他身上淡淡地压着一道）。

改的是 `.st15 / .st59 / .st39 / .st60 / .st169` 五条**有填充色**的类，去掉 opacity。
**描边类（`fill:none`）的 opacity 一个都没碰** —— 那是笔触浓淡，是画风。
代价是角色整体深了约 4 级（不再跟背景混色），肉眼看不出来。
⚠ 已出片的 001–005 是带着 0.94 渲的，**不回改**（成片不重出）。

⚠ **`horse/horse-pose.mjs` 里有同样的四处替换**（给摆拍工具用，纯 .mjs 导不进 TS）。
三个常量（HEAD_CX / DEPTH / 口型 id）两边必须一致，**改一处记得改另一处**。

### 2 之二、场景摆件（2026-08-23 加）

桌上按**天数号**摆一两件小东西（`horse/dressing.mjs`）：笔 / 纸 / 杯子 / 电脑 / 文件夹 / 手机。
同一个场景连发几条，摆的东西不一样 —— 补的是 `horse_standup_plan` §六之二 里
「场景重复」那个洞（换 `seed` 只是笔触重洗，桌上还是空的）。

⚠ **稿件的 `object` 永远不摆**，硬闸在代码里（`skip`）。那件东西是台词点名的，
摆进画面就是 §五 禁的「图解台词」。判据：**删掉这件摆件，有没有哪句台词变得不好懂？**

⚠ **摆件跟场景画在同一层**，不单独提一层做视差 —— 提出来的话桌上的杯子会跟桌子分家。

⚠ **台面是斜的，摆件得跟着斜。** `scenes.mjs` 里桌子画成梯形（近大远小），
按固定 y 摆的话靠右那件浮空二十多像素，一眼看出是贴上去的。
`SURFACE` 里每个场景的 y 是按 x 插值的函数，端点抄自各场景的桌面四边形 ——
**改了 `scenes.mjs` 的桌子，这儿要跟着改。**

没台面的场景（电梯、地铁、街道、候诊区）池子是空的，不摆。

### 2. 场景：外挂 `horse/scenes.mjs`

10 个手绘线条场景，直接进 `SCENES`（现在共 20 个），跟剪纸风那 10 个并存。
两套画风并存是有意的 —— 观众一眼分得出是哪条线。

**地平线不一样**：这边 1290，那边 1500。靠 `Layers.ground` 钩子接过来。
不接的话马会悬在半空，**而且不报错**（layout 只对「没实现 ground()」的场景报警）。

#### 竖幅构图：地平线不能动，要让就让上边

竖屏 30 秒的片子只有一个构图，它得一次对到底。这一条的实测数据（`f20`，说第五句时）：

| | 改前 | 改后 |
|---|---|---|
| 有内容的行 | 62 → 1510 | **230** → 1509 |
| 内容竖直中点 | 786 | **870** |
| 离有效画幅中点 828 | −42px（偏上） | **+42px（偏下）** |
| 马头顶上方的空墙 | 318px | **150px** |

**「下面空了一大块」是错觉，那块是平台的。** 地平线在 1500，画幅下面还剩 420px
看着确实空 —— 但 `cover.ts` 的安全区辅助线写着「底部 20% 昵称文案遮挡」，也就是
y>1536 归平台。实测 1536 以下的墨量是 **45 个像素**（地平线那根线的余尾），
等于 0。**脚正好落在遮挡带上沿往上 36px** —— 这不是巧合出来的余量，是它该在的地方。

所以**整体下移是不能做的**：真按内容中点对齐画幅中点（下移 174px），
脚会落到 1674，埋进文案条里 138px。上传之后马是站在自己的标题里的。

**真正挤的是右上角，不是上边。** 窗户原来从 y=62 一路顶出画幅，
而同一条上边界的左半边、马头顶上是 318px 全空的墙 —— 左空右满，
读出来就是「上面挤下面空」。**把窗顶从 up(1.25) 压到 up(1.10)**（矮 168px）之后
右上角让出来，两边留白对得上，内容中点顺带落到有效画幅中点稍偏下 ——
竖屏里偏下一点是对的，偏上会飘。

⚠ 压的是窗，不是地平线。`GROUND` 是整套场景的比例地基（家具全按 `up(f)` 摆），
动它等于动全部十个场景的取景，**而且底部那 36px 的余量会一起没**。

#### ⚠ 换新场景之前，先量一遍收尾卡那一片地

**画面上边那一带不是空的，收尾卡住在那儿。** 钩子字幕由 `render.ts` 画死在 **y=250**，
字号 52、居中、无衬底，「老马的第 1854 天」实测**横跨 x 324–756、墨迹 y 268–313**。
场景里任何靠上的元素只要落进这块，收尾那两秒半就废了 ——
而且它**只在最后两秒露出来**，逐镜看静帧看不见，非得渲完整条才发现。

003 是渲出来才撞上的（§六之二：为躲平台 UI 把楼层屏往下压 112px，藏青的字压在深色屏上直接看不见）。
008 换 `hospital` 时改成了**渲之前先量**：那块叫号屏原来 470×230、y 89–319，
跟钩子字幕正好叠在一起。压到 470×152（底 y≈241）之后让开 27px，两行屏字跟着缩一档。

选场景 / 改场景的时候按这个顺序过一遍：

1. 这个场景**最靠上的那个元素**底边在哪？低于 y≈250 就得让
2. 让的是**高度不是位置** —— 靠上的元素通常是「挂在墙上」的（屏、白板、挂历），
   往下挪就撞脸，往右挪就占掉字幕那半幅
3. 顺带看一眼**封面标题**：新排版首行基线 0.22（墨迹顶边 y≈248），
   跟收尾卡是同一条上界。让开收尾卡，就一起让开了标题

⚠ 这条**跟「让场景替台词说话」不矛盾**。008 的叫号屏是落点指着的东西，它必须清楚、
必须一直在画面上 —— 让开收尾卡不是把它挪走，是把它**压矮**。

### 3. 字幕：`sideText`，跟 `dialogueStrip` 是两套

> **2026-08-23 换了样式**（字幕规范 [horse/SUBTITLE_SPEC.md](horse/SUBTITLE_SPEC.md)）：
> 得意黑、奶白＋深墨、铺垫 80 / 落点 100 琥珀、**长句折行**（均分不贪心）。
> 位置没动，仍旧在上方跟脸平齐。**001–010 不重出**，只对新片生效。
>
> ⚠ **字体要显式喂给 resvg**（`config.ts` 的 `FONT_FILES`），**而且 worker 也要**。
> 漏了不报错：静帧上字体对、成片里回退成雅黑 —— 因为静帧走主线程、出片走 worker 池，
> 两边各有一份 resvg 配置。
>
> ⚠ **字族名在 `FONT_LAOMA` 里用单引号**。写双引号会把 SVG 的 `font-family="…"`
> 属性提前截断，resvg 报的是「expected space not 'S'」，跟字体一点关系都没有。

| | dialogueStrip（段子/一页故事） | sideText（老马） |
|---|---|---|
| 衬底 | 米白纸片＋手撕边＋投影 | **没有** |
| 位置 | 底部居中 | **角色侧边** |
| 入场 | 弹入 | **没有，直接出现** |
| 断行 | 按宽度折 | **按逗号断，一小句一行** |

段子是「两个角色在演，字幕是台词条」，纸片衬底把台词托出来。
老马是**一个人在讲**、画面和镜头都不动 —— 这时候字幕不是配角，
它是观众的主要落点。给它加衬底、加动效，等于给主角化了妆再让他别动。

**字号按最长的那一小句自适应**（52 起，每次 −2，下限 34）。写死字号的话，
只要有一句偏长就会被折成两行，而按逗号断行的全部意义就是「一小句一行」，
折了等于没断。宁可全篇小一号，也不要有一句破相。

配置：`"subtitleStyle": "side"`。收尾卡跟着一起去掉色块。

#### 柔光描边：**没有衬底，但字自己带一圈纸色**

**2026-08-21 加的，而且走了一次弯路，弯路本身要记下来。**

先做的是**外投影**（同形副本位移 3/4px、30% 深墨）。方向错了 —— 投影解决的是
「把字抬起来」，而这一层真正要解决的是「**别被背后的线条咬**」：
005 的字全排在白板上、背后四行潦草横线，007 的字压着窗框格子和显示器边。
深色影子跟那些深色线是同一类干扰，非但不挡，还添乱；而且它糊在深墨字周围，
等于把字变粗变脏。

**正解在治愈线，那边早就把这条路走完了**（`src/xinli-text.ts` 的文字层）：

| | 治愈线（ASS） | 老马（SVG） |
|---|---|---|
| 描边色 | `OutlineColour = 纸色` | `ink(P.paper)` |
| 宽度 | `Outline = 3`（字号 44） | `stroke-width = 字号 × 0.136` |
| 糊 | `lur2.4` | **没有**，硬边 |
| 投影 | `Shadow = 0` | 没有 |

⚠ **搬的是「描边宽 ÷ 字号」这个比，不是绝对像素。** 那边画布 1920×1080、正文 44px，
这边 1080×1920、字号 34–52，绝对值搬过来会差一倍。那边 3 ÷ 44 ≈ 0.068，
指的是**往外长 3px**（libass 的 outline 只往外长）。

⚠ **SVG 的 `stroke` 是骑在轮廓线上的，一半长在字面里** —— 所以要往外 0.068，
`stroke-width` 得给 **0.136**，里面那一半被后画的填充盖掉。
跟封面标题（`cover.ts / inkedLine`）是同一个坑，两处都是画两遍。

治愈线给的调法直接适用：**往外小于 2px 挡不住线条，大于 4px 笔画之间的白开始糊成一片。**
这边字号 34–52，往外 2.3–3.5px，正在带里。

两件不能改的：

- **颜色用纸色不用纯白。** 治愈线的原话：「用纯白会在这张低对比的图上跳出来」
- **描边那一遍不带高亮色。** 高亮词是芥黄，描边副本要跟着描一圈黄的，笔画边上就镶了道金边

还有一条治愈线踩过、这边也照抄了的规矩：**整块的描边要全部画完，再画填充** ——
逐行「描边＋填充」交替的话，下一行的描边会啃掉上一行的填充（行距 1.5 倍，够得着）。

**为什么没上柔边。** 治愈线那边是 `lur2.4`，注释说硬边「看着像给字加了白边的字幕」。
SVG 里要柔得上 `feGaussianBlur`，那是**逐帧滤镜** —— 一条片子 800 帧、每帧四五行字，
成本没量过。先按硬边出（007 起），真觉得字幕感太重再上，那时候要连渲染耗时一起量。

⚠ **001–006 是没有这一层的**，不回改（成片不重出）。

### 4. `keepX`：单人镜不要自动居中

`charStateFor` 里 `x: solo ? W/2 : baseX` —— 单人镜自动挪到画面正中。
那是给对话类定的（一个人说话时他本来就该占住画面），
但**独白线整条片子只有一个人**，一直居中就把两边都占死了，侧边字幕没地方排。

`"keepX": true` ＋ 显式 `x` → 他站三分之一处，让出另外半幅。
**只有显式声明的角色不居中**，别的线不受影响。

### 5. `camera: "static"`：镜头不动

跟随没有对象可跟（就他一个），推近也没有反转可推，剩下的只是画面在无缘无故地晃。
`static` 只保留开场那一下缓推，之后停住。**不是把幅度调小** —— 调小还是在动。

### 6. 音效：**四个默认开的全部关掉**

A 类默认往时间轴里塞四样：开场「嘶」（**蛇专属**）、回应句木鱼、反转句下滑音、定格「咚」。
那套默认是给对话段子调的，音效在那种片子里是节拍。

**独白 deadpan 全都不能要**，「咚」尤其致命：它等于自己先敲了一下锣。
跟 §一之七「落点句不要有形容词」是同一条道理 —— 形容词和音效都是在替观众下判断。

```json
"cues": { "introHiss": false, "replyWood": false, "punchSlide": false, "freezeThud": false }
```

关掉之后停顿是**数字静音**（全零窗口从 94 涨到 130），片尾 2.7 秒绝对静音。
空白交给画面，见 SCRIPT_GUIDE §五。

## 四之九、开场幕布

素材包给的 `horse/curtain.mjs`，2026-08-23 接进来，**三个出场档都开**（稿件写
`"curtain": false` 单条关）。0.45 秒拉完，配音从 0.000 起 —— 详见

### ⚠ 挂载点有两个，只挂一个不会报错

`render.ts` 里档 ③ 是**提前 return 自己的 `<svg>`** 的（首帧只有物件特写），
正常路径在文件末尾收尾。**两处都要挂** —— 只挂后者的话，恰恰是老马缺省那一档没有幕布。

### ⚠ 别改成 ffmpeg 位移合成

素材包 README 主张「不要逐帧渲整张画面」，改用 `curtainPanel()` 导两张 PNG、位移交给 ffmpeg。
**那条建议对这个仓库不成立**：这儿本来就逐帧渲整片（25 秒 756 帧全渲），
头 14 帧渲不渲幕布都要渲，多画两片布几乎不要钱；换成 ffmpeg 反而多一个合成阶段、
两张外部 PNG 和一条 overlay 表达式。

**但 README 另一条警告要记住**：CSS / SMIL 动画 SVG 在 resvg 里**不执行**，
只静态渲 t=0 那一帧 —— 真那么做会得到 14 张一模一样的全闭画面，而且不报错。
所以幕布必须按帧算进度、每帧重画。

### 接进来时修的两个 bug（素材包那份有）

**一、最后两帧让 resvg 崩。** 带 `opacity` 的 `<g>` 会渲进离屏图层，图层尺寸取组内容外接框；
淡出从 `p>0.85` 开始，而 `p>0.86` 之后两片布已经整个移出画布，图层跟画布**没有交集**，
resvg 在 `geom.rs` 里对空矩形 `unwrap()` 直接 panic。
**Rust panic 是杀进程不是抛异常**，JS 那头 `try/catch` 接不住 ——
表现是 `npm run still` 退出码 3221226505，一行错误信息都没有。
修法：**拉到画外的那一片不再画**（`seen()`）。

**二、全闭那一帧中缝有条竖缝。** 原版两片正好在 x=540 相接、**重叠为零**，
而内缘是波浪（±14）且左右不同 seed、不同步，最坏裂 28px，背景直接漏出来。
修法：中缝各多伸 30px（`OVERLAP`），标称重叠 60，最坏仍重叠 32。

## 五、动效：脸不做戏，戏在眼睛和字幕上

人设是「不愤怒、累到平静、不表演」，脸上不能有戏。可 30 秒一张不动的脸会闷死。
出口有四个，**没有一个是让他做表情**：

| 手段 | 频率 | 配置 | 体检拦不拦 |
|---|---|---|---|
| 眼动（扫视＋固视） | 全片，自动排 | 不用配，`say[].look` 可点名 | 拦（6 秒不眨眼） |
| 眨眼 / 闭目 | 眨眼自动；闭目**全片一次** | `line.closeEyes` | 拦 |
| 逐屏字幕 | 转折句、落点句必须 | `line.say` 拆小句 | 拦（一屏 >12 字） |
| **张嘴无声** | 全片最多一次 | `line.openMouth` | 拦 |
| 扭头 | 一条最多两次 | `line.turn` | — |
| 说话放射 | **按 beat 分档，不是常亮** | `speechBurst.byBeat` | 报 |
| 漫符 | **全片最多一个**（可以是 0） | `endMark` | 拦 |

### 眼动：扫视 ＋ 固视，不是漂移

**人的眼球是瞬间跳到一点、钉住不动、再瞬间跳走。** 匀速运动在生理上不存在。

这一条走了两版弯路，都是同一个错：

| 版本 | 做法 | 为什么不行 |
|---|---|---|
| 一 | 低频漂移 ＋ 偶发扫视 | 视线没有目的地，读作走神或心虚 |
| 二 | 停顿时沿一个圆走整一圈 | **圆是匀速的，匀速就是漂移**，只是漂得规整了些；而且一次停顿转满一圈，动得太多 |
| 三 | 一串固视点，两帧跳过去 | 眼睛**绝大部分时间不动**，只是每隔一两秒换个地方 |

参数（`render.ts` 的 `eyeTrack()`）：

| 项 | 值 | 为什么 |
|---|---|---|
| 扫视时长 | **2 帧**（0.066s） | 基本等于瞬移。**不要插值成缓动** —— 缓动就是漂移 |
| 固视时长 | 0.9–2.0s | 超过两秒眼睛开始像定住的图 |
| 微动 | ±0.8px | 固视期间眼球也不是死的。多了又成漂移 |
| 一句话内扫视 | **≤ 2 次** | 太频繁读作「心虚、慌张」，跟人设正相反 |
| 幅度 | 中扫视 14–20px | ±24 那一档留给转折；物理上限 ±26 / ±22（顶出眼白） |

**方向是有语义的**：向上＝回想，向下＝无奈，向侧＝转移注意，归中＝面对。
老马的底色是「累到平静」，所以**向下和向侧为主，向上少用** —— 配比约 向下 55 / 向上 30 / 平移 15。

按 beat：

| beat | 起手 | 扫视 |
|---|---|---|
| 铺垫 | `(-6, 4)` | 每 1.6 秒左右一次中扫视 |
| 转折 | 大扫视到扭头方向 | **视线比头先动 0.12 秒** |
| 停顿 | 往中间收一点 | **但不回到正中，正中留给落点** |
| 落点 | `(0, 0)` 正视 | **不扫视，连微动都压掉** |

三条硬规则：

**一、视线比头先动。** 扭头前 0.12 秒眼珠先跳过去，才像「他决定看那边」；
同时动像是被人掰过去的。代码里是 `GAZE_LEAD`。

**二、落点前的归零必须是一次扫视，不能滑回来。** 滑回中间没有决断感。
做法是在落点前 0.45 秒插一个归零固视点（`ZERO_LEAD`），两帧跳到位，然后整个落点句钉住。

**三、扫视和眨眼同帧。** 人换注视点时经常顺带眨一下，两者永远错开反而假。
所以停顿处的那一跳和那一眨排在同一个时刻。

⚠ **轨在 `render.ts` 里排，不在 rig 里。** 「什么时候该跳」要看 beat、看这一句说到哪、
看这次停顿从哪到哪 —— rig 只看得到当前时刻，这些它一样都不知道。
rig 只管画（`s.gaze` 收结果）。

#### 表情：必须由稿子点名，而且**可以点到小句**

自动扫视是待机动作，**待机动作永远碰不出一个表演**。所以「不屑」这种东西
只能靠 `look` 点名。可选的见 `rigs/horse.ts` 的 `LOOKS`：

| 名字 | 位移 | 读作 |
|---|---|---|
| 不屑 | `(-19, -15)` | **往斜上看才是「懒得看你」**，往侧面看只是「在看别处」 |
| 心虚 | `(-13, 11)` | 往下才是躲，往上是走神。幅度比不屑小一档 —— 心虚是「不敢看」不是「不想看」 |
| 笑眯眯 | 眯成一条线 | 眼白和眼珠一起藏掉，画两道**上弯**的弧 |
| 瞪 | 眼珠 ×1.45 | 只给定格用 |

**表情写在 `say[].look` 上，不要写在整句上。** 一个表情挂满一整句就太久了：
固视超过两秒眼睛开始像定住的图，而拆过屏的句子里几个小句本来就不是一个意思。
这条片子两处都这么改的 ——

- 转折句：「我练了三年 / 找到了最佳位置」心虚，到「第三个。」**归中正视**（那是他的答案）
- 揭晓句：「第一个像拍马屁 / 最后一个像敷衍」不屑，到「第三个刚好像是认真读完的」**归中**（那句说的是他自己）

写 `"look": ""` 表示这一小句归中。**表情说完就松开**（按 `speakingAt` 判，不含 padAfter）——
用段来判的话他说完了表情还挂着，一直挂到下一句起头，而那段正是眼睛该自己动的时候。

⚠ 眼白/眼珠的坐标是**光栅化量出来的**硬编码值（眼珠中心 293.0/408.2, 266.5；
眼白中心 282.5/421.7, 257.0）。**原稿换了要重量**，不然表情会错位而且不报错。

### 眨眼与闭目：不是一回事

| | 眨眼 | 闭目 |
|---|---|---|
| 时长 | 5 帧（0.167s） | **0.8–1.5 秒** |
| 用量 | 每 1.2–6 秒一次 | **全片最多一次** |
| 位置 | 停顿处、`say` 的换气处 | 铺垫段某个「受不了」的瞬间 |
| 落点句 | **不眨** | **绝对不能用** |
| 读作 | 他是活的 | 忍耐 / 认命 |

**首片 24 秒一次没眨眼。** 观众第 8–10 秒就开始读出「静图配音」——
这是那条片子最大的一处硬伤，而且形式体检全绿。现在 `MAX_NO_BLINK = 6`，
超过 6 秒排不进眨眼体检直接报。

**位置只放在停顿和换气处**：人是在换气和停顿时眨眼，不是匀速眨。
排不下的时候才往句子中间兜底塞。

闭目这一条片子用在「你回晚了不对，回早了也不对」说完 —— 那正是「受不了」的一下。
为它把 `padAfter` 从 0.5 加到 0.9：**闭目要 0.8 秒以上才读作忍耐**，
0.5 秒里闭一下只会读成眨眼。停顿本身没丢，反而更长了。

⚠ 闭目咬进下一句开头是最容易犯的错，体检拦这一条
（`closeEyes` ＞ `padAfter` ＋ 下一句 `padBefore` 就报硬伤）。

### 张嘴无声：把画面的限制变成表达

老马的嘴由配音包络驱动 —— 有声音就动，没声音就闭着。这是个限制。
`line.openMouth` 是**唯一一处手动把嘴掰开的地方**：说完这一句之后，
张着嘴、不出声，挂多少秒。

```json
{ "text": "她说，我知道啊。", "padAfter": 1.8, "openMouth": 1.6 }
```

为什么它成立：**前面二十多秒观众已经学会「嘴在动＝有话」**，
突然嘴动了没声音，那个空是响的。这不是口型没对上，是他真的没话说。

稿 5《天气预报》整条片子就是为这 1.6 秒存在的 —— 妈妈说「我知道啊」，
他张嘴想反驳，说不出来。方案 §六 的原话：「它把口型开但不出声用成了叙事手段 ——
**画面的限制反过来变成了表达**。」

- 时长 **1.0–2.0 秒**。不到一秒读成口型没对上，不是「说不出话」
- **全片最多一次**，跟闭目一样。用两次就成了口癖
- **不能放在落点句后面**（体检拦）。落点说完就该完，
  再补一个动作等于自己给包袱加注解
- ⚠ 要跟 `padAfter` 一起加长，否则咬进下一句（体检拦）
- **张嘴和闭眼不能同时** —— 那是「张着嘴睡着了」。代码里张嘴排在闭眼之后，
  会把 `eyes` 掰回 normal：这一下要的是他睁着眼、张着嘴、什么都说不出来

### 扭头

- 幅度 **±13°**，渐入渐出，不要硬切
- **一条片子最多两次**，只用在话锋转了的那一句（`line.turn`）
- 超过 **±25°** 会穿帮 —— 耳朵和鬃毛不会转到三维正确的位置
- 渲染时**视线比头先动 0.12 秒**

做法是水平压缩（cos）模拟转动，脸再按 sin 横移做视差。这是二维假三维的极限，
不是参数没调好。

### 口型

三态由配音包络驱动（`mouthFrom`），另外两件事：

- **闭 ↔ 大张之间垫一帧 `E`**。从一条细线直接跳到一个圆块，切换那一下会「啵」地弹出来。
  只垫一帧，多了嘴糊成一团。判据是上一帧的包络 —— **不能存状态**，
  渲染是多进程逐帧并行的，帧与帧之间没有共享内存。
- **开口还是一坨实心深色**（脸上像开了个洞）。要厚度得在原稿上加一层比外圈浅一档的内腔 ——
  **这是美术活，代码这层改不了长相**（`horse_only.svg` 是唯一真源）。还欠着。

### 说话放射

素材是外部给的 svg，**路径数据一个字没改**，改了三处：

1. **CSS 动画换成逐帧算。** resvg **不支持 `@keyframes`** —— 直接喂进去五根刺
   会全定在初始状态，**而且不报错**。把五个周期和缩放区间抄成数，按时刻算 scale。
   五根周期互质（.37–.62 秒），所以永远不会齐步跳 —— 齐步跳会变成一个在闪的整体。
2. **缩放中心**：原稿 `transform-origin: 0px 0px`，这边绕 (0,0) 缩放，效果一致。
3. **摆位**：挂头右上，扇形朝右开、上仰。**不能放左边** —— 左边只剩 90px，
   扇形一开就出画（试过）。

**开关按 `speakingAt()` 判，不按 `segAt()`**：段的 `end` 是含 padAfter 的，
按段判的话他早说完了、符号还在跳。`speakingAt` 只认配音波形真正在响的区间：

```
放射符  1.37–4.63   5.07–8.30   8.60–12.60  13.20–16.50  17.17–25.87
灭的四段    0.44s       0.30s       0.60s       0.67s
```

最后那 0.67 秒正是落点前的停顿（§四「转折前那半秒是全片最重要的」）。

**不往下细到配音包络** —— 包络能把句内换气（0.22–0.3 秒）也抠出来，
但那 0.2 秒的一开一关在 30fps 下就是闪一下，而且句子里换口气本来就还算在说话。

#### **不能全程常亮**

首片挂了 29 秒。挂满一整条它就退化成一张装饰贴纸，而且**落点那一下再没有
额外的强调余地了** —— 一直亮着的东西，亮的时候没人注意。

按 beat 分档（`speechBurst.byBeat`）：

```json
"byBeat": { "setup": 0, "reply": 0.7, "punch": 1.15 }
```

数字是尺寸倍率，0 = 这一档不出。这条片子前 12.6 秒**一个符号都没有**，
转折段小一号，落点那一下最大。**留白是为了让落点有东西可以亮。**

那 12 秒靠什么撑？眼动和眨眼 —— 见上面。

### 漫符：**全片最多一个**

`node horse/render.mjs --marks` 出一览图。现有 10 个：
惊 / 惊二 / 问 / 汗 / 点 / 闪 / 云 / 灯 / 冷 / 星。

⚠ **用量口径改过。** 原来是「一条最多 3 个，同一个不重复」。现在是 **1 个**，
理由是人设：汗滴、问号、井字纹这类符号是**画面在替观众下判断**，
跟「不慌不忙、只陈述不评论」直接冲突 —— 老马这条线的全部力气都花在
「他只是在陈述，判断留给你」上，一个惊叹符号就把它拆了。

这条片子那唯一的一个给了收尾卡的大汗珠。正片里原来在「回晚了不对回早了也不对」
那句挂了一个「点」（无语），**删掉了** —— 那正是最典型的「替观众下判断」：
台词已经说清楚荒唐在哪，符号是在旁边补一句「你看多荒唐」。

**留下的那滴汗是一处有意的例外。** 规范说不用汗滴（慌张跟人设相反），
但收尾卡那一滴不是慌张，是**面具掉下来** —— 前面 26 秒的平静是装的，
定格那一下瞪眼＋张嘴＋一滴汗是包袱的第二层，而且它是那 2.7 秒里唯一发生的事。
真要严格执行规范就删掉它，收尾只剩转灰和钩子字幕。

⚠ **2026-08-21 起改了口径：出收尾卡的片子，卡上不能只有一行钩子字。**

原来是一稿一议「这条该不该挂符号」，结果稿 4《看哪儿》判成不挂，出来的收尾卡是
两秒半什么都没发生的静止画面 —— 单看不觉得，跟稿 1 摆在一起立刻看出漏了一层。
**收尾卡上一条片子只有三样东西**：去色的定格、一行藏青钩子字、一个漫符；
抽掉第三样就剩两样，观众读作「没做完」而不是「克制」。

**但要挂哪一个仍旧一稿一议 —— 固定的是「有」，不是「是汗」。**
汗＝尴尬心虚，只在落点把他自己也算进去、当场被自己抓包的时候才成立
（稿 1 面具掉下来，稿 4「我们发明了一个方向」他就是那七个人之一）。
落点是个纯推断、他站在事外的，挂汗就是硬凑 —— 那正是稿 4 原来那条注释
警告过的事，别把它一起丢掉。按落点选：想通了一件没用的事用「灯」（自带反讽），
没话接用「点」，认了用「云」。

⚠ **挑符号要先看它在去色的画面里立不立得住。判据是「落差」，不是「有没有颜色」。**

（**2026-08-21 修过一次**：原来写的是「必须是那一帧上唯一还有颜色的东西」。
按那条，稿 7 用的问号该被排除 —— 它是 `#3B322B` 墨色，不是彩色。
渲出来才发现不对：问号是近黑压在浅墙上，**明度落差比那滴淡蓝的汗还大**，视线一样落得上去。
真正挂不住的是**中间调**。）

两条路都行：**要么有颜色**（汗 `#CFE0E4`、灯/星 `#F2D98A`、冷 `#8FA3AD`、惊/闪 `#C4552E`），
**要么明度压得够低**（问、惊 的墨色 `#3B322B`）。漫符不过 `ink()`，收尾卡是全屏去色的，
它得是那一帧上唯一还「跳」的东西。所以中间调的那几个
（点 `#6E6459`、云 `#D8D2C6`）挂上去看得见，但**看得见不等于跳出来** ——
它们既没有颜色、明度又跟去色之后的整幅画在同一档，读作画面的一部分，
不是「唯一还活着的那样东西」。两条都试过：稿 4 试「点」，稿 6 试「云」，都是这个毛病。
稿 4 试过「点」（语义最贴的一个），就是这个毛病；顺带 0.5 的尺寸最左边那个点还糊在耳朵尖上。
有颜色的是：汗（`#CFE0E4` 冷蓝）、惊 / 惊二 / 闪（`#C4552E` 朱）、
灯 / 星（`#F2D98A` 暖黄）、冷（`#8FA3AD`）。

同一个符号在不同片子之间**参数照抄、连 seed 都不换**
（汗是 `{ "spot": "右上", "size": 0.5, "seed": 2, "tilt": 8 }`）——
换了手绘抖动就每条不一样，那是「每条各画了一个」，不是「又到这儿了」。

规范那句「一条最多一个漫符」照旧，**收尾卡这一个就是那一个**：正片里一个都不许再出。

```json
"marks": [{ "name": "点", "spot": "右上", "size": 0.3, "seed": 9 }]
```

`spot` 只有 `左上` / `右上`，落点在头的**外侧**。压在头上就不是漫符了，是贴纸。
`size` 是占角色框宽度的比例：全身镜 0.30–0.50，近景 0.22–0.34。

三条硬规矩：

1. **出符号的那一帧，脸不许动。** 脸毫无反应、旁边啪地弹出一个巨大的符号，
   那个落差本身就是笑点。脸要是也跟着惊讶，符号就白画了。
2. **一条 30 秒最多 3 个，同一个不重复。** 满屏乱弹就成了表情包合集。
3. 全部走 `rough.mjs`，跟马和场景同一套笔触。**不要用 emoji、不要用图标字体。**

**漫符不过 `ink()`，所以定格去色时不掉色** —— 全屏灰掉只剩那滴汗还有颜色，
视线自然落在上面。这是撞上的，留成了规矩。


### 收尾：不是每条片子都该出收尾卡

收尾卡是定格去色那一帧上唯一的一块藏青，要亮着让人看见、让人记住这个号。

**2026-08-21 起它是一张日子牌**（`老马的第 1847 天`，一稿一天往下加，
分配表在 `horse/CHANNEL_LAOMA.md` §五之二）。原来那句固定的「老马，今天也没辞职。」
是**段子的 CTA**，而 CTA **往一条不是段子的片子后面一贴，就成了「刚才那是个段子」**。
日子牌不表态、不俏皮，这个毛病没有了 —— 但下面这条判断仍旧成立：
稿 5《天气预报》没有可笑的地方，靠的是「拦不住」；最后跳出来一行俏皮话，
前面三十秒就白攒了。

所以这一档是可选的：不写 `hook` 就没有收尾卡，配 `fadeOut` 走黑场。

```json
"freeze": 2.6, "hold": 1.4, "fadeOut": 1.4
```

**先褪色，再灭灯。** 定格去色是「颜色抽走」，黑场是「灯灭了」，两回事 ——
黑场那层黑画在最外面，把字幕、钩子、片头卡一起吞掉：
黑场的意思是「片子关上了」，留一行字在黑里飘就不是关上，是没关严。

⚠ 发布文案和分镜表都认这一档：没写 `hook` 的时候末行打
「收尾黑场，不出收尾卡」，不再打空的「说破段落点「」」——
**那看着像漏填了，而它是有意不填的**。

### 落幕表情

最后一句说完（`freezeStart`）到片尾，锁住三件事：

```json
"endPose": { "mouth": 2, "eyes": "wide" },
"endMark": { "name": "汗", "spot": "右上", "size": 0.5 }
```

- **张嘴必须在渲染层覆盖** —— `charStateFor` 里 `mouth` 是从包络算的，
  定格时包络已经是 0，脸会自动闭上
- **瞪眼**：眼珠放大 1.45 倍，**绕各自的中心缩放**（中心是光栅化量出来的：
  左 293.0,266.5 / 右 408.2,266.5）。绕 (0,0) 缩放会把眼珠甩到脸外面。
  1.45 是上限，眼白是画死的，再大眼珠顶到白边上就不是瞪眼是白内障
- **瞪的时候眼神归位**，不再漂移 —— 视线钉在正前方才是「僵在那儿」

前面 25 秒面无表情，就是为这一下攒的。

## 六、稿件体检（`laoma-check.ts`）

`SCRIPT_GUIDE.md` §六 那张十一条的自检表写着「有一条不过就不发」，
**但它是一张复选框，没有代码在守**。稿 1 就是照结构填出来的 ——
形式全对、流程全通、一路绿灯，可片子出来「总觉得没亮点」。
回头拿那张表对，当场挂掉一条硬伤：**落点句 41 字，上限 15，超了 2.7 倍**。

```bash
npx tsx src/laoma-check.ts jokes/laoma-001.json
```

**文字项**：落点句字数、铺垫个数、落点后还有没有话、问句结尾、感叹号、
下判断的形容词、网络热词、说教句式、第一人称、模糊量词、全片时长、镜别切换。

**「像不像真事」那几项**（SCRIPT_GUIDE §一之十二到十六 ＋ §二「通篇四不」，2026-08-22 加）：

| 拦什么 | 判据 | 机器查得了多少 |
|---|---|---|
| 物件不是物件 | 没写 `object`；或它是纯外观描述（颜色/材质/新旧/大小）；或它只出现在 1 句里 | **大半**。「删掉它有没有句子说不通」查不了，只提醒 |
| 落点是反应不是事实 | 落点命中 `差点|几乎|居然|竟然|忍不住|莫名|才发现|原来|不由|有点想|想起|我觉得|我以为|说不上来` | 词表拦得住典型的 |
| 落点里没有数字 | — | 只提醒（「具体名词」查不了，数字查得了） |
| 钩子埋了没回收 | `hookLine` / `payoffLine` 两句去掉停用字之后一个实词都不重叠 | **查得了**，见下 |
| 单句太长 | 一句 >24 字（硬伤）；≥3 分句且 ≥20 字（提醒） | 全查得了 |
| 数字撞车 | 近 10 条用过同一个 ≥10 的数（账本 `horse/used-numbers.json`）；没有「不圆」的数只提醒 | 全查得了 |
| 通篇在解释 | 命中 `其实|说明|意味着|大概是因为|可见|也就是说|这就是|所谓` | 词表拦得住 |
| 首尾没扣上 / 出现颜色描述 | — | 只提醒 |

### ⚠ 三个新字段

```jsonc
"object": "小门",        // 承担叙事功能的物件，必须在 >=2 句里出现
"hookLine": 4,           // 钩子埋在第几句（1 起算）
"payoffLine": 6          // 第几句回收
```

**`object` 跟 `props`（摆进画面的道具）不是一回事：这个物件不进画面**，
进了画面就成了图解台词。

⚠ **`object` 是从 `prop` 改名的，语义一起翻过来了。**
旧的要「闲置的、删掉毫发无伤的」东西，照那条写出来的是 007 的「发票是绿的」
和 008 的「挂号单是粉色的」—— **两句都是贴上去的装饰，只出现一次，删掉毫发无伤。**
「未解释」和「闲置」是两回事：**物件要有用，不给的是解释。**
体检里那两条 `APPEARANCE` / `COLOR_WORD` 正则就是照这两句写的（「粉色挂号单综合症」）。

### 钩子回收为什么从「查不了」升级成了硬伤

原来的做法是把钩子末句和落点并排打给人看，理由是「量度回收（007 的
『优化了一个流程』→『第十一天』）两句可以一个字都不重叠」。

**那个让步是错的。这是听觉媒介，观众没法回看。** 换了同义词或者只靠语义呼应，
观众得先认出「哦这说的是刚才那个」，那一下的迟疑正好盖住笑点。
现在按 `hookLine` / `payoffLine` 点名的两句做字面重叠比对 ——
**滤掉一张停用字表**，因为「小门」和「小时」共用一个「小」不是呼应，
没有那张表任意两句中文都能凑出重叠字，这条检查就恒过。

**表情项**（§五 的规范，后加的）：

| 拦什么 | 判据 |
|---|---|
| 连续 6 秒排不进眨眼 | 停顿太密或太短，观众会读出「静图配音」 |
| 闭目超过一次 / 用在落点句 | 它读作忍耐，用两次就廉价了；落点闭上等于丢掉最重的一眼 |
| 闭目咬进下一句 | `closeEyes` ＞ `padAfter` ＋ 下一句 `padBefore` |
| 落点句点了表情 | 脸在替台词做解释，笑点就成了图解 |
| 说话标记全程常亮 | `byBeat` 没写，或者没有一档是 0 |
| 情绪符号超过 1 个 | 画面在替观众下判断 |
| 转折句/落点句有一屏超过 12 字 | **笑点在被听到之前就消费掉了** |

**首片形式项全绿，表情项当场挂掉四条**：24 秒没眨眼、落点句眯着眼三秒、
说话标记挂满 29 秒、转折句字幕整段预铺。**这四条一条都不是品味问题，
都是规范里写死的数** —— 而人照着结构填稿的时候最容易漏的正是这些数。

**查不了的三条恰好是决定好不好笑的三条**：一条只有一个笑点吗、误导公不公平吗、
转折的线索前面出现过吗。所以：**体检全绿不等于好笑，只等于没有明显的形式硬伤。**

三条刻意换了栏目和场景 —— 前三条是给完播率看的样本，
一个栏目连发三条，看不出是形态的问题还是选题的问题。

**《看哪儿》示范了一件值得复用的事：让场景替台词说话。**
落点是「七个人，看同一个不会变快的数字」，而 `elevator` 场景里那块楼层屏
写死是「12」，整条片子一格不动 —— 观众听到落点的时候不用想象，
他已经盯着那个数字看了二十秒了。选场景的时候先问一句：
**这条稿子的落点指着什么东西？那东西能不能一开始就在画面上？**

⚠ 也在这一条上摔了一跤：为了躲平台顶部的 UI 把楼层屏往下压了 112px，
结果**撞上了收尾卡**（钩子字幕画死在 y=250），藏青的字压在深色屏上直接看不见。
原位置本来不撞。教训是**场景里靠上的元素跟收尾卡是同一片地**，
挪之前先看那一片有没有别人 —— 而「被顶部 UI 盖住」那个担心本身也是虚的：
盖到的是空框上沿，数字在 120–190，看得见。
