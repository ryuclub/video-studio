## 一、规格

| | |
|---|---|
| 出处 | 《聊斋志异》卷二 |
| 定位 | 全篇最动人的一个「鬼不害人」的故事 |
| 建议字数 | **3200–3400 汉字**（原卡写 3800） |
| 预计成片 | **15.4–16.3 分钟**（按 E01 实测 **208 字/分含停顿**） |
| 预计段数 | 约 190 段 / 200 个声部 |
| 预计合成 | 约 140 秒 |

**为什么把 3800 改成 3200–3400**：E01 稿 2840 字，成片 12:32。原卡的 3800 字
按实测系数是 18.3 分钟——比 E01 长了近六分钟，而这是**同一个订阅位上的第二期**。
第二期就把时长拉到 18 分钟，完播率风险不值得冒。砍的位置见第三节每幕的字数。

> 语速系数是 E01 实测的，不是估的：全片 2840 字 / 752.8 秒 = 208 字/分（含所有停顿）。
> 其余 15 期的字数配额都按这个换算。

## 二、选角：直接映射到现有的 7 个通用原型

**不要用原卡的半音模型**（男主 −2 / 女主 +3 / 老者 −4…）。E01 已经把它换成
「先用不同的基础音色拉开距离，morph 只做微调」——理由是 morph 拉得越狠
rubberband 的金属味越明显，而说书是十几分钟连着听。

| 角色 | 用哪个原型 | 现成参数 | 念法要点 |
|---|---|---|---|
| 叙述 | `说书人` | 云健 +19% / 0.92 / 0.94 | E01 返工定稿，别再动 |
| 宁采臣 | `书生` | 云希 −2% / 0.94 / 0.96 | cast.ts 的注释里本来就写着「王生/**宁采臣**/成名」。**正气要读得稳，不能软**——拒色那两句走 `揭底`（平着说），别演成慷慨陈词 |
| 聂小倩 | `艳鬼` | 晓伊 −2% / 1.10 / 1.13 | 前段怯、后段暖，**靠节拍不靠换音色**：幕二用 `贴近`（压低拉近），幕三自陈用 `常规`，幕四归葬后用 `落定` |
| 燕赤霞 | `老道` | 云扬 −10% / 0.86 / 0.91 | 话少，每句有分量。**注意他在 E02 的戏份比 E01 的道士重得多**，见第六节的技术债 |
| 老魅 | `厉鬼` | 晓伊 −16% / 0.95 / 0.97 + 22ms 梳状回声 | **只出声不出场**——这正是厉鬼那套配置的最佳用法（贴耳、干、没有情绪起伏）。E01 它只有一句，这期终于用得上 |
| 宁母 | **不给台词** | — | 一期出场角色不超过四个。她的话全部由说书人转述 |

**聂小倩要不要新做一个音色？** 先不做。`艳鬼` 是「女鬼的美人相」这个**原型**，
小倩正是。前怯后暖是表演不是音色。**如果试听下来幕四的温柔被 333Hz 的清亮顶掉了**，
再新增一个 `少女`（晓伊 base，pitch 1.04 / formant 1.06）——那个原型后面
婴宁、青凤、小翠、连城都用得上，届时属于「积累」而不是「打补丁」。
先出前两幕试听再定，跟 E01 一样。

## 三、分幕

总字数 3300 上下。**每幕结尾留一个短句独立成段**——那是 TTS 的自然停顿点，
也是静态画面的切点。

### 冷开场（180 字）｜ 钩子照抄原卡，它够狠

> 先说一件事：这个故事里的女鬼，是杀过人的。
> 她自己承认了。她说她杀人的方式，是用一根锥子，扎进人的脚心，血就顺着孔流出来。
> 可《聊斋》五百个故事，最让人记住的女子，偏偏就是她。
> 今天讲《聂小倩》。

节拍：`扣子` → `贴近`（那句锥子要压低了说，别喊）→ `悬` → `揭底`。
跟 E01 冷开场同一个结构：**吊住 → 停死 → 平着揭**。

### 引入（320 字）
金华北郭的兰若寺。蒿草没人，僧舍久无人住。宁采臣是浙江人，为人慷慨、不苟且——
**这句性格交代必须放在借宿之前**，因为幕二整幕都在兑现它。
借宿时遇见独居东厢的燕赤霞，只交代「是个怪人，剑匣不离身」，不解释。

> ⚠ 原卡的提醒仍然有效：**不要照搬原文的骈句写景**，改成三句短白描。

### 幕一 · 荒寺（620 字，原卡 700）
夜里同宿的两人先死。写死法：足心有小孔，血被吸尽——**这个细节要留在这一幕**，
因为冷开场已经把「锥子扎脚心」说出去了，这里是应验，听众自己会接上。
燕赤霞警告宁采臣别出屋，宁不明所以。

幕尾短句：「那一夜，寺里死了两个人。」

### 幕二 · 夜叩（**820 字，全篇最重，不能省**）
小倩夜来相诱 → 宁拒 → 改以黄金诱 → 宁**掷金于外**。

**这是全篇立人的地方。**两次拒绝要写出层次：第一次拒的是色，第二次拒的是利。
掷金那个动作不要加形容词，就是「宁采臣拿起那锭金子，走到门口，扔了出去。」

宁采臣的两句台词都走 `揭底`（平着说，音量放回来）。**不要用 `点评` 或者拔高**——
正气一演就假，E01 那句「不要演，平着说反而更冷」在这里同样成立。

幕尾短句：「小倩站在门外，很久没走。」

### 幕三 · 实情（780 字）
小倩自陈：受妖物胁迫，以色诱人、取人血，不从则受苦。**杀过两个人这件事她自己说出来。**
求宁迁其白骨归葬。

这一幕是**全篇唯一的长对白段**，小倩连着说三四段。要点：
- 说话人一律写「聂小倩说：」，**不要写「她说：」**（理由见第五节）
- 中间插两处说书人的短评把节奏断开，别让一个声音连讲两分钟
- 蒲松龄原文里最有力的那一两句直接引用，念之前给提示：「原话是这么写的——」，走 `引文`

幕尾短句：「宁采臣答应了。」

### 幕四 · 剑光（700 字）
燕赤霞剑匣中白光如练，斩夜叉 → 宁携骨归葬 → 小倩事其母 → 终为妻。

**收尾要快。** 打斗只写三句：光、声、静。老魅的声音在这里出现（`厉鬼`，只出声），
说完就没了。然后是很长的日常：小倩每天做什么、宁母怎么从怕到不怕。
**这段日常是全篇最动人的地方，别急着结束**——恐怖是壳，这才是芯。

幕尾短句：「后来她成了他的妻子。」

### 收束点评（250 字）
**不要复述剧情。**讲一个原文没说破的东西——

> 这个故事里，**没有人追究小倩杀过人**。
> 蒲松龄没有安排她赎罪、立功、以死谢过。他只是让一个人**不占她的便宜**，
> 然后让她活了过来。
>
> 宁采臣做的事，说穿了只有一件：夜里有人送上门，他没要；有人送金子，他扔了出去。
> 这两件事都不算英雄行为，只是**没有伸手**。
> 而全篇死掉的那些人，都是伸了手的。

结尾扣（照抄原卡）：「明天这一期短，也轻松。一个书生上山学仙，学了几个月，
只学会一样本事——穿墙。」

## 五、写稿时必须守的三条（**直接决定后期工时**）

E01 的瓶颈从来不是机器（合成 117 秒），是**标注**。这三条能把标注量砍掉大半：

**① 对白一律写「聂小倩说：」，不要写「她说：」**
解析器 `shuoshu-parse.ts` 认「某某说：」直接点名的对白，能自动定说话人；
代词开头的一律标 `needsReview` 要人判断。E01 有 18 段栽在这上面。

**② 冒号，不要逗号**
E01 第 21 段写的是「她说，我原是…」——解析器的正则只认 `[说问道][：:]`，
整段当旁白过去了，**而且没有任何标记**。这类漏网比 `needsReview` 危险得多。

**③ 每幕结尾一个短句独立成段**
给 TTS 自然停顿点 + 画面切点，同时解析器会自动给它打 `收` 节拍。

## 六、动工前必须先清的技术债

E01 的管线是**照着一期硬写的**，E02 直接跑会撞下面四条：

| # | 问题 | 位置 | 怎么改 |
|---|---|---|---|
| 1 | **期号硬编码** | `shuoshu-parse.ts:117` 的输出目录、`shuoshu-build.ts:33` 和 `shuoshu-sample.ts:15` 的 `EP` 常量 | 改成命令行参数或从稿件文件名推。**不改的话 E02 会把 E01 的 script.json 覆盖掉**（解析那一侧有保护会改道，但 build 会把音频写进 E01 的目录） |
| 2 | **人名表是 E01 的** | `shuoshu-parse.ts:44` 的 `NAMED`（王生/陈氏/道士/乞丐/姑娘/女子/蒲松龄） | 挪到**稿件头部**的元信息里，每期自己带。E02 要的是 宁采臣→书生 · 聂小倩→艳鬼 · 燕赤霞→老道 · 老魅→厉鬼 |
| 3 | **燕赤霞 ↔ 说书人 撞音** | `cast.ts` 的 `老道` vs `说书人`，Δ基频 17Hz / Δ低高频 1.8dB，两条红线都不过 | **E02 必须解决**——E01 的道士只有 9 段 42 秒，燕赤霞在 E02 是幕一和幕四的主角。方案见 E01 方案.md 第七节末（甲/乙/丙三条），先出对照用耳朵定 |
| 4 | **响度 −23.4 LUFS** | 峰值归一化，不是响度归一化 | 在 `shuoshu-build.ts` 里加 loudnorm 到 −16。**别动 `config.ts` 的 `PEAK_DBFS`**，段子视频也在用 |

第 1、2 条是**一次性投入，17 期都受益**；第 3 条是 E02 特有的；第 4 条越早越好，
不然每期都要事后补一道。

## 七、制作思路（七步，照 E01 走过的路）

```
① 扩写整稿              → shuoshu/liaozhai-E02-nie.md（3300 字，头部带人名表）
② npx tsx src/shuoshu-parse.ts ../shuoshu/liaozhai-E02-nie.md
                        → projects/2026-08-19_liaozhai-E02/script.json
③ 人工标注              → 说话人（守了第五节三条的话应该 <5 段要判断）+ 节拍
④ npx tsx src/shuoshu-build.ts --preview   前两幕试听（约 4 分钟）
   ⚠ 听三件事：小倩的怯、宁采臣的稳、燕赤霞跟主讲分不分得开
⑤ 定了再跑全片          → 全片.wav + .srt + .manifest.json（约 140 秒）
⑥ npm run cast:check    确认这一期的调音没动到别人
⑦ 静态图 + ffmpeg concat（水墨风模块还没有，见第四节）
```

**第 ③ 步是唯一的瓶颈**，前面五条写作规范全是为它服务的。
**第 ④ 步不能跳**——E01 就是跳过试听直接跑了全片，结果主讲人机械偏慢，全片重来一遍。

## 八、还没定的

- **聂小倩用 `艳鬼` 够不够**（幕四的温柔会不会被 333Hz 顶掉）→ 第 ④ 步试听时定
- **幕四的剑光要不要音效**——全系列到现在一个音效都没有。E01 证明了纯人声能撑，
  但「白光如练」这一下留白可能比加音效好。倾向不加，**别为了热闹开一个后面 15 期都要维护的口子**
- **字数砍到 3300 之后，幕三的长对白够不够铺开**——这是全篇的芯，宁可砍幕一
