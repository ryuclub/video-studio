# E01《第七个饼》· 方案

副标题：他后悔的是前面六个
出处：百喻经·欲食半饼喻　｜　题材域：钱与工作　｜　床音：`LNDO_Glorious_instrumental_3_24`（纯器乐，跟心理线同一条）

排期见 [zhiyu/禅佛典向_小故事大道理_书目与稿件.md](../../../zhiyu/禅佛典向_小故事大道理_书目与稿件.md)
§四「24 期标题表」第 1 期。稿源 §五 有一份早期完整稿，**这一版不是照抄**，

## 说破层三行（先于扩写定的）

| | |
|---|---|
| **说破句**（错位型，翻面版） | 他要的不是那半个饼，是一个说法——这七个饼里，哪一个算数 |
| **诊断词** | 计较 —— 不是小气，是一个人把力气花出去以后，想知道那些力气落在了哪儿；不知道落在哪儿，它们就没有地方可放 |
| **现代对照**（行为链推出来的） | 交出力气 → 只认最后那一下 → 把前面的记成教训 → 生一场找不到落点的气 |

行为链对齐：

| 王七式的行为链（本篇是买饼人） | 同构的现代动作 |
|---|---|
| 一个一个买，钱一次一次给 | 一天两三份地投简历／两年一百多条地发／半年谈七次 |
| 吃到第七个的一半，饱了 | 第三十一份有回音／某一条被转几千次／第七次签字 |
| 判定「是这一个让我饱的」 | 复盘只写最后那一份改了排版、那一条选题对了、第七次说对了哪句 |
| 判定「前面六个白吃了」 | 前面三十份成了「当初太不讲究」，前两年缩成「一直没做起来」 |

**站位是「松开」不是「认清」**（稿源 §〇之二）：说破句的后半句落在
**他为什么非要这个说法不可**（不然那些力气没处安放），不落在他把哪一步估错了。

## 二版：床音、文字版、发布文案（2026-08-21）

一版出完之后按「参照心理洞察线的做法」改了三处，**稿子一个字没动**，
重跑的是音频（换床音）→ 画面 → 文字层 → 两版成片 → 发布文案。

### ① 床音：空 → 纯器乐

稿源 §五 给 E01 写的是「床音：空」，§八 写的是「用『溪』与『空』」——
那是开线时按助眠档口径定的，而且 `zhiyu/musics/` 里根本没有「溪」这条素材。

**这条线不是助眠档。** 它要人听完一个故事，八分钟里空着的停顿显得比实际更长。
现在跟心理线 E02 同一条：`LNDO_Glorious_instrumental_3_24`，204 秒纯器乐，
七分多钟的片子循环三遍多（缺省的 `1.wav` 只有 10.3 秒，循环四十几遍会被听成节拍器）。

**要 instrumental 版不要 background_vocals 版** —— 心理线 E01 用的是后者，
它的自检清单里就写着「底下可能有人声，糊就换 LNDO」，不再赌一次。

垫床之后真峰从 −4.8 走到 −7.6 dBFS，整期响度仍是 −21.0 LUFS（床音本身 −38 LUFS）。
缺省值已经写进 `zhiyu-lines.ts` 的 `defaultBed`，稿源 §八 那一行也改了。

### ② 字幕：多出一版「文字版」

跟心理线一样两版并存，走同一份 `xinli-text.ts`：

| | 常规版 | 文字版 |
|---|---|---|
| 给谁 | 听的人 | 静音看的人 |
| 正文 | 不上屏 | 逐句上浮，124 句，字直接落在景上 |
| 字幕 | 另出 `.srt`，不烧 | 另出 `.srt`，**别开平台软字幕** |

**改了一处代码**：`xinli-text.ts` 原来把墨色纸色抄成两个字面值
（`#3F4A52` / `#F4F1EA`，心理线那套），注释还写着「改那边这儿要跟着改」——
那句话就是分叉的预告，换条线立刻兑现：本线的景是赭石暖色，
抄来的冷灰字浮在上面像贴上去的，**而且不会报错，只会看着不对**。
现在从 `zhiyu-scene.ts` 导出的 `C` 里取，跟着线路走。

### ③ 发布文案列出中心思想

`zhiyu-publish.ts` 多出一节【中心思想】，**从稿子的稿头取**，不在 `发布.json` 里再写一遍：
心理线认「中心思想：…」，本线认「说破句：…」，治愈线两样都没有就整节不出
（那条线的收束是消解不是点破）。

抄进 json 是最容易分叉的做法 —— 改了稿子忘了改 json，文案上挂的就是上一版的落点，
而两份看上去都对，没人会发现。

顺带把**文字版补进了「文件」那张表**：出了而不列等于没出，
照着这份传片的人不会知道目录里还有一个。这一条对心理线同样生效
（E02 已出片，按「已出片不回改」的约定没有回去重跑它的发布文案）。

## 跟稿源 §五 那版差在哪

§五 那版写在硬规则 11–13 之前，四处不合现行规范：

1. **回看段没有诊断词**（规则 12）。原版说破完就转下一段，落点是画面不是把手。这一版补了「计较」＋重定义。
2. **引申段铺了三个题材域**（规则 13：一期一个域）。原版是减肥（健康）／简历（工作）／学语言（自我期待），现在三个场景全收进钱与工作。
3. **冷开场二拍的现实锚点也跟着换了**：原版是电梯里说减肥，现在是简历——跟引申段第一个场景同一件事，首尾扣得上。
4. **格式不能直接进管线**：原版用 `> 引句` 和 `〔静音 1.0 秒〕`。`loadAct` 会把 `>` 开头的行整行丢掉，而〔静音 X 秒〕会被 TTS 念出来。这一版引句写成正文段，停顿写 `⏸`。

另外**故事段落到 776 字，在 700–900 区间内**，加的全是环境与重复动作（规则 6），
并把三处「桌上」统一成了「那块布上」——摊子支在墙根，没有桌子。

## 这条线的管线是这一期顺手加出来的

`zhiyu-lines.ts` 顶上写着「加第三条线的时候，应该是往这张表里加一项，
而不是再去六个文件里各改一处」。这一期兑现了那句话，加的东西是：

| 加在哪 | 加了什么 |
|---|---|
| `paths.ts` | `OUT_CHAN` —— 成品落 `projects/禅佛典/` |
| `zhiyu-lines.ts` | 一项 `禅佛典`：音色仍是「夜读」、cpm、缺省床音、赭石色板、`check: 'chan'`、封面脚本、产物名 |
| `zhiyu-scene.ts` | 两个镜位 `饼摊` / `空墙根`，和 `ChanShot` 类型 |
| `xinli-cover.ts` | series `zenParable`（赭石 ＋ 圆印）、motif `摞饼与半块` |
| `chan-check.ts` | **新文件**，这条线的体检：七段结构字数 ＋ 硬规则 1/4/5/7/8/11/12 |
| `zhiyu-episode.ts` | 体检分流多认一个 `'chan'` |

**封面没有另写一个脚本。** 稿源 §七之二 的封面规范跟心理线是同一套骨架
（和纸底 ＋ 木格窗框 ＋ 竖排标题 ＋ 落款位印 ＋ 底部细进度线 ＋ 木刻线描 motif），
差别只有 series 那一组值和 motif —— 两样都能按名字注册，没有理由复制一份 429 行的文件。

### 落地时改过三处

**① motif 缩到 320 是一条鱼。** v1 画的是三张分开的椭圆 ＋ 旁边一个半块，
缩到 320px 之后椭圆读成鱼身上的横纹、半块的收口读成鱼尾。
稿源 §七之二 记着的两次翻车（井口被看成气球、竹简像相机镜头）是同一种。
v2 把一摞改成侧看的柱体加一道分层弧，半块改成**实心填一半的圆**（切面朝外）—— 一眼就是「有一个只剩一半」。

**② 饼摊那一景第一版几乎看不见。** 灶身用了 `ridge`，跟墙的 `far` 只差一档，
1920 上就是一块不存在的浅方块，鏊子那个椭圆浮在半空像一张桌子。
改成物件用 `ground`、物件上的东西用 `subject`（墙是最浅那一档，东西压在前面才立得住）。
**没有再往深里走** —— `inkDim` 是文字那一档，画进景里深夜会跳出来。

**③ ⏸ 的体检不能照抄心理线。** 那份查的是「总数是不是偶数」，
而这条线冷开场两拍之间还有一个换气用的 ⏸，总数天然是奇数，照抄每期都会报一条假警。
改成查位置：引句段各 2 个、收束段 2 个（静音 → 经文 → 静音，这是本线的识别点）。
