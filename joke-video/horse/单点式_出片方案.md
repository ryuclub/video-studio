## 收尾卡

**尾卡固定排在日子牌正下方，日子牌和尾卡同时上。**

一个报「第几天」，一个报「后来怎么样了」，两条都是事实，**观众一眼读完两行**。
分两次上字等于让人读两回；两行分居画面两处，等于两处零散的字。

走到这一版之前试过两个位置，都不对，记下来免得再绕：

| 试过 | 为什么不行 |
|---|---|
| 脚下那片空地（`y = 0.86H`） | 规范原文写的是「居中偏下」，但它离日子牌隔了大半个画面，两行字各说各的 |
| 跟着落点符号走（符号正下方） | 符号**不是每条都有**，没有的那些条又要另找地方；而位置是规矩，规矩不该有两套 |

**位置跟着日子牌走才是稳的：日子牌每条都有。**

⚠ **有尾卡的时候，落点符号往下让一档**（头框 3% → 10%）。
符号的缺省高度正好落在尾卡那条横带上 —— 1858 实测那三个点从「第二天早上」几个字中间穿过去。
**让的是符号不是字**：字那一行的位置是规矩，符号只是贴着头，往下挪一点照样贴着。

### 收尾：不是每条片子都该出收尾卡

收尾卡是定格去色那一帧上唯一的一块藏青，要亮着让人看见、让人记住这个号。

**2026-08-21 起它是一张日子牌**（`老马的第 1847 天`，一稿一天往下加，
分配表在 `horse/CHANNEL_LAOMA.md` §五之二）。原来那句固定的「老马，今天也没辞职。」
是**段子的 CTA**，而 CTA **往一条不是段子的片子后面一贴，就成了「刚才那是个段子」**。
日子牌不表态、不俏皮，这个毛病没有了 —— 但下面这条判断仍旧成立：
稿 5《天气预报》没有可笑的地方，靠的是「拦不住」；最后跳出来一行俏皮话，
前面三十秒就白攒了。

所以这一档是可选的：不写 `hook` 就没有收尾卡，配 `fadeOut` 走黑场。

```json
"freeze": 2.6, "hold": 1.4, "fadeOut": 1.4
```

**先褪色，再灭灯。** 定格去色是「颜色抽走」，黑场是「灯灭了」，两回事 ——
黑场那层黑画在最外面，把字幕、钩子、片头卡一起吞掉：
黑场的意思是「片子关上了」，留一行字在黑里飘就不是关上，是没关严。

⚠ 发布文案和分镜表都认这一档：没写 `hook` 的时候末行打
「收尾黑场，不出收尾卡」，不再打空的「说破段落点「」」——
**那看着像漏填了，而它是有意不填的**。

## 五之二、尾卡事实句（2026-08-24 立）

落点之后、收尾卡之前，屏幕上再出现一行字，**老马不开口 —— 只显示，不念。**
稿件字段 `tailCard`，不写就一帧都不占（片长跟以前一模一样）。

### 这一行必须是事实，不能是感想

老马的第一条硬禁令是**不解释**，而金句是解释里最响的一种 ——
它把观众刚刚自己想到的东西，又替他们说了一遍。**观众完成的那个「哦」，必须留给观众自己完成。**

| 落点 | ✗ 金句 | ✓ 事实 |
|---|---|---|
| 那瓶水他一口没喝 | 有些好意，接不住 | 第二天那瓶水还在桌上 |
| 他没起来，又坐了一会儿 | 我们都在被生活推着走 | 电视一直开到十二点 |
| 那天我喝了四次空杯子 | 成年人的体面都是装的 | 三舅走的时候拍了拍他肩膀 |

### 唯一的写法：把时间往后推一格

不解释刚才发生了什么，**只告诉你后来怎么样了**。四种推法：
**第二天** / **当晚·后来** / **下一次** / **同一场景里的另一个人**。
第四种最锋利，因为它把镜头从老马身上挪开了一下。

**反向检验**：这句话删掉，观众对这条片子的**理解**有没有变化？
没变化、只是余味淡了 → 合格；**变清楚了 → 它在解释，废掉重写。**

### 硬规则（体检查得了前五条）

① 必须是可观察的事（有时间、有动作、有物件，没有心理活动）
② **不许出现第二人称或泛指人称** —— 你 / 你们 / 我们 / 谁 / 大家，跟配额句同一条闸门
③ 不许出现解释词 —— 真实 / 都懂 / 就是这样 / 扎心 / 其实 / 终究 / 原来 / 有些人 / 成年人
④ 不许重复落点里的物件动作（落点写了「一口没喝」，尾卡就不能再写喝不喝）
⑤ **长度 ≤ 16 字**，一行不折行
⑥ ~~**使用率 ≤ 1/5**，每五条最多一条~~ —— **2026-08-25 作废**。

> ⚠ **单点式片子要有收尾卡和尾卡事实句这两样，不能变**（用户当天原话）。
> 尾卡从「配额」变成了**格式的一部分**，跟日子牌一个地位：一个报「第几天」，
> 一个报「后来怎么样了」，两条都是事实，观众一眼读完两行。
>
> 两条规矩不能同时留着：留着使用率，每条稿子都会挨一次警告，
> 而**天天报的警告等于没有警告**（这条线为这件事栽过一次 —— 「四行永远消不掉的提醒
> ＝ 这条检查以后会被当背景噪音」）。所以 `laoma-check` 里那条使用率删了，
> 换成**缺了就报硬伤**。
>
> ⚠ **配套动作：001–009 全部补了 `"legacy": true`。** 尾卡这东西 2026-08-24 才立，
> 那九条出片的时候还没有这回事，不标的话它们当场变成不合格 ——
> **改规矩的配套动作永远是「先把靠旧规矩活着的都钉死」**。新稿子不许写这个字段。
>
> ⚠ **累积式不受这条管**：它不带日子牌、不出收尾卡、也不出尾卡（体检拦）。

### 跟配额句二选一

配额句是老马**说**的一句带情绪的话，尾卡是屏幕**显示**的一个事实。
同一条里两个都上，等于连着捅两下，**第二下必然弱**。体检默认拦，
真要都留写 `"allowBoth": true`。

### 第一次用 `allowBoth`：1863（2026-08-24）

规范说二选一，1863 两个都留了 —— **知情的例外，不是缺省。**

用户的判断：**这条太冷，只靠落点不一定看得懂，看不懂就更没意思。**
落点是「我没起来，又坐了一会儿」，一个字的情绪都没有；配额句（第 4 句「我想起来了」）
是全片唯一一处让人知道「他确实想起来了」的地方 —— 拿掉它，观众可能只看到一个人坐着不动。

顺带记一条实现上的死结：**这条的配额句拿不掉。** 试着把 `emotionLine` 置空，
体检立刻报「第 4 句是情绪句：命中『想起』，而这一条一句都没点名」——
那句话本身就带情绪，不点名反而是违规。所以想留尾卡，路只有 `allowBoth` 一条。

⚠ **规范那句警告仍旧成立**：连着捅两下，第二下必然弱。
第二下还是**屏幕上的字**，力气本来就比说出来的那句小。
所以这是一次「宁可弱一点，也要让人看懂」的取舍，**不是把二选一那条作废**。

⚠ **尾卡跟评论区应答会撞。** 1863 的尾卡是「电视一直开到十二点。」，
而预写回复里原来有一条一模一样的（回「这是不是老了」）——
屏幕上已经出过的话，回复里再说一遍就是复读。**上尾卡之后要回头扫一遍 `replies`。**

### 排版必须冷

| 项 | 规格 |
|---|---|
| 字号 | 正文字幕的 **0.8 倍** |
| 字体 | 无衬线、常规字重、**不加粗** |
| 位置 | **排在日子牌正下方**（`y = 250 + 72×1.4 + 36 + 62`）。**每条都一样，不跟着别的元素走** |
| 描边 / 发光 / 阴影 | **全部禁用** |
| 入场 | 0.2 秒淡入，**之后不动** |
| 停留 | 1.7 秒（`tailHold`，规范给的区间是 1.5–2.0） |
| 背景 | 保持画面最后一帧，压暗 15% |

> **做成大字加黄边的金句卡，内容再对也毁了。**
> 这一行的气质应该像是片子忘了关，不像是片子在总结。

⚠ **颜色这一项跟规范不一样，是知情的。** 规范写的是白字或 `#D8D8D8` —— 那是按深底写的。
老马的画面是**纸白底**，白字压上去等于没有；而「压暗 15%」救不回来：
要让白字读得出得压到六成，那就成了黑场卡，**正好是规范骂的那种金句卡**。
所以这条线用墨色（`#3B322B`），其余照抄。**冷的是气质，不是颜色。**

### 位置与时机：跟符号、日子牌是一组（2026-08-24 用户定）

第一版是照规范排的：尾卡在脚下那片空地（`y = 0.86H`），收尾卡等尾卡走完再上。
出片看了一遍之后两处都改了：

- **尾卡挪到落点符号正下方。** 原来符号在头侧、尾卡在脚下，隔了大半个画面 ——
  符号说的是「他不打算说了」，尾卡说的是「后来怎么样了」，**两件事本来是一组**，
  隔那么远就成了两处零散的字。
  横向取符号与右边界的中点：**正下方是他的头**，压上去就看不清了。
- **日子牌跟尾卡同时上**，不再排队。分两次上字等于让观众读两回；
  一起出反而是一组：日子牌报「第几天」，尾卡报「后来怎么样了」，两条都是事实。

⚠ **那个 +172px 是量出来的，跟场景有关。** 符号正下方 118px 处正好压着工位那扇窗的横档，
字被一条线从中间穿过去。**换场景要再看一眼静帧。**

## 五之四、停顿符号（2026-08-24 立）

**中途的停顿里给一个符号。** 稿件写在那一句的 `line.emote` 上，挂的是**这一句说完之后的那段停顿**。

> 立这一条的原因：三十秒一张不动的脸，中途只有眼动在撑。
> 1863 出片之后用户的话是 —— **太冷场，会很无趣。**

### 两套符号都能用

| 库 | 有哪些 | 配额 |
|---|---|---|
| `emote.mjs` **没有情绪的八个** | 省略号 / 一横 / 小问号 / 数字 / 日历 / 小钟 / zZ / 下沉箭头 | 停顿符号全片 ≤2 |
| `marks.mjs` **情绪符号十个** | 惊 / 惊二 / 问 / 汗 / 点 / 闪 / 云 / 灯 / 冷 / 星 | **近 5 条最多 1 条**（跟 `endMark` 共用同一份账） |

**情绪符号 2026-08-24 从「一律禁用」改成「配额」**，用户定的：偶尔用是可以的，不然视频很无趣。
理由照旧记着 —— 它们是画面替观众表态；但「偶尔」这个词本身就是配额，
**写成数字机器才拦得住**：写成提醒的话，提醒久了就麻木，迟早每条都有。

### 挂在哪儿：只挂 ≥0.8 秒的句末停顿

浮现要半秒多，**0.3 秒的停顿里塞进去只会闪一下**（1863 五句全是 0.3，所以那条一个都没挂）。
时间窗是「语音结束 +0.15 秒 → 下一句起头前 0.1 秒」，**绝不跨句**。

### 三条硬规矩（体检守）

① **停顿 ≥0.8 秒**，短了直接拦
② **落点句、以及它前一句的停顿里不许挂** —— 那是「这里好笑」的提示
③ **全片 ≤2 个**，加上落点符号 ≤3；两个不许用同一个符号

⚠ **不拦「这个停顿里有闭目」**（一度拦过，2026-08-24 去掉）：
**闭目和眨眼本来就是日常动作**，不是一件跟符号抢戏的事 —— 人停下来的时候本来就会闭一下眼。

⚠ **符号不许图解刚说完的那句话。** 它是他停下来时脑子里那点东西，不是台词的插图。
1871 第 3 句「想让她照着做」原来给的是 `question`（没听懂）—— **不搭**：
他不是没听懂，他是做完了没等到回应，那是「点」（三个点 · 无语）。

| 停顿 | 台词 | 符号 | 为什么 |
|---|---|---|---|
| 第 2 句后 1.47s | 我说往后一点，她把手机举得更近了 | **汗**（尴尬心虚） | 无奈。这一类里最认得出的那个 |
| 第 3 句后 1.91s | 我把自己的手机往后挪，想让她照着做 | **点**（三个点 · 无语） | 做完示范，等到的是没有下文 |

## 六、稿件体检（`laoma-check.ts`）

`SCRIPT_GUIDE.md` §六 那张十一条的自检表写着「有一条不过就不发」，
**但它是一张复选框，没有代码在守**。稿 1 就是照结构填出来的 ——
形式全对、流程全通、一路绿灯，可片子出来「总觉得没亮点」。
回头拿那张表对，当场挂掉一条硬伤：**落点句 41 字，上限 15，超了 2.7 倍**。

```bash
npx tsx src/laoma-check.ts jokes/laoma-001.json
```

**文字项**：落点句字数、铺垫个数、落点后还有没有话、问句结尾、感叹号、
下判断的形容词、网络热词、说教句式、第一人称、模糊量词、全片时长、镜别切换。

**「像不像真事」那几项**（SCRIPT_GUIDE §一之十二到十六 ＋ §二「通篇四不」，2026-08-22 加）：

| 拦什么 | 判据 | 机器查得了多少 |
|---|---|---|
| 物件不是物件 | 没写 `object`；或它是纯外观描述（颜色/材质/新旧/大小）；或它只出现在 1 句里 | **大半**。「删掉它有没有句子说不通」查不了，只提醒 |
| 落点是反应不是事实 | 落点命中 `差点|几乎|居然|竟然|忍不住|莫名|才发现|原来|不由|有点想|想起|我觉得|我以为|说不上来` | 词表拦得住典型的 |
| 落点里没有数字 | — | 只提醒（「具体名词」查不了，数字查得了） |
| 钩子埋了没回收 | `hookLine` / `payoffLine` 两句去掉停用字之后一个实词都不重叠 | **查得了**，见下 |
| 单句太长 | 一句 >24 字（硬伤）；≥3 分句且 ≥20 字（提醒） | 全查得了 |
| 数字撞车 | 近 10 条用过同一个 ≥10 的数（账本 `horse/used-numbers.json`）；没有「不圆」的数只提醒 | 全查得了 |
| 通篇在解释 | 命中 `其实|说明|意味着|大概是因为|可见|也就是说|这就是|所谓` | 词表拦得住 |
| 首尾没扣上 / 出现颜色描述 | — | 只提醒 |

**尾卡与符号那两组**（§五之二 / §五 末，2026-08-24 加）：

| 拦什么 | 级别 | 判据 |
|---|---|---|
| 尾卡出现人称 | ✗ | 你 / 你们 / 我们 / 大家 / 谁 —— **尾卡是说给画面的，不是说给观众的** |
| 尾卡命中解释词 | ✗ | 真实 / 都懂 / 就是这样 / 扎心 / 其实 / 终究 / 原来 / 有些人 / 成年人 |

| 缺收尾卡 ／ 缺尾卡事实句 | ✗ | 单点式两样都是必备的（2026-08-25）。标了 `legacy` 的老片子跳过这一组 |
| 用了漫符 | ✗ | 老马线的落点符号改走 `endEmote`，**漫符整套在这条线上禁用** |
| 落点符号名不存在 | ✗ | 不在 `horse/emote.mjs` 的 `SYMBOLS` 里 |

**查不了的仍旧是决定性的那几条**：这一行删掉观众的理解会不会变（尾卡合不合格的**唯一判据**）、
回复里有没有共情、五种回法用得对不对。**体检全绿不等于好，只等于没有明显的形式硬伤。**

### ⚠ 三个新字段

```jsonc
"object": "小门",        // 承担叙事功能的物件，必须在 >=2 句里出现
"hookLine": 4,           // 钩子埋在第几句（1 起算）
"payoffLine": 6          // 第几句回收
```

**`object` 跟 `props`（摆进画面的道具）不是一回事：这个物件不进画面**，
进了画面就成了图解台词。

⚠ **`object` 是从 `prop` 改名的，语义一起翻过来了。**
旧的要「闲置的、删掉毫发无伤的」东西，照那条写出来的是 007 的「发票是绿的」
和 008 的「挂号单是粉色的」—— **两句都是贴上去的装饰，只出现一次，删掉毫发无伤。**
「未解释」和「闲置」是两回事：**物件要有用，不给的是解释。**
体检里那两条 `APPEARANCE` / `COLOR_WORD` 正则就是照这两句写的（「粉色挂号单综合症」）。

### 钩子回收为什么从「查不了」升级成了硬伤

原来的做法是把钩子末句和落点并排打给人看，理由是「量度回收（007 的
『优化了一个流程』→『第十一天』）两句可以一个字都不重叠」。

**那个让步是错的。这是听觉媒介，观众没法回看。** 换了同义词或者只靠语义呼应，
观众得先认出「哦这说的是刚才那个」，那一下的迟疑正好盖住笑点。
现在按 `hookLine` / `payoffLine` 点名的两句做字面重叠比对 ——
**滤掉一张停用字表**，因为「小门」和「小时」共用一个「小」不是呼应，
没有那张表任意两句中文都能凑出重叠字，这条检查就恒过。

**表情项**（§五 的规范，后加的）：

| 拦什么 | 判据 |
|---|---|
| 连续 6 秒排不进眨眼 | 停顿太密或太短，观众会读出「静图配音」 |
| 闭目超过一次 / 用在落点句 | 它读作忍耐，用两次就廉价了；落点闭上等于丢掉最重的一眼 |
| 闭目咬进下一句 | `closeEyes` ＞ `padAfter` ＋ 下一句 `padBefore` |
| 落点句点了表情 | 脸在替台词做解释，笑点就成了图解 |
| 说话标记全程常亮 | `byBeat` 没写，或者没有一档是 0 |
| 情绪符号超过 1 个 | 画面在替观众下判断 |
| 转折句/落点句有一屏超过 12 字 | **笑点在被听到之前就消费掉了** |

**首片形式项全绿，表情项当场挂掉四条**：24 秒没眨眼、落点句眯着眼三秒、
说话标记挂满 29 秒、转折句字幕整段预铺。**这四条一条都不是品味问题，
都是规范里写死的数** —— 而人照着结构填稿的时候最容易漏的正是这些数。

**查不了的三条恰好是决定好不好笑的三条**：一条只有一个笑点吗、误导公不公平吗、
转折的线索前面出现过吗。所以：**体检全绿不等于好笑，只等于没有明显的形式硬伤。**

## 六之二、已出的三条

| | 栏目 / 场景 | 片长 | 收尾 | 这一条试出来的东西 |
|---|---|---|---|---|
| 稿 1《收到》 | 工位 / `office-desk` | 0:30 | 收尾卡 ＋ 大汗珠 | 表情规范整套的第一次落地 |
| 稿 5《天气预报》 | 回家 / `street-night` | 0:31 | **黑场，不出卡** | `openMouth` 张嘴无声、`fadeOut` |
| 稿 4《看哪儿》 | 众目睽睽 / `elevator` | 0:22 | 收尾卡 | 场景本身当道具（楼层屏那个 12） |

三条刻意换了栏目和场景 —— 前三条是给完播率看的样本，
一个栏目连发三条，看不出是形态的问题还是选题的问题。

**《看哪儿》示范了一件值得复用的事：让场景替台词说话。**
落点是「七个人，看同一个不会变快的数字」，而 `elevator` 场景里那块楼层屏
写死是「12」，整条片子一格不动 —— 观众听到落点的时候不用想象，
他已经盯着那个数字看了二十秒了。选场景的时候先问一句：
**这条稿子的落点指着什么东西？那东西能不能一开始就在画面上？**

⚠ 也在这一条上摔了一跤：为了躲平台顶部的 UI 把楼层屏往下压了 112px，
结果**撞上了收尾卡**（钩子字幕画死在 y=250），藏青的字压在深色屏上直接看不见。
原位置本来不撞。教训是**场景里靠上的元素跟收尾卡是同一片地**，
挪之前先看那一片有没有别人 —— 而「被顶部 UI 盖住」那个担心本身也是虚的：
盖到的是空框上沿，数字在 120–190，看得见。
