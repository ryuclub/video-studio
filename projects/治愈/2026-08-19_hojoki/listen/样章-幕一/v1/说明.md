**`试听-方丈记-幕一.wav`** —— 这是默认档。
另外两个只是音乐大小不同，**人声完全一样**（同一条 wav 混出来的），不用重听内容。

| 文件 | 音乐响度 | 比人声低 | 成片响度 |
|---|---|---|---|
| `试听-方丈记-幕一（音乐-34）.wav` | -34 LUFS | 13 LU | -20.9 LUFS |
| `试听-方丈记-幕一.wav` | -38 LUFS | 17 LU | -21.0 LUFS |
| `试听-方丈记-幕一（音乐-42）.wav` | -42 LUFS | 21 LU | -21.0 LUFS |

`人声-无音乐.wav` 是垫在底下的那条。判**稿子调性**用它，判**音乐大不大**用上面三条。

## 音乐

`1.wav`。三条素材里挑它的理由是量出来的：

| | 时长 | LRA（起伏） | 4kHz 以上 | 首尾电平 |
|---|---|---|---|---|
| **1.wav** | 10.3s | **0.6 LU** | −52.4 dB | −18.0 / −17.9 |
| 2.wav | 36.0s | 6.8 LU | −55.1 dB | −31.5 / −17.3 |
| The Enchanted Castle | 13.0s | 2.4 LU | −48.0 dB | −19.2 / −17.3 |

LRA 0.6 说明它几乎没有起伏，是条持续的 pad —— **不会在人声底下冒头**，
这正是助眠档要的。首尾电平又对齐，本来就是给循环用的。
2.wav 带淡入（首尾差 14dB），硬接会爆音，而且 6.8 LU 的涨落在深夜档会把人拽醒；
Enchanted Castle 的 1kHz 那一档最厚，正好是人声的地盘。

床是**自己跟自己交叉淡化、翻倍**接出来的（不是 `-stream_loop`，那个会在接缝爆音），
淡入 6s、淡出 8s。

## 链路

```
Edge 合成 → 变声(pitch 0.83 / formant 0.83)
→ 按段拼接（段间 1.25s，⏸ 处 3s）+ -62dBFS 粉噪底噪
→ highshelf 8kHz −3dB → 窄压缩 2:1 (30ms/200ms)
→ 响度归一 -21 LUFS
→ 混入音乐床（人声居中，音乐保留立体声）
```

停顿这个长度**只有垫了底噪才成立**：TTS 插的是绝对静音（实测 −227dB），
现实里没有这种东西，没底噪时停顿越长越像卡带、不像酝酿。
输出是立体声 —— 稿件要求「戴耳机暗房听」，音乐的宽度在耳机上才有意义。

## 实测

| | |
|---|---|
| 基频 | 202 Hz |
| 半音标准差 | 4.37（目标 1.5–2.5，见方案文档「一条没解决的」） |
| 说话速度 | 303 字/分 |
| 含停顿均速 | 212 字/分 |
| 人声响度 | -21.0 LUFS / 真峰 -4.2 dBFS |

**含停顿均速**是反推整期字数配额的那个数（幕表按 218 字/分 × 45 分钟 = 9800 字）。
这一段的均速要是跟它对不上，配额得跟着重算 —— 样章的停顿点比正片密，
偏低是正常的，偏得太多才要动幕表。

## 听完要回两件事

1. **调性** —— 稿子是「只记事、不评论」的冷淡写法，情绪全靠「他说」转述出去。
   这个冷淡程度对不对。点头我就按幕表把剩下约 8900 字补齐。
2. **音乐大小** —— 三档里哪一档。以及要不要换 2.wav / Enchanted Castle 听听
   （`--bgm 2`，重跑只混音、不重新合成，TTS 有缓存）。

> **这是 v1（停顿 1.25s / 3.0s），已被 v2 取代。** 反馈是「停顿有点久」。
> 音乐档在这一版里选定为 −42 LUFS。留档用，不要再听。
