# 累积式 · 字幕

> 并入《累积式_出片方案.md》。共用层（rig / 场景 / 音色 / 管线 / 发布）见 `BASE.md`，此处只写与单点式不同的部分。

---

## 为什么单独立一节

**单点式的字幕在防剧透，累积式的字幕在造节拍。**

单点式怕的是观众读完落点才听到落点，所以规则是拆屏、少给、晚给。
累积式怕的是排比塌成一段话，所以规则反过来：切齐、对齐、看得见重复。

两套规则在好几处正面冲突，**不要互相参照，也不要从单点式那边继承缺省值。**

---

## 六条规则

### 1. 排比句一句一屏，绝不合并

```
✓  第一趟少一张复印件
   第二趟章盖错了地方
   第三趟系统在升级
✗  第一趟少一张复印件，第二趟章盖错了地方，第三趟系统在升级
```

合并之后排比就成了一段话。**重复要看得见，才有累积感。**

### 2. 状语和结果必须同屏

「认认真真地犯了很多错」不能拆成两屏。那个错位就是笑点，拆开等于把笑点切成两半，而且前半屏还剧透了后半屏。

与第 1 条合起来意味着：**分屏按语义单元切，不按字数切。** 一屏 12 字放不下，改写句子，不靠拆屏解决。

### 3. 位置锁死，一格不动

排比段每一屏出现在完全相同的 y 上。**竖向对齐是「这是一串」的唯一视觉信号**，动一格就散了。

### 4. 最短驻留 0.6 秒（硬底线）

累积式句间压到 0.35–0.45 秒。字幕若严格跟着语音起落，会出现 0.4 秒一闪，读不完。

做法：**字幕早于语音 0.1 秒出，晚于语音结束 0.15 秒撤**，用重叠换驻留。

### 5. 数字用阿拉伯数字

| 写法 | 说明 |
|---|---|
| 600 多 / 2800 / 17 个 | 快节奏下识别快一档，与汉字混排也有对齐感 |
| 第一趟 / 第二趟 | **序数仍用汉字**，「1 趟」读起来不对 |

### 6. 落点拆两屏，理由不是防剧透

「不过这样也挺好，至少死的是绿萝，不是我」拆成：

```
屏 A   不过这样也挺好          ← 停一拍
屏 B   至少死的是绿萝，不是我   ← 驻留 1.2 秒，全片最长的一屏
```

拆的目的是**给那一拍腾出位置**，不是怕提前读到。

---

## 签名屏

「不过这样也挺好」在全部条目里逐字相同。字幕上反复出现同一行字，会长成频道的记忆点——像个签名。

**成立的前提是完全一致。** 位置、字号、入场方式、驻留时长四项锁死，任何一条飘了，就只显得偷懒。

建议单独一套样式：略大（比正文大 1 档）、居中、驻留 0.9 秒、无位移入场。

## 体检要加的三条（2026-08-25 已并进 `laoma-check.ts`）

按稿件 `format: "cumulative"` 分流，**不写就是单点式**。具体判据和实现见
《累积式_出片方案》§六 —— **这儿不重抄，抄一遍就等着分叉**。

| 拦什么 | 级别 | 判据 |
|---|---|---|
| 一屏驻留 < 0.6 秒 | ✗ | 计入前后重叠之后仍不足 |
| 排比段合并成屏 | ✗ | 同一屏内出现 ≥2 个序数标记（第一/第二/第三、一趟/二趟）或 ≥2 个同构分句 |
| 状语与结果被拆开 | ! | 一屏以「地」「得」结尾，或以副词短语单独成屏 |

另外三条从单点式**显式停用**（写成关闭，不是漏填）：落点整句一次性打出的拦截、转折句一屏 ≤12 字的上限、以及尾卡那一整组检查。
