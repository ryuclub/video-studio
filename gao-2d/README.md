## 二、怎么用

```bash
node gao-2d/入库.mjs          # 美术给了新文件之后跑（会重写素材册）
node gao-2d/查.mjs            # 出片前跑；美术重导之后**必跑**
node gao-2d/看.mjs            # 12 张对照图，挑姿势

node gao-2d/画.mjs            # 出表情演示表 _表情.png
node gao-2d/头.mjs            # 出头动演示表 _头动.png
node gao-2d/index.mjs         # 重出汇总页 projects/高总/index.html
node gao-2d/index.mjs --force # 连页面上的图一起重渲
```

出片那一半（规范在《角色集成规范》和《英文频道出片方案》）：

```bash
node gao-2d/出帧.mjs                        # 五组 B 层帧序列，一次性，全频道共用
node gao-2d/出帧.mjs --验                   # 另出接缝图，拿眼睛看循环接不接得上
node gao-2d/build.mjs uk_potholes --check   # 八项自检，不跑 ffmpeg
node gao-2d/build.mjs uk_potholes           # 全量合成
node gao-2d/build.mjs uk_potholes --only 7  # 只重建第 7 块
```

```js
import { 渲脸 } from './gao-2d/画.mjs';

渲脸('gao-2d/素材库/svg/正面站立.svg');                    // 原件（图元一条不增不减）
渲脸(file, { 眨: 0.4 });                                  // 半睁
渲脸(file, { 眨: 1 });                                    // 全闭
渲脸(file, { 眼x: -1 });                                  // 眼珠看左（-1..1）
渲脸(file, { 眼y: 1, 眨: 0.3 });                          // 往下看
渲脸(file, { 嘴: '小' | '大' | '扁' });                    // 口型（默认 '闭'）
```

```js
import { 渲人 } from './gao-2d/头.mjs';

渲人(poseFile, { 点头: 1 });                              // 低头（+1 低头，-1 抬头）
渲人(poseFile, { 摇头: -1 });                             // 摇头
渲人(poseFile, { 点头: 0.8, 表情: { 眨: 1, 嘴: '大' } });   // 头动 ＋ 表情
```

`渲人` 不给 `点头`/`摇头` 时**直接转给 `渲脸`**，不叠头部层 ——
不动头的那些帧跟原来一个图元都不差。

⚠ **不给参数时原样返回。**「这一帧没表情」和「原件」必须是同一张图 ——
不然一过处理就悄悄变样，而且不报错。

## 三、六种姿势 ＋ 头部层

| key | 名 | scale | 眼 |
|---|---|---|---|
| `side-stand` | 侧面站立 | 1.5333 | 1 |
| `side-hand` | 侧面抬单手 | 0.8118 | 2 ← 四分之三侧，两只眼都露着；**点头摇头用不了** |
| `front-stand` | 正面站立 | 1（基准） | 2 |
| `front-hand` | 正面抬单手 | 0.9452 | 2 |
| `front-wave` | 正面单手打招呼 | 0.9583 | 2 |
| `side-walk` | 侧面走路 | 1.5333 | 4 帧 |
| `front-walk` | 正面走路 | 0.7667 | ⚠ **只有 2 帧** |
| `head` | 头部单图 | —— | 叠在正面姿势上做点头摇头 |

**对位按脸高归一化**，不按整体墨高 —— 抬单手那几张手举过头，
墨高里含着手，按它缩放一换姿势人就矮一截。
帧序列的水平锚 `ax` 是**一组共用一个**，各帧按自己墨心锚的话走路时人会左右平移。

三批素材是分别导出的，各用各的缩放，比例约 **1 : 1.58 : 2.0**。

## 四、表情是怎么做的

**眼睛不重画。** 重画一双杏仁眼一定比原画难看，所以只做两件事：

- **眨眼** = 整只眼 clip 掉上半截，切口上补一条上眼睑线；全闭时整只眼抠掉，画一条弧
- **转眼珠** = 只给眼珠那几条加 `translate`

只有两样是新画的：**全闭那条弧**（闭着的眼没有原画）和**张开的嘴**
（美术给的嘴是一条闭合的线，没有张嘴的图）。

### 眼睛怎么认出来的

**眼白打种**，不是邻近聚类。第一版用「盒子挨着就并一簇」，
**右眼那簇把镜框和头发并进来了**（40×30，左眼才 27×21）—— 高总戴眼镜，
镜框是一条独立 path 紧贴眼睛外沿，邻近法分不开「挨着」和「是同一个东西」。

现在的做法：先按颜色捞眼白（近白、低饱和、脸的上 60%、面积占脸 0.4%–10%），
横向并簇（间距 ≤ 脸宽 15%），一簇一只眼；再收两档图元 ——
完全落在眼盒子里的（虹膜／瞳孔／高光／下眼睑影），
和**盖住自己一半以上、且不超过眼盒子 1.3 倍**的（杏仁外框，它比眼白大一圈装不进盒子）。

第二条判据的余量是实测的：外框 #140 盖 76%、1.04×1.19；镜框 #118 盖 33%、1.40×1.47。
**两边都不能松**：只按「重叠」收会把镜框一起抠掉，只按「完全包含」收会漏掉外框 ——
漏了的表现是抠完眼睛**脸上留着两坨黑**，不报错。

### 三个踩过的坑

1. **右眼的反光留在原地** —— 转眼珠时右眼碎成一片。虹膜下缘那道反光（#159）
   探出眼珠 2px，按「完全包含」收不着。判据放宽到「盖住自己 40% 以上」。
   下眼睑影不会被误收，它只盖 27%。

2. **clip 用眼白 → 从虹膜中间剜一刀。** 这个角色的「眼白」不是一整块眼球，
   是虹膜两侧的**两条白牙**（#151 管 129–137、#150 管 142–153，中间 5px 空着，
   原本被虹膜盖住）。

3. **clip 用「外框」→ 虹膜只剩碎渣。** 因为**两只眼画法根本不一样**：
   左眼 #140 确实是一圈杏仁外框，右眼 #149 **只是上睫毛**。

   最后**转眼珠不 clip**，靠限制行程（眼珠挪不出眼白的横向范围，留 15% 余量）。

> 这三条全是**肉眼在 `_表情.png` 上看出来的**，机器一条都不报。
> 第 3 条是把右眼 9 条图元一条条单独渲出来才看清的（`_右眼分解.png`）——
> 光看合成图只知道「碎了」，不知道为什么碎。

## 四之二、点头／摇头（头部层）

2026-09-08 美术补了 `头部.svg`（独立一张正面头，66 条图元），这条路才通。
在这之前做不了：整figure 里**头和身体的 path 下标不连续**
（正面站立头部 62 条散在 2–159 之间，中间夹着 95 条身体的），整组 `transform` 会把身体一起带走。

做法（`头.mjs`）：把姿势自己的头抠掉，叠上 `头部.svg`，绕脖子根转。

**对位按两只眼的中心**：缩放 = 眼距之比，平移 = 对齐眼心。
不按脸的包围盒 —— 脸是靠「上半部最大的肤色块」认出来的，边界会随头发遮挡浮动几像素，
而眼心是两个几何点，稳。实测头部 vs 正面站立眼距 57 vs 57.5，缩放 1.0026，
基本是同一份画裁出来的（**抠掉的正好 66 条，跟头部.svg 的图元数一模一样**）。

**抠头的判据是「头盒子盖住这条图元的 40% 以上」**，不是「完全落在头盒子里」。
第一版按「完全包含」写，漏网三条：一大块头发 `#4` 底边探出头盒 10px（盖 92%），
和脖子两侧一对 `#45`/`#46`（盖 47%）—— 表现是**头一动，脸边上飘着一条黑线、左脸多出一块黑斑**。
这里有干净的空档：该抠的 47–92%，该留的（脖子 `#43` 盖 19%、外套 `#2` 盖 4%）差得很远。
反过来「重叠就算」会把外套和肩膀一起抠掉。

三个限制：

- **只能用在正面姿势上。** `头部.svg` 是正面的，套到四分之三侧的 `侧面站立-抬单手` 上
  是一张正面的脸贴在侧身上。判据是眼心偏离脸心多少：正面 0.7%，四分之三侧 15%，
  中间没有含糊地带。超了**直接抛错**，不是警告 —— 这种错渲出来很显眼，
  但批量出帧的时候没人一帧帧看。
- **抬头的幅度只给低头的三分之一。** 头部图自带两缕鬓角，原本掖在衣领后面；
  头一抬就整条露出来，末端在衣领上戛然而止（2D 分层藏不回去）。低头没这个问题。
- 2D 转不出俯仰，点头是**转一点 ＋ 整颗头往下沉一点**凑出来的。

## 五、闸

`node gao-2d/查.mjs`。核心是**比对源文件 checksum**：
对位、五官分组全是按 **path 下标和几何**算出来的，
而美术在 Illustrator 里重新导出一次**下标就全变，并且不报错** ——
颜色还在、形状还在，只是「第 149 条是右眼睫毛」这个事实悄悄失效，
渲出来是把袖口当眼睛抠掉。

对不上就停，让人重跑 `入库.mjs` 重新量。顺带查：文件在不在、图元数、
脸还认不认得出来、五官分组变没变、帧序列够不够帧。

**这道闸验过会红**：改一个字节 → `✗ 1 条硬伤`、退出码 1；还原 → 转绿。

## 六、resvg 的第四种 panic

前三种记在 `svg-assets-intake`（viewBox 带偏移 / 画布远小于内容 / 对内容做 `scale()`）。
第四种：**同一页拼多张脸时 clipPath 的 id 撞了**，resvg 不报 "duplicate id"，
直接 panic 在 `geom.rs:27` 的 `unwrap()` 上。
`画.mjs` 每次调用换一批 id（`g0bai0`、`g1yan1`…）就是为了这个。

还有一种同源的：**裁得太紧**——外层 viewBox 只框住右眼，
而另一只眼的 clipPath 整个落在可视区外，clip 的包围盒成了空，同一个 unwrap 炸。
所以放大验证要**裁在顶层 viewBox 上**，别用嵌套 `<svg>` 套 clip。
