# 【第一组】暖场。最松弛的状态，像跟朋友聊天。这一组还兼做「参考音频」的取材段。
好，那我就随便说两句。
在日本做房子这行，我做了十几年了。
一开始也不懂，也交过学费，交得还不少。
现在回头看，很多坑其实都写在纸上，只是当时没人告诉你那行字是什么意思。
那行字它不骗你，它就是不解释。
我这个号想做的事就一件：把那行字翻译成人话。
不劝你买，也不劝你不买。
我把我知道的摆出来，你自己看完了自己决定。
有些话中介不方便说，我方便，因为我不赚你这一单。
说错了你们也别客气，评论区直接指出来，我下一条改。
这行里最值钱的东西不是房源，是别人踩过的坑。

# 【第二组】数字。这条线的主力栏目就是讲数，数字念得稳不稳直接决定成片。
这套房当年的利率，是百分之零点三。
不是百分之三，是百分之零点三，中间差着一个小数点。
一个小数点，三十五年下来差多少钱，你自己按一下计算器。
月租十二万八千日元，管理费另算，一万五。
面积二十五点八平米，换算过来大概八个榻榻米多一点。
建成年份是一九八八年，到今天三十七年了。
表面收益率百分之六点二，扣掉税、扣掉管理、扣掉空置期，实际到手大概百分之三点九。
这个差，就是所有中介都不会主动跟你算的那一段。
一百二十五万，三百八十万，两千四百万，你听着差不多，其实差着一套房。
首付两成还是三成，月供差一万七，三十年就是六百一十二万。
再加一句：这些数我都是按今年的行情说的，明年不一定还成立。
数字这东西，你不问它是哪年的，它就随便你怎么理解。

# 【第三组】日语词。这条线绕不开的行业词，克隆音把它念错就整期报废。
房源上写着即入居可，你先别高兴。
礼金两个月，敷金一个月，加上仲介手数料，你还没搬进去，先出去五十万。
每两年一次更新料，又是一个月房租，这笔钱很多人算漏。
管理费和修缮积立金是两笔钱，别搞混。
管理费是养这栋楼的日常，修缮积立金是给二十年后的大修攒的。
大家さん这个词，翻成房东不太准，他更像是这栋楼的看门人。
内见的时候，你要的不是感觉，是重要事项说明书那几页。
不动产屋跟你说这套很抢手，你就当没听见。
定期借家和普通借家，差一个字，续不续得下去完全两回事。
再建築不可这四个字，写在角落里，它的意思是这块地拆了就盖不回来。
瑕疵担保责任现在改叫契约不适合责任了，改了名，坑还是那个坑。

# 【第四组】疑问与反问。语气要往上抬，这是这条线唯一的「重音」来源。
你猜他为什么不让你在白天看房？
这套房上一位租客，是什么时候搬走的？
空了半年，你不问一句为什么吗？
你有没有想过，同一栋楼里，同样的户型，凭什么隔壁比你便宜两万？
这话你信吗？
那你觉得，他图什么？
免租两个月，听着挺好，那两个月的钱谁出？
中介费打五折，你不觉得奇怪吗？
他为什么这么着急让你今天就签？
这栋楼这么好，怎么会轮到你？
说到底就一句话：便宜的那一部分，是从哪儿省出来的？

# 【第五组】列举与长句。一口气说长句的换气位置，模型要学的就是这个。
可能是采光，可能是隔壁，可能是楼里出过事，也可能只是上一任房东嫌麻烦不想再租了。
你要看的是三样东西：楼龄、结构、和这栋楼过去五年的空置记录，前两样写在纸上，第三样得问。
在东京，新宿、涩谷、池袋这一圈的老楼，和港区、目黑那一圈的老楼，虽然都叫老楼，但它们贬值的速度完全不是一件事。
一个在日本待了三年的人，和一个在日本待了十三年的人，看同一份合同，看到的东西不一样，不是因为语言，是因为他见过合同兑现的样子。
所谓的地段好，拆开来其实是四件事：走到车站几分钟、这条线通不通到你上班的地方、周围有没有超市和医院、以及晚上十一点你敢不敢一个人走回来。
一栋楼的价值，一半写在它自己身上，另一半写在它旁边那块空地上，而那块空地要盖什么，卖你房子的人是不会替你去查的。

# 【第六组】短句落点。这条线每期最后一句都是短句，落点稳不稳全靠这一组。

# 【第七组】调侃和无奈。轻度就行，不要演。这条线不做浓情绪。
中介带你看的第一套房，通常不是给你买的。
是给你对比的。
你看完那套，再看第二套，你就觉得第二套真好。
这套路用了二十年了，到今天还管用，你说气不气人。
他倒也不算骗你，他只是没把顺序告诉你。
我当年也是这么被带过来的，还挺高兴，觉得自己捡着了。
后来我自己做了这行，才知道那天的路线是前一晚就排好的。
现在我看房，第一句话就是：把你今天不打算给我看的那几套也发过来。
对方一般会愣一下。
愣那一下，我就知道有没有。

# 【第八组】地名与专名。这些词一期里出现好几次，念法要定死。
东京、大阪、名古屋、横滨、福冈、札幌。
新宿区、港区、涩谷区、目黑区、世田谷区、江东区、台东区、墨田区。
埼玉、千叶、神奈川，这三个地方通勤时间差很多，别一概而论。
丰洲、月岛、门前仲町，这一片这几年变化最大。
山手线、中央线、总武线、东西线，离哪条线近，价格是两回事。
台场那边看着漂亮，你去住一个月试试。
上野和浅草挨着，气质完全不一样。
吉祥寺年年评第一，但那个价格是把这个第一算进去了的。

# 【第九组】合同与流程。整串术语连读，这是最容易念崩的一组，慢一点没关系。
从看房到拿钥匙，一般是六步：内见、申込、审查、重要事项说明、签约、交割。
申込书不是合同，你签了还能退，但很多人以为签了就跑不掉了。
审查看三样：收入、在留资格、和保证公司愿不愿意接。
重要事项说明必须由持证的人当面念给你听，这是法定的，不是走过场。
念到你听不懂的地方，你就喊停，让他解释，这是你的权利。
签约当天带印章、在留卡、住民票，还有第一笔钱。
交割之后，钥匙、火灾保险、和公共费用的过户，一样都不能忘。
整个流程快的话两周，慢的话一个半月，卡在哪儿一般都卡在审查。

# 【第十组】时间、日期、连串数字。这类念法定不下来，成片里就得每期手动改。
二零二五年四月一号起，这条规矩就变了。
上一次修法是二零一八年，中间隔了七年。
每个月十号之前交房租，晚一天保证公司就会给你打电话。
合同是两年一签，到期前三个月要通知。
早上九点到晚上六点，周三定休，这是这一行的作息。
第一年、第三年、第五年，这三个时间点你要各查一次。
房号是三零二，楼是地上八层地下一层。
电话号码零三，五五三六，七八九一。
邮编一六零，零零二二。

# 【第十一组】转折与递进。连接词的语调是句子的骨架，一定要念出层次。
虽然价格便宜，但是它便宜得有道理。
反过来说，如果你只打算住两年，这些问题其实都不算问题。
也就是说，同一套房，对不同的人是完全不同的两笔账。
换句话说，你要先想清楚你是要住，还是要收租，还是要它涨。
更麻烦的是，这三件事经常互相打架。
问题不在于贵不贵，而在于贵在哪儿，值不值。
不过话说回来，这行里也不是全是坑，好中介是有的，只是你得会认。
所以我一直说，你不用变成专家，你只要会问三个问题就够了。

# 【第十二组】自述。第一人称长段落，语气最贴近这条线的真实用途。
我第一次自己买房，是二零一二年。
那会儿我三十出头，手里的钱刚够首付，心里一点底都没有。
中介带我看了七套，我看到第四套就已经分不清了。
最后签的那套，说实话是被气氛推着签的，不是被数据说服的。
那套房现在还在，涨了不少，但我不觉得那是我眼光好。
那是运气，是那几年整个市场都在往上走。
我真正学到东西，是在第二套上，那套我亏了。
亏的原因特别简单：我没查那栋楼的修缮计划，签完第二年就摊了一笔大修的钱。
纸上写着的，我没看。
所以我现在跟人说的每一句，都是从那笔学费里来的。
你可以不信我，但你去把纸上那几行字看一遍，看完你再决定。
这件事没人能替你做。
