# 治愈档视频封面设计规范

适用于「醒木不响」治愈系列（深夜助眠档／单元短篇档）。所有坐标按**成品尺寸 1280×720** 给出。

---

## 一、设计前提：封面和片内画面职能相反

片内画面的任务是**让人不想切走**，所以要无聊、要低对比、要几乎不动。
封面的任务是**在一屏十二个视频里被点开**，必须显眼。

同一套插画语言，三处必须拉开：

| 项 | 片内画面 | 封面 |
|---|---|---|
| 窗框 | 有（五件固定构件之一） | **去掉**，画面顶到边 |
| 主体占比 | 近景不超过画面高 60%；留白档更小 | 放大约一倍 |
| 色阶层数 | 同色相 2–3 层，柔和 | 4 层以上，明暗拉开 |
| 文字 | 竖排标题 **72px SemiBold**（原写 19px @680 宽 ≈ 54px，2026-08-20 加大加粗） | 主位 132px @1280 宽（总封面） |

### 三条硬约束

1. **右下角 240×100 留空**——YouTube 时长角标压在那里。
2. **不放人脸、箭头、红圈、夸张表情。**这套刺激型缩略图语法会招来错的观众，点进来两分钟就走，对完播率的伤害比没人点更大。
3. **元素总数不超过三个**（插画主体 / 书名 / 印章）。手机首页缩略图实际只有约 210px 宽，第四个元素必糊。

### 片内的文字为什么可以比规范大

原来那个 54px 是按「片内一切都要小」定的。但**标题是片内唯一不变的东西** ——
它不闪不动，大一点不会变成让人睁眼的理由，反而让人一眼知道自己在听哪本。

该压住的是**会动的那个**：底部进度线。它每 30 秒才前进 2.5%，
颜色也压到跟纸底只差两档 —— 那才是「几乎不动」这条规矩真正管的对象。

所以片内标题定在 **72px / SemiBold**，比原折算值大三成、重两档。
色值不动（`#5A6E66`，比封面的墨色浅得多）：**要的是「看得清」，不是「跳出来」**，
字号和字重管前者，颜色管后者，别一起加。

## 一点五、两种封面：总封面 / 分期封面（2026-08-20 追加）

原来这份规范只设想了一种封面，主位固定给书名。**实际发的是分期视频**，
一本书拆成两期以上，观众在列表里先要知道的是「这一期讲什么」，不是「这是哪本书」。
所以拆成两种：

| | 主位 | 第二列 | 档位标第二行 | 用在哪 |
|---|---|---|---|---|
| **总封面** | **书名 132px** 墨色 | 作者 30px 灰 | 全 N 期 | 播放列表封面、专辑封面、频道橱窗 |
| **分期封面** | **期标题** 96px 墨色 | **书名 56px 墨色 @0.74** | 上篇 / 下篇 | 每期视频的缩略图 |

**两种的主位字号不一样**，见第四节字号表。总封面旁边只有一列 30px 的作者名，
横向余量大得多，所以能比分期大一档；分期那一列 56px 的书名占掉了空间，96px 就是上限。

**骨架不变。** 竖条宽度、分隔线、印章、色带、留空区、副题位置全部共用 ——
换了骨架就不是一个系列了，两种封面之间也认不出亲缘。

### 书名降级但不缩水

分期封面上书名让出主位，但**不能顺手降成小字**。两条：

1. **56px 是下限。** 再小就跟副题（26px）拉不开层级，书名会被读成又一行注释。
   主位是 96px，56 差不多是六成，一眼分得出主次，又不至于沦为附注。
2. **颜色比字号更管用。** 副题是灰 `#A8A294`，书名要用**墨色**（跟主位同色），
   只压到 0.74 不透明度。试过 0.62，偏淡，读着像水印，「醒目」这条就不成立了。

**缩到 210px 只有主位读得出**，这是没办法的事 —— 规范自己也写了「第四个元素必糊」。
书名在手机播放页那个尺寸读得出就够了，别为了让它在缩略图里也读得出而去挤主位。

### 期标题怎么起

4 字最稳（对应 96px 那一档），5 字是上限。**不要跟副题重意思** ——
《方丈记》上期的期标题是「三米见方」，副题就不能再用「三米见方的屋子」，
换成了「两辆车就能装走」。

## 二、版式：左条 + 右画

```
┌─────────────┬───────────────────────────────────┐
│  0          │ 384                          1280 │
│  米白竖条    │  插画满幅（无边框，四边出血）        │
│  384 宽      │                                   │
│             │                                   │
│  竖排主位    │        总封面：主位＝书名           │
│  第二列      │        分期：主位＝期标题，第二列＝书名│
│  副题钩子    │                                   │
│             │                                   │
│  朱砂印      │                        （此区留空）│
│  档位标      │                                   │
├─────────────┴───────────────────────────────────┤
│  底部色带 12px 通栏 y=708                         │
└─────────────────────────────────────────────────┘
```

**二十期不动的部分**：竖条宽度、分隔线、主位基线、第二列与副题坐标、印章坐标、色带高度。
**每期变的部分**：右侧插画、主位文字、第二列文字、副题文字、墨色、底部色带色。
**总封面和分期封面共用这套骨架**，只换主位放谁，见第一点五节。

## 四、字体与字号

### 字体

| 用途 | 字体 | 字重 |
|---|---|---|
| 中文书名 | 思源宋体 / **Noto Serif CJK SC** | Medium (W5) |
| 日文书名（武蔵野、方丈記、枕草子等含日文字形） | **Noto Serif CJK JP** | Medium (W5) |
| 作者名 | Noto Serif CJK SC | Regular (W4) |
| 副题钩子 | Noto Serif CJK SC | Regular (W4) |
| 印内「醒」 | Noto Serif CJK SC | Medium (W5) |
| 档位标 | Noto Serif CJK SC | Regular (W4) |

**日文那条不是讲究，是必须。**「蔵」「記」「絵」这类字在 SC 与 JP 字形不同，用 SC 排日文书名会出现字形错误，日本观众一眼看得出。凡书名保留日文汉字的，整个书名走 JP。

字体本身可商用、可嵌入（SIL OFL 授权）。

## 六、副题钩子：这套封面真正的卖点

「相模滩的落日」「林子里的三个月」「三米见方的屋子」——这三句都不是书名，是**内容钩子**。

同类频道的缩略图普遍只有书名加「助眠」两个字，多这一行，点击理由就具体了。

**写法**：6–8 字，具体名词优先，不用形容词，不用问句。直接从《治愈系旁白书目_选题稿件.md》里那二十条开场句摘——那批已经按「第一句就要有画面」写过一遍。

## 七、待定与风险

~~**档位标的时长要不要留。**~~ **已定（2026-08-20）：去掉时长。** YouTube 自带角标已经给了，重复占位置；第二行改放分期信息（上篇/下篇，总封面是「全 N 期」）。

**留白款是风险项。**《方丈记》那张符合设计逻辑（内容越接近减法，画面越空），但在缩略图网格里「空」往往被读成「没内容」。它可能表现最好（一片满当当里唯一的空白），也可能最差。**建议单独 A/B，不要跟着系列一起定**。

**已验证的三款**：自然与人生（远景·落日）、武藏野（林中路）、方丈记（留白）。其余两个镜位的封面还没出样。

## 八、生产

- **代码：`joke-video/src/zhiyu-cover.ts`**（2026-08-20 落地）。各期的入参写在
  `projects/治愈/<期>/发布.json`，封面和发布文案共用那一份，两边不各写一份。
- 出图流程：SVG 模板 → PNG。入参：`kind`（book/episode）、`书名`、`期标题`、`作者`、`副题`、`镜位`、`档位`、`label`。镜位决定书名墨色、色带色和调用哪套插画。
- 每套出四个文件：`upload-1280x720.png`（横版上传）、`wechat-1080x1080.png`（微信 1:1）、
  `check-210.png`、`check-square-200.png`（两张自检），外加两个 svg 矢量源。
- **方版不是把横版裁一刀** —— 896 宽的插画区裁成方的会把主体切掉。
  版式语言照搬，比例重排：竖条从 30% 提到 37%。
- 硬约束①（右下角留空）和「书名超 5 字」都是**断言**，越界直接报错，不靠记性。
- 与公众号那套 `cover_studio.py` 是两套东西（尺寸、职能都不同），但参数化思路一致，可并入同一目录管理。
- 上传前必检一项：**把成品缩到 210px 宽看一眼**，书名笔画是否还分得开。这是唯一必须做的检查。
