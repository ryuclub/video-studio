# 老马 · 用语规范（全系通用）

适用于单点式、累积式、长片三条线。
**这份只管"句子写成什么样能被念对"**；稿件结构、选题、出片见各线方案。

与说书、治愈两份规范并行，**互不参照** —— 老马是口语角色，有几条规则跟那两边正好相反。

---

## 〇、老马这条线的特殊处境

| | 说书 / 治愈 | 老马 |
|---|---|---|
| 语言 | 书面偏口语 | **纯口语，带方言味** |
| 目标 | 听懂 | **像个人在说话** |
| TTS 难点 | 长句、歧义 | **口语字、连读、语气** |

**核心矛盾：老马要说得越随便越好，而 TTS 越随便越读不对。**

书面语的句法边界有标点撑着，口语没有——「别人说啥我都点头」在人嘴里有停顿、有轻重，在 TTS 嘴里就是八个字连成一串。

所以这条线的规范，八成是在**把口语的隐性节奏写成显性标记**。

---

## 一、停顿要写出来

### 1.1 主从句边界必须加逗号

```
✗ 别人说啥我都点头
✓ 别人说啥，我都点头
```

人说这句会在「说啥」后停半拍。TTS 不会——除非你给它一个逗号。

**判据：这句话说出来，中间有没有一个换气的地方？有就加逗号。**

### 1.2 常见的漏停位置

| 结构 | 漏停的样子 | 加逗号 |
|---|---|---|
| 条件 + 结果 | 谁说啥我都答应 | 谁说啥，我都答应 |
| 时间 + 动作 | 到了晚上十一点我说睡了 | 到了晚上十一点，我说睡了 |
| 主语 + 长谓语 | 我这人吧别人说啥都点头 | 我这人吧，别人说啥都点头 |
| 转折 | 我确实有意见但我不说 | 我确实有意见。但我不说 |

**转折用句号不用逗号** —— 老马的转折要顿得更实。

### 1.3 逗号 ≠ 停顿符

逗号让 TTS 停 0.15–0.25 秒，是句内换气。真正的"停一拍"要另标（见 §六）。

## 二、多音字

### 2.1 高危字表

老马这条线最常翻车的：

```
都 得 了 着 干 会 差 还 好 少
长 重 分 中 转 空 数 应 便 落
```

### 2.2 出现频率最高的三个

| 字 | 两读 | 老马稿里的典型 |
|---|---|---|
| **都** | dōu / dū | 别人说啥我**都**点头 |
| **得** | de / dé / děi | 说了就**得**解释 |
| **了** | le / liǎo | 干完就不累**了** / 受不**了** |

这三个在段子里几乎每条都有。**不用逐个改，但要在生成后抽听** —— 尤其「都」在句中、「得」表"必须"这两种情况。

### 2.3 能换就换

| ✗ | ✓ |
|---|---|
| 说了就**得**解释 | 说了就**要**解释 |
| 我**都**点头 | 我**全**点头 ／ 我**一律**点头 |
| 这事**差**不多 | 这事**凑合** |

换词比标 SSML 划算——**改一次永远对，标记每期都要标，换个 TTS 还可能失效。**

## 三、口语字

### 3.1 保留，但知道代价

```
啥 咋 嘛 呗 吧 哈 呢 哟 嘞
```

这些是老马的命，**不能为了 TTS 顺畅把它们删掉** —— 删了就成播音稿了。

但要知道：晓晓是普通话播音底子，读方言口语字时字正腔圆，会有轻微违和。这是**角色和音色之间的固有落差**，接受它，别试图靠参数修。

### 3.2 密度控制

**一条段子里方言字不超过三处。** 太密会让违和感累积；三处以内反而像口音，是加分的。

### 3.3 不要连着堆

```
✗ 咋整啊这事儿呗
✓ 这事儿咋整
```

三个口语字挨着，TTS 会读成一串怪音。

---

## 四、不许靠重音

跟治愈线同一条，但老马的对比句更多，所以更要紧。

### 4.1 三条

**一、对比写进结构。**

```
✗ 我不是不想干，我是干不动
✓ 不是不想干。是干不动
```

**二、一句一个重点。**

```
✗ 我拧了四下手心印出一圈齿
✓ 这瓶水我拧了四下。手心印出一圈齿
```

**三、重点放句尾。**

```
✗ 那瓶水我一口没喝就走了
✓ 我走了。那瓶水一口没喝
```

### 4.2 排比段的额外要求

累积式的排比句，**每句的重点必须在同一个位置**（都在句尾或都在句中），不能一句在头一句在尾。位置一致，节奏才起得来。

```
小心翼翼上了很多当
扣扣嗖嗖花了很多钱
认认真真犯了很多错
```

三句的落点都在末四字，所以成串。

## 五、句子

| | 上限 |
|---|---|
| 单句 | **16 字**（三条线里最严） |
| 排比句 | **12 字**，且三句字数差 ≤4 |
| 落点句 | **单点式 ≤15 字，累积式 ≤20 字** |
| 硬伤线 | 24 字 |

比治愈线还严，因为老马是**短视频**，25–45 秒里塞不下长句。

**一条 line = 一个字幕屏。** line 内部不该有句号。

## 六、停顿标记

### 6.1 三档

| 记法 | 时长 | 用在哪 |
|---|---|---|
| 逗号 | 0.15–0.25s | 句内换气 |
| 句号 | 0.35–0.5s | 句间 |
| `⏸0.8` | 显式标注 | **落点前那一拍** |

### 6.2 落点前必须有一拍

单点式和累积式都是。这一拍是笑点和苦味的容器，**没有它，落点只是最后一句话，不是落点**。

```
我看了那瓶水一会儿。
⏸0.8
那瓶水我一口没喝。
```

### 6.3 说不下去的那半秒

长片专用。角色要说难听话之前卡一下：

```
我哪明白啊。我就是……
⏸0.5
我就是没敢试。
```

**这半秒是剪出来的，不是读出来的。** TTS 演不了省略号——把它拆成两条音频，中间手工插静音。

## 七、用词

### 7.1 能用口语词就不用书面词

| ✗ | ✓ |
|---|---|
| 他没说话 | 他没吭声 |
| 他不是为了结果干的 | 他不图什么 |
| 他不是不确定 | 他不是没主意 |
| 我不是看破了 | 我那不叫看得开 |
| 这段对话重复过十几次 | 这话我俩来回说过十来次 |

### 7.2 书面概念词黑名单

```
看破 执念 意义 本质 状态 机制 认知
内耗 能量 磁场 底层逻辑 情绪价值
```

**老马嘴里一个都不许有。**「看破」是佛经武侠词，工位上的人不这么说话。

### 7.3 判断句改认输句

```
✗ 我是不敢        （给自己下定义）
✓ 我就是没敢试    （承认）
```

**老马不给自己下定义。**

### 7.4 量词各归各的

```
拧瓶盖用「下」   喝水用「回」   按开关用「次」
拧了四下         喝了四回       按了十几次
```

量词选错，白话就成了假白话。

---

## 八、词要白，事要怪

只追大白话会滑成流水账。

```
✗ 三舅问我工资，我没说实话，心里有点难受
✓ 我端起杯子喝了一口，杯子是空的
```

每个字都是大白话，但第二句有个反常。**朴素的是词，不朴素的是事。**

**观众留下来是因为怪，不是因为白。**

---

## 九、两条线的差别

| | 单点式 | 累积式 |
|---|---|---|
| 语言 | 可以稍微文一点点 | **全程口语，一句都不能文** |
| 理由 | 有个转折要立，偶尔需要一句收紧的话当支点 | 靠密度和节奏推，中间冒出书面话整串就断 |

「扣扣嗖嗖」「不过这样也挺好」这种，是累积式的命。

## 十一、可以脚本化的检查

| 项 | 判据 |
|---|---|
| 超长句 | `len > 24` |
| 漏停 | 句长 >10 且无逗号无句号 |
| 多音字 | 匹配「都得了着干会差还好」，输出上下文 |
| 口语字密度 | 单条内「啥咋嘛呗吧哈呢」计数 >3 |
| 口语字连排 | 相邻两字都在口语字表 |
| 排比字数差 | 连续三句 `max-min > 4` |
| 落点长度 | 最后一条 line 超本线上限 |
| line 内句号 | 含「。」 |
| 概念词 | 匹配黑名单 |

**人只需要看三样**：事情够不够怪、少不少一拍、口音的违和感能不能接受。

## 十二、落地（2026-08-26 立）

### 12.1 实现在哪

`src/laoma-diction.ts` —— **一份实现，两个入口共用**：

| 入口 | 管谁 |
|---|---|
| `laoma-check.ts` | 单点式（`format` 缺省）、累积式（`format: "cumulative"`）|
| `laoma-long-check.ts` | 长片 |

**没有第三个脚本。** 新开一支就得靠人记着跑，而这仓库的教训是靠人记着就每次都会漏。

### 12.2 §十一 那张表，落地时改了六处

**照抄会误伤，六处都是拿 18 条已出稿 + 长片 001 量出来的。**

| 规范原文 | 落地判据 | 为什么改 |
|---|---|---|
| 超长句 `len > 24` | **按小句量**（逗号／句号切开），不按整行 | §五 的「单句 16 字」说的是小句。按整行量，「你回晚了，显得不积极。你回早了，显得没看完。」20 字要报，可它是两个 10 字小句，完全合规 |
| line 内句号：含「。」 | **句号 ≥3 个才报** | 见 12.3 |
| 落点前 `⏸0.8` | **绝对 ≥0.8s 或 相对 ≥1.3×句间中位，满足其一** | 见 12.4 |
| 多音字：匹配「都得了着干会差还好」，输出上下文 | **只报「得」，且整条汇总一行** | 见 12.5 |
| 排比字数差：连续三句 `max-min > 4` | **「三句」= 三条 line，且三条在同一字位有 ≥2 字公共片段** | 见 12.6 |
| 口语字密度 >3 | **段子线查，长片关掉** | §3.2 原文是「一条段子里」，量的是 25–45 秒里的密度。长片 001 有 82 句、4 处方言字，套这个绝对值就是误报 |

### 12.3 「line 内句号」这条跟 §1.2 打架，按 §1.2 判

规范 §五说「line 内部不该有句号」，可 §1.2 那张表**点名要求**转折写成「我确实有意见。但我不说」—— 那就必然是 line 内句号。

18 条已出稿里有 10 行含 line 内句号，**逐条看过，没有一处是流水账**：

| 稿 | 原文 | 是什么 |
|---|---|---|
| 017 第4 | 我确实有意见。但我不说。 | §1.2 表里的正确示范本身 |
| 018 第2 | 开会我从来不说话。不是没意见，是说了也白说。 | 转折 + §4.1 一的对比 |
| 002 第2 | 明天降温，加衣服。有雨，带伞。风大，别骑车。 | 三段排比 |
| 004 第5 | 备注只写两个字。随便。 | 后半是落点词，故意顿开 |

**结论：一条 line 是一个字幕屏、一个包袱单元，里面可以有两三拍。**「一段一句」是治愈线的规矩，那边一段 = 一次 TTS 合成 + 一屏字幕，语境不同，别搬过来。

落地判据收紧成**句号 ≥3**（三段以上就真该拆了）—— 18 条里只中 002 第2 那条排比，warn，不拦。

### 12.4 落点前那一拍：绝对和相对，满足其一

§6.2 写的是 `⏸0.8`。实测 18 条，落点前的**实际停顿**（`padAfter` + 下一句 `padBefore` + `beatPause`）是这样的：

```
倍数 = 落点前停顿 ÷ 全片句间停顿中位数

001  0.65s  中位0.65  1.00×     ← 唯一真的没有那一拍
010  1.37s  中位1.66  0.83×     ← 绝对够，全片本来就慢
015  1.54s  中位1.57  0.98×     ← 同上
003–009  0.65s  中位0.45–0.50  1.30–1.44×
002  1.90s  中位0.45  4.22×
017/018  0.80s  中位0.50  1.60×
```

**只用绝对值 0.8 会误伤 003–009 那七条**（0.65s，但已经是句间的 1.4 倍，那一拍听得出来）。
**只用相对倍数会误伤 010/015**（全片节奏本来就慢，1.4s 的绝对停顿足够，只是不比句间更长）。

所以判据是**或**：绝对 ≥0.8s **或** 相对 ≥1.3×。18 条里只报出 001 一条 —— 那条确实是落点前跟句间一样长，没有容器。

⚠ **别把 §6.2 的 0.8 改成 0.65。** 0.8 是写稿时该标的目标值；0.65 是管线在 `banter` 预设下的实际产出。两个数管两件事，规范里的 0.8 不动。

### 12.5 多音字只报「得」

§2.2 点名了「都 得 了」三个。**三个都报的话，18 条已出稿 18/18 全中，长片也中。**

100% 命中的闸门等于没有闸门 —— 它只会把同一块里真正该看的那几条淹掉。拆开量：

| 字 | 命中 | 为什么 |
|---|---|---|
| 了 | 18/18 | 几乎全是 `le`，没有歧义 |
| 都 | 9/18 | 几乎全是 `dōu` |
| **得** | **6/18** | 唯一真有三读（de／dé／děi），而且 §2.3 举的例子（「说了就得解释」）就出在它身上 |

所以闸门只报「得」。**「了」「都」不是不用听，是退回 §十 那张出稿检查表** —— 每期都要做的固定动作属于检查表，不属于闸门。

### 12.6 「连续三句」指三条 line，不是一行里的三句

§4.2 给的例子本身就是三条 line：

```
小心翼翼上了很多当
扣扣嗖嗖花了很多钱
认认真真犯了很多错
```

第一版按「一行里三个句号」判，**在长片 001 上 4 处全是误报** —— 那些只是连着三句的叙述（「他去了一个更小的地方。工资低了点，通勤短了四十分钟。」），不是排比。

光靠字数接近判不出排比，叙述句的字数本来就常常接近。所以判据是两条都要满足：

1. 三条**连续的 line**，且都是单句（中间不带逗号句号）；
2. 三条在**同一个字位**上有 ≥2 字的公共片段（上例是第 4–6 位的「了很多」）。

改完之后，长片 001 的 4 处误报清零，规范自己那个正例也不误报（9/9/9 差 0）。

### 12.7 分级：什么是 error，什么是 warn

老马这条线的稿子比治愈线干净得多 —— **18 条已出稿按小句量，超 24 字 0 处、漏停 0 处、口语字连排 0 处、方言超 3 处 0 条、概念词 0 处、判断句式 0 处。**

所以这条线**不需要治愈线那种 `用语豁免` 开关**，硬伤直接 error：

| error（拦） | warn（提醒） |
|---|---|
| 小句 > 24 字 | 小句 > 16 字 |
| 书面概念词黑名单 | 漏停（句长 >10 且无逗号句号）|
| — | 判断句式的自我定义（「我是不…」）|
| | 口语字连排 |
| | 方言字 > 3 处／条 |
| | 排比三句字数差 > 4 |
| | 落点前没有那一拍 |
| | line 内句号 ≥3 |
| | 多音字「得」（整条汇总一行）|

只有两条是 error：**过了 24 字的小句**和**书面概念词**。前者是规范自己划的硬伤线，后者是 §7.2 写死的「一个都不许有」。

判断句式放 warn 不放 error，是因为它靠正则猜句意，比前两条虚。原式 `我是不[^，。]` 会把「我是不是该早点说」当成下定义，落地时排掉了「我是不是」——
**这类式子每加一条都要先想它会误伤什么。**

### 12.8 现在的成绩

18 条单点式 + 长片 001，跑下来 **error 0**。提醒是这些：

| | 条数 | 是什么 |
|---|---|---|
| 多音字「得」 | 6/18 | 提示抽听，不是错 |
| line 内句号 ≥3 | 单点式 1（002 那段三句排比）· 长片 4 | 都是有意的三拍，warn 不拦 |
| 小句 >16 字 | 长片 3 处（22／18／17 字）| 旁白，可以留 |

**没有豁免，没有 fold。** 这是这仓库第一条不用开后门就能全绿的用语闸 —— 因为老马这条线的稿子本来就干净：按小句量，18 条里超 24 字 0 处、漏停 0 处、口语字连排 0 处、方言超 3 处 0 条、概念词 0 处、判断句式 0 处。
