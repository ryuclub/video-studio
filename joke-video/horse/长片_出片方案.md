## 二、仓库这边支持了什么

`format: "long"` 一个字段分流，缺省不写的一切照旧：

| 做了什么 | 在哪 |
|---|---|
| 体裁分流 | `types.ts` 的 `JokeCfg.format = 'long'` |
| **节奏档 `longform`** | `pace.ts`：句间 0.6（0.2+0.4）、换镜 1.2。落在 `bedtime` 0.90 和 `standup-fast` 0.40 中间 |
| **句子级音染 `line.tone`** | `types.ts` ＋ `tts.ts`：叠在角色音色的 `tone` **后面**，不是替换 |
| **老牛音色** | `cast.ts` 的 `老牛`：云健压到 0.80/0.80、−15% |
| 成品单独一枝 | `preview.ts`：`projects/老马/长片/<id>/`，**不进段子那棵排期树** |
| 不进汇总页 | `preview.ts` 的 `syncProjects` 跳过 —— 一条长片一百多句，逐句出场景图没有意义 |
| 稿子 → json | `tools/long-parse.mts` |

### 稿子是源，json 是产物

```bash
npx tsx tools/long-parse.mts "E:/ryu/laoma/长片001_配音版v2.md" jokes/laoma-long-001.json
npm run voice -- jokes/laoma-long-001.json
npm run align -- jokes/laoma-long-001.json
npm run audio -- jokes/laoma-long-001.json      # → projects/老马/长片/<id>/<id>-试听.wav
```

⚠ **改稿改 .md 重跑脚本，别手改 json** —— 改了下次重跑就没了，而「下次重跑」总会发生。

配音稿把两件事标死了，**脚本一条规则都不发明**：

```
【马】/【牛】/【马·台词】/【牛·回忆】   谁在说、哪一层
⏸0.5                                  这一句之后静音几秒（也可以单独成行）
```

⚠ **一段一句，别按句号拆。** 稿子把几句排成一段，是因为它们要一口气读下去
（旁白句长、台词句短，长短对比本身就是两个人的区分）；拆开等于在每个句号后面
塞进 0.6 秒，那不是稿子的意思。

### 三层音质（方案 §〇）

**说话人靠音色分，时态靠音质分，两件事分开解决，不互相挤。**

| 层 | 处理 | 现在上了吗 |
|---|---|---|
| 旁白 | 全干、全频 | — |
| 现场台词 | `aecho=0.85:0.35:18:0.06` | **没上**（稿子自己说的：先只做停顿和句长听一遍，**别一次上三层**） |
| 回忆段 | `lowpass=f=6500,volume=-1.5dB,aecho=0.9:0.25:28:0.05` | 上了，**两个音色都加** |

要上现场那一层，把 `tools/long-parse.mts` 里 `LAYER.台词` 指到 `LIVE_ROOM` 就行。

## 三、⚠ 三件跟方案不一致的，别照方案改回去

**一、老马不是晓晓。** 配音方案抬头写的是 `zh-CN-XiaoxiaoNeural`，那是把别的线的女声
当成了老马 —— **这条线的老马从 001 起就是云希 1.20/1.20**（`cast.ts`），
前面 18 条短片全是它，换了就是两个人。用户 2026-08-25 定：**老马坚持他原本的声色。**

**二、`mstts:express-as` 做不到。** 方案给老牛的是
`style="narration-relaxed" styledegree="0.5"`，而这条链走 `msedge-tts` 的
`toStream(text, {rate, pitch})`，**只接 rate 和 pitch 两个参数**，进不去 express-as；
Edge 那个免费端点对 SSML 一向挑（`<break>` 就是一律被拒的）。
所以**压解说腔只能靠语速 ＋ 变声 ＋ 音染**。先听「那你现在知道了」那一句 ——
带出解说腔的话，下一步是再降 rate，不是加 style。

**三、通片环境床音没有。** 管线的 `ambience` 只有开场草声和片尾蝉鸣两条写死的，
给不了一层房间底噪。现在是 mixdown 之后用 ffmpeg 垫一层**恒定**底噪
（棕噪声 55–1100 Hz，比人声低约 38 dB），**不是分场景的床音** ——
v2 §五 要的「室内空调 → 窗外车流」那次换层做不了，要等场景先落地。

```bash
ffmpeg -y -i <干版>.wav -f lavfi -i "anoisesrc=color=brown:amplitude=0.06:sample_rate=48000" \
  -filter_complex "[1:a]highpass=f=55,lowpass=f=1100,volume=-13dB[bed];[0:a][bed]amix=inputs=2:duration=first:normalize=0[out]" \
  -map "[out]" -ac 1 <带底噪>.wav
```

## 四、⚠ 这条线现在没有闸

`laoma-check` **不查长片**（`cli.ts` 的 `laomaOk` 按 `format === 'long'` 跳过）。
它查的全是短片的东西 —— 落点、铺垫几句、物件、日子牌、片长 18–45 秒；
拿去判一条五分钟的稿子，**报出来的每一条都是错的**，
而天天报错的闸门只会教人加 `--anyway`（那样连另外两条有用的闸也一起失效）。

**长片自己的规范还没写。有了再往这儿接一道；在那之前，稿子对不对只能靠人看。**
