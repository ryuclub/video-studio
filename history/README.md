# history —— 已停用的东西

放在这里的不是废弃代码，是**暂停使用、但保留可复活性**的产物。

## 纯 PPT 演示风（`style: "slide"`）

2026-08-17 决定停用：整片都是版式屏，太单调。新选题一律走空镜解说风，
需要「图」的地方用 `video-pipeline` 的动效面板叠上去。

| 文件 | 是什么 |
|---|---|
| `PPT-STYLE.md` | 这套风格的设计与踩坑记录（九种版式、词级时间戳对齐、解说词的三条硬约束） |
| `article-to-ppt-video.md` | 把稿件改编成 PPT 讲解片的作业指引（slash command 形式） |
| `2026-08-16_你4月交的永住申请，可能已经在新规则里_ppt/` | 这套风格唯一的成片（31 秒渲染 / 8.6MB），留作对照 |

**代码没有一起移走**，仍在原位：

- `src/lib/slides.ts`（九种版式的 ASS 生成）
- `src/steps/tts-slide.ts`（整条合成 + 词级时间戳）
- `src/steps/render-slide.ts`

理由：`src/cli.ts` 和 `src/types.ts` 里有 `style: "slide"` 的分流，
把这三个文件移走就得同时把分流逻辑剖掉，那是一次不可逆的手术 ——
而停用的决定是「暂停」不是「废弃」。要真正下线再动它们。

想复活：把这几份文档搬回根目录，照 `PPT-STYLE.md` 走即可，代码链路是通的。
