### 标题

```
房子越住越小，他反而睡得着了｜《方丈记》上·三米见方｜深夜助眠
```

### 简介

```
八百年前，一个日本人把家搬进了一间三米见方的屋子。
两辆车就能装走。他在里面住了几年，有人问他闷不闷，他说闷——但他没有搬走。

他叫鸭长明。家里世代管一座神社，那份差事本来该是他的，最后没轮到他。
他等过很多年，托过人，都没成。后来他失去了旧宅，五十岁那年离开城里，
六十岁搭起这间一丈见方的小屋。

这一期讲他在小屋里的一天：天没亮起来取水，上午读几页旧书，
下午坐着看一片光从床沿挪到门口，天黑了不点灯。
以及他是怎么一步一步走到这儿的——不是想通了什么，
是先没了差事，再没了房子，最后才发现自己什么也不缺。顺序是反的。

## 下篇 · 山中一年

### 标题

```
他问自己是不是在骗自己，没答上来｜《方丈记》下·山中一年｜深夜助眠
```

### 简介

```
他在山里住到第几年的时候，鹿会走到门口，抬头看他一眼，不跑。
那年他六十多岁，一个人，一间三米见方的屋子。

这一期先讲山里的一整年：春天的紫藤开在西边，夏天听杜鹃，
秋天蝉声铺满整片林子，冬天看雪积起来又化掉。
山下有个看山人的孩子，十岁，偶尔上来找他。两个人去捡落穗、爬到山顶，
从那儿能看见他年轻时候住过的那座城。

然后是这本书真正的结尾。他念了几十年「不要起执着」这句话，
有一天忽然把它套到了自己身上：那我喜欢这间小屋，也是执着；
我贪图这份清静，也是妨碍。他问自己，你到底是想通了，
还是被逼到这一步，然后回过头把它说成是自己选的。

他没有答上来。他也没有找一个说法把这件事圆过去。
只是念了两三遍佛，然后天就亮了，他起来去取水。
