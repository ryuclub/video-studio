## 怎么引用

时间表的 `music.file` 以 `_音乐/` 开头就走这儿，其余写法相对本条工作目录：

```js
music: { file: '_音乐/zhege-hao.mp3', db: -22 }
```

路径解析在 `gao-2d/自检.mjs` 的 `音乐路径()` —— 只有那一处。

## db 怎么定

方案 §5.1：**音乐比人声低 18–22dB**。人声归一到 −16 LUFS，所以：

```
db = (人声 LUFS − 差值) − 音乐原始 LUFS
```

实测 `zhege-hao.mp3` 原始 **−14.03 LUFS**，人声 −15.97，取差值 20dB：
目标 −35.97，衰减 **−21.94 → db: -22**。

⚠ **换一首就要重测重算。** 不同曲子的原始电平能差十几个 dB，
照抄上一首的 db 会让音乐要么听不见要么盖住人声。
