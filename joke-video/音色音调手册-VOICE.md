# 音色音调手册

**这份是 `npm run voicedoc` 生成的，别手改。** 改 `src/cast.ts` 再重跑，
表和代码才不会脱节——过期的参考表比没有更浪费时间，照着错数字调会越调越偏。

基准句：「大哥，我们有毒吗？我咬到了自己的舌头。」。测量口径见 `src/audio/measure.ts`。

## 一、先看这三条（踩过的坑，实测）

### 1. SSML pitch 响应又不对称、又不连续

同一句、同音色（童声，「我问你几点到。」），只扫 SSML pitch：

| 设定 | 实测基频 | 变化 | |
|---|---|---|---|
| +10Hz | 310Hz | +0 | 死区 |
| +20Hz | 314Hz | +4 | 死区 |
| **+30Hz** | 343Hz | **+33** | 台阶，一下跳上来 |
| +40Hz | 340Hz | +30 | 平台 |
| +50Hz | 343Hz | +33 | 平台 |
| +60Hz | 348Hz | +38 | |
| **+80Hz** | 372Hz | **+62** | |
| +100Hz | 372Hz | +62 | 饱和 |
| −20Hz | 265Hz | −45 | |
| −40Hz | 223Hz | −87 | |
| −60Hz | 187Hz | −123 | |

三条结论：

1. 正方向 **+20Hz 以内等于没写**，+30Hz 才起跳
2. **+30~+50Hz 是同一个平台**，在这区间里调数值没意义；要更高得跳到 +80Hz
3. 负方向近乎线性且灵敏，**斜率约 2.1×**（设 −20Hz 实际掉 45Hz）

所以念法只用 **+30 / +80 / −15 / −20 / −32** 这几个档位，别在平台里瞎调。

### 2. 破折号和省略号不产生停顿

想要「龟——来——」那种拖腔，写标点是没用的：

| 写法 | 时长 |
|---|---|
| 龟来 | 1.763s |
| 龟——来—— | 1.760s　← 完全无效 |
| 龟…………来………… | 1.764s　← 无效 |
| 龟。来。 | 2.186s　← 只有句号有效，+0.42s |

**唯一可靠的拖腔手段是变声的 `tempo`**（走 rubberband，音高不变）。
`延宕` 念法就是干这个的，实测把「龟来」从 0.62s 拉到 1.03s（1.65×）。

### 3. 两个概念别混

| | 改什么 | 走哪个参数 |
|---|---|---|
| **谁在说** | 角色身份、年龄、体型 | `cast` 的 `morph.pitch` / `formant` |
| **怎么说** | 语调起伏、快慢、情绪 | `delivery` 的 `pitchHz` / `rate` |

做抑扬顿挫**只动 delivery**。动了 morph.pitch，角色会变成另一个人。

### 说书（长篇叙述）跟段子是两套设计

段子 2 分钟，说书 15 分钟。**时长一变，取舍就反过来了。**

| | 段子（A 类） | 说书 |
|---|---|---|
| 分角色 | 硬拉 pitch 就行 | **先换基础音色**，morph 只微调 |
| 理由 | 短，artifact 听不出来 | 十几分钟连着听，一点点金属味都被放大 |
| 叙述者 | 可以变声 | **几乎原声**（占全片八成时间） |

说书的 7 个通用音色（书生 / 老道 / 女鬼这些原型 17 期反复出现）在 `cast.ts` 末尾。

### 停顿：没有底噪就别给长停

做《画皮》时试了三版节奏，最后选了停顿最紧的那版（最长 0.98s）。

原因不是「长停顿不好」，是**我们插的是绝对静音**——实测 **−227dB**，
现实里不存在这种东西。真人停两秒，听众听得到换气和现场；广播里的长停
底下永远垫着环境声。没有底噪时，停顿越长越像**卡带**，不像**酝酿**。

两条具体的：

- **没有 BGM / 没有底噪时，单个停顿别超过 1 秒。**
- **一个戏剧点只给一个停。** 曾经做成「A →〈1.28s〉→ B →〈1.48s〉→ C」，
  2.76 秒静音夹着 3 个字，听感是卡壳不是吊胃口。
  正确结构：正常 → 正常 → **停住** → 揭开。

想要长停顿，先垫底噪（−48dB 粉噪，全局一处改动），那之后停顿可以整体放回去。

### 砍东西要分清哪一样有问题

试听反馈"停顿太久不舒服"时，别整个退回默认版。手工调过的版本比默认版多了
**三样**：停顿、音量、语速。只有停顿那一样有问题：

- **停顿给多了会「卡」** —— 听得见的破绽，风险高
- **音量、语速给多了最多是「起伏小了点」** —— 不会翻车，风险低

所以砍停顿、保留音量语速。十几分钟全程一个响度一个语速是另一种失败：**单调**。

### 可懂度优先于分离度

做《画皮》的厉鬼时踩过：为了让"低高频差"这个指标过线，压到
`pitch 0.50 + lowpass=1500 + 长混响`，指标漂亮了，**人完全听不清说什么**。

根因是**低通把辅音砍了**。中文辅音 s / sh / x / c / q 的能量在 **2–8kHz**，
低通压到 2kHz 以下就只剩元音共鸣，再叠上长混响把残存的辅音抹平，就是一团糊。

所以量音色要量两件事，顺序不能反：

| | 怎么量 | 红线 |
|---|---|---|
| **① 可懂度** | 2–8kHz 的 RMS 相对全带（dB） | 不得比叙述者低 **8dB** 以上 |
| **② 分离度** | 基频差 / 低高频差 | ≥25Hz **或** ≥6dB |

几条具体的：

- **低通不要低于 6kHz**。要做"闷"，用 `equalizer` 在 3kHz 附近做 −3~−5 的窄带衰减，
  别用低通一刀切。
- **混响要短**。做"不像人"用 45ms 左右的 slap（`aecho=0.9:0.4:45:0.3`）；
  150ms 以上的长混响是"在山洞里"，会把辅音全糊掉。
- **pitch 别超过一个八度**。0.50 是往下整八度，人声本来就散了。
  实际能用的下限在 0.65 上下。
- 指标撞车时，**先想能不能换基础音色或换设计方向**，别一味加大滤镜。
  乞丐那个就是：卡片让压低，压低撞车，改成抬高做亮反而更贴角色。

## 三、念法

用 `童声` 念短句「我问你几点到。」测的，看的是**相对变化**。换个音色绝对值会变，方向和幅度可以参考。

**念法必须用短句测。** 长句上基频中位数会被句子本身的语调起伏淹掉——
实测能把 +80Hz 的 `拔高` 量成负数。音色表用长句，念法表用短句，两张表口径不同。

| delivery | 参数 | 基频 | 相对基准 | 净时长 | 相对基准 |
|---|---|---|---|---|---|
| `平` | {} | 312 | +0 | 1.02 | +0% |
| `压低` | {"rate":"-8%","pitchHz":"-20Hz"} | 270 | -42 | 1.14 | +12% |
| `拔高` | {"rate":"+4%","pitchHz":"+80Hz"} | 372 | +60 | 1.01 | -1% |
| `喊` | {"rate":"+2%","pitchHz":"+80Hz","tempo":0.8} | 366 | +54 | 1.26 | +24% |
| `疑问` | {"rate":"-2%","pitchHz":"+30Hz"} | 336 | +24 | 1.05 | +3% |
| `拖长` | {"rate":"-14%","pitchHz":"-12Hz"} | 282 | -30 | 1.21 | +19% |
| `延宕` | {"rate":"-10%","pitchHz":"-15Hz","tempo":0.62} | 268 | -44 | 1.88 | +84% |
| `急` | {"rate":"+14%","pitchHz":"+30Hz"} | 324 | +12 | 0.89 | -13% |
| `弱` | {"rate":"-6%","pitchHz":"-15Hz"} | 276 | -36 | 1.08 | +6% |
| `泄气` | {"rate":"-12%","pitchHz":"-32Hz","tempo":0.96} | 245 | -67 | 1.23 | +21% |

### 怎么配

- **punch 句几乎总要变调**，不然三句一个调子，包袱抖不响。最常用 `泄气`。
- **一句话内部的起伏**用 `say` 分句，每小句给不同念法：

```jsonc
"say": [
  { "text": "我没叫你名字，", "delivery": "急",   "gap": 0.18 },
  { "text": "我问你几点到。", "delivery": "压低" }
]
```

实测这组落差 **46Hz**、语速差 **1.22×**，是"越说越无奈"的语调。
整句只给一个 delivery 做不到这个——句内还是平的。

### 旁白：只准动语速，pitch 一律给 0

上面那张表是给**对话角色**用的。旁白（B 类叙述片，一个人从头讲到尾）**不能用**。

mouse-cake 第一版旁白混用了 `拔高`(+80Hz) / `疑问`(+30Hz) / `急`(+30Hz) / `压低`(-20Hz)，
前后摆动近 100Hz，听感就是**换了个人在讲**——用户第一句反馈就是「旁白串音了」。

根因是本手册第一条：SSML pitch 正方向有死区，+20Hz 以内没反应，一动就是 +30Hz 起跳。
**做不出"轻微上扬"**，所以旁白的抑扬顿挫只能靠快慢。

| delivery | 参数 | 用在哪 |
|---|---|---|
| `叙缓` | {"rate":"-12%"} | 收尾句、要留韵味的地方 |
| `叙平` | {} | 默认，绝大多数叙述句 |
| `叙快` | {"rate":"+10%"} | 情节推进、连着说的地方 |

角色本身的 `rate` 是叠加的——mouse-cake 旁白 cast 上挂了 -8%，
所以实际落到 -20% / -8% / +2%。

### 节奏预设：直接调用，别重新试

调《小老鼠做蛋糕》的节奏花了三轮反复（三次反馈："讲太快""每句之间要有缓冲"
"说完上句紧接着下句"）。这套值已经固化成命名预设，**新稿件写一行就够**：

```jsonc
{ "type": "B", "pace": "bedtime", ... }
```

| 预设 | 用在哪 | 句内(句号/逗号) | 句间 | 换镜 |
|---|---|---|---|---|
| `bedtime` | 睡前故事、儿童向 | 0.55 / 0.30 | **0.90s** | **1.95s** |
| `narrate` | 常规叙述（B 类默认） | 0.38 / 0.20 | 0.60s | 1.35s |
| `banter` | 段子对话（A 类默认） | 0.18 / 0.12 | 0.35s | 0.50s |

定义在 `src/pace.ts`。**停顿不要写死在 beats 里**——写死了下一条片子又要从头试。
单句要特殊处理时才在 `line.padBefore/padAfter` 或 `say[].gap` 上覆盖。

配套语速在念法表里（预设只管停顿，不管语速）：
`bedtime` 搭 `叙缓/叙平/叙快`，叠上角色 `rate: "-8%"` 后实际落到 **−30% / −18% / −8%**。
《小老鼠做蛋糕》22 句、145 秒就是这套组合。

#### 为什么必须分三层

用户反馈"讲太快、说完上句紧接着下句"时，**八成漏的是第一层**：

| 层 | 在哪配 |
|---|---|
| ① 一句**内部**的小句之间 | `say[].gap`，不写则由预设按标点给 |
| ② 句与句之间（同一镜） | 预设的 padBefore + padAfter |
| ③ 换镜的地方 | 预设的 padBefore + padAfterShot |

第一次改的时候只动了 ②③，而一句旁白内部还拆成 2–3 个小句、中间只有 0.16~0.24s，
听感照样是"一口气读完"——**②③ 管不到句内**。

## 五、调音流程

```bash
npm run cast                              # 看有哪些音色和念法
npm run try -- 童声,老太太 "真实台词"       # 试听对比，出到 out/try/
npm run lines -- jokes/<id>.json          # 出片前核对，会报音色撞车
```
