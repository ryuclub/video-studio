# 治愈频道 · 用语规范（全系通用）

适用于禅佛典向（小故事大道理）、心理洞察向（方案一现象型／方案二道理向／清单体法则档），
以及治愈系旁白线。**这份只管「句子写成什么样」**；选题、结构、封面、画面见各线文档。

与说书频道的规范并行，不互相参照——**两边的听众状态不同，规则有几处正好相反。**

> **落地在哪**：§十二 那张表已经**接进现有三支体检**（`zhiyu-check` / `xinli-check` /
> `chan-check`），共用一份 [`joke-video/src/zhiyu-diction.ts`](../joke-video/src/zhiyu-diction.ts)。
> **没有第四个脚本** —— 新开一支就得靠人记得跑，而靠人记着就每次都会漏。
> 详见 §十三。

## 〇、和说书线的三处不同

| | 说书 | 治愈 |
|---|---|---|
| 听众状态 | 醒着，跟情节 | 半睡，或边做事边听 |
| 句子密度 | 可以密，靠情节推 | **必须稀**，一句一件事 |
| 同音歧义的危险 | 语境是鬼神，歧义被放大 | 语境是日常，**歧义会让人以为自己听错了，回过神去想那一下就掉出去了** |
| 抽象词 | 可以有 | **故事段一个都不许有** |

**治愈线的核心风险不是听不懂，是「卡了一下」。**
半睡状态的人一旦需要回想上一句，注意力就断了，而且往往不会再接回来。

## 一、三个自查动作

写完必做，跟说书线一致：

| 测试 | 怎么做 | 不过关说明 |
|---|---|---|
| **平读** | 每句用完全平的语调念一遍，意思还在吗 | 靠重音撑着，改结构（见 §三） |
| **同音** | 高危字逐个搜 | 会被听成另一件事 |
| **一遍懂** | 念给没看过稿的人听，问他刚才那句什么意思 | 需要回想的句子，改掉 |

第三条是治愈线专属。说书线可以靠情节把人拉回来，治愈线不行。

## 二、同音歧义

### 2.1 高危字表

```
活 干 数 空 还 得 着 了 会 好
分 中 转 长 重 为 相 度 差 卷
```

比说书线多出来的几个（会、度、差、卷），是因为**治愈线大量写现代生活**：

| 词 | 歧义 |
|---|---|
| **会**议 / **会**不会 | huì 同音但语义跳 |
| 一**度** / 制**度** / 温**度** | dù 反复出现容易黏 |
| **差**不多 / 出**差** / **差**距 | chā / chāi / chà 三读 |
| 内**卷** / **卷**起来 | juǎn / juàn |
| **还**行 / **还**钱 | hái / huán |

### 2.2 现代词的额外坑

治愈线写的是工位、群聊、通勤，这些场景里的常用词自带歧义：

| 原句 | 问题 | 改 |
|---|---|---|
| 他**干**得挺好 | gān / gàn | 他**做**得挺好 |
| 这事**得**看情况 | de / dé / děi | 这事**要**看情况 |
| **会**上没人反对 | 听成「会不会」 | **开会**的时候没人反对 |
| **差**不多就行了 | 三读字 | **凑合**就行了 |
| 他**还**在等 | hái / huán | 他**一直**在等 |

### 2.3 判据

同说书线：**这个字离开它所在的词，会不会读成另一个音、变成另一个意思。**

但治愈线**不留有意的歧义** —— 说书线可以用歧义制造鬼气，治愈线没有这个需求，一律改掉。

## 二之二、词边界（2026-08-26 从说书线搬过来）

> **判据、元教训、审稿方法这三样是跨线共有的，正文在
> [`../稿件审查通则.md`](../稿件审查通则.md)。** 这儿只写这条线自己的部分 ——
> 各写一份迟早漂移，而那种不一致没人核得出是哪边错的。

§二 查的是「这个字**离开**它所在的词，会不会变意」。
这一节是**反方向**：字跟旁边的字**重新勾搭成了另一个词**。

> **判据：把这一句的字重新分组，有没有第二种分法也说得通？**

### 为什么这一条在这条线上比在说书线更要紧

§〇 那张表已经写了：**这条线的核心风险不是听不懂，是「卡了一下」。**

词边界歧义正是「卡一下」的标准长相 —— 听众得回过神重新切分。
**说书线的听众醒着、跟着情节，切错了还能被情节拉回来；这条线没有情节可拉。**

这一类的特点是 —— **看着一点问题没有**。写的人知道自己想说什么，
读到「千万颗心里头」脑子里自动是正确切分。**听的人没有那个先验。**

### 2.2.1 固定块被跨词凑出来

| 原句 | 耳朵切成什么 |
|---|---|
| 我在冥间**千万颗心里头**挑 | 「千万」是副词（千万别）＋「心里头」是固定词 → 整句散架 |
| 只当**下面**又是那几句 | 「只当 / 下面」被切成「只 / 当下 / 面」 |
| 车马停下，**头一个人**下来了 | 「头一个 / 人」被切成「头一 / 个人」 |

表在 [`zhiyu-diction.ts`](../joke-video/src/zhiyu-diction.ts) 的 `词边界坑`。
**前六条是说书线踩出来的通用款**（跟内容无关，是汉语本身的性质），
后面几条是这条线自己的 —— 写工位、群聊、通勤，**现代词有它自己的一批坑**
（跟 §2.2「现代词的额外坑」是一张表的两半）。

⚠ **这张表不求全，是踩一个记一个。** 词边界歧义没有穷举的办法。
**2026-08-26 搬过来的时候，拿四期已出稿跑了一遍，一处没报** ——
说书线的坑不是这条线的坑。机制搬过来了，**内容要这条线自己攒**。
真正兜住这一类的是 §十四 那道审稿，不是这张表。

### 2.2.2 单音节裸奔

**一个单字名词或动词，前后没有别的字撑着，声音上抓不住。**

规律：**双音节是中文听觉的最小单位。** 同一个字，有词撑着和裸着是两回事 ——
「行当」听得清，「行」听不清。要用单字，先问它前后有没有东西托住。

⚠ **这一条现在只有规则，没有表。** 说书线那张表是志怪场的字（缝／血／朝／相），
这条线写的是现代生活，**该有自己的一张**（会／度／差／卷／点／面／单／群…）。
列表之前先靠 §一 的三个自查动作和 §十四 的审稿兜着。

### 2.2.3 一句里两个语域 ＝ 这条线的 §四

说书线管这个叫「语域混杂」（文言腔＋当代口语在一句里，听起来像两个人在说话）。

**这条线不用另立一节 —— §四「抽象词三层」和 §4.2「比喻之后必须跟人话」
就是同一个病的另一种长相**：一句里半截是书面／抽象词，半截是大白话。

两边是一件事，**别各写各的**。

## 三、不许靠重音

这是治愈线最要紧的一条，因为 TTS 不知道该重读哪个字。

### 3.1 三条硬规则

**一、对比写进结构，不写在语气里。**

```
✗ 那也是他要处理的情绪，不是你要处理的
✓ 那是他的情绪。不是你的
```

**二、一句只放一个重点。** 两个重点拆成两句。

```
✗ 他要的是第三层，下面两层不必
✓ 下面两层他不要。他只要第三层
```

**三、要强调的词放句尾。** 中文句尾天然重读，位置就是重音，不需要任何标记。

```
✗ 你不用替他处理这件事
✓ 这件事你不用替他处理
```

### 3.2 常见病灶

- 支点代词（他／你／我）夹在句子中段，前后各挂修饰
- 一句里出现两组对立概念
- 关键词后面还跟着三个字以上的尾巴

### 3.3 兜底（不改稿时用）

优先级：**停顿 > 局部降速 > emphasis**

```xml
那也是<break time="200ms"/>他<break time="150ms"/>要处理的情绪
<prosody rate="-20%">他</prosody>要处理的
```

`<emphasis>` 对中文神经语音效果弱且不稳定，不作主要手段。**CosyVoice 连这个都没有，只能靠写法。**

⚠ **这条兜底在这仓库里基本用不上**：管线走 `msedge-tts` 的
`toStream(text, {rate, pitch})`，**只接 rate 和 pitch 两个参数**，
`<break>` 一律被 Edge 拒掉。**所以只能靠写法。**

## 四、抽象词三层

| 层 | 例 | 处置 |
|---|---|---|
| 能拍下来的 | 铁鏊子、陶碗、掉在脸上的碎屑 | 随便用，越多越好 |
| 从外面看得出来的 | 停下来、嚼得慢了、抬头看了一眼 | 可用，能换成动作就换 |
| 只能被判断出来的 | 贪、执着、无常、注意力、本质、机制 | **故事段／现象段一个都不许有** |

第三层是听众听完本该自己得出的结论。**提前说了等于剧透，后面的说破就没有落点了。**

### 4.1 书面概念词黑名单

不分线路，全部禁用：

```
看破 执念 意义 本质 状态 机制 参照点 配置
维度 底层逻辑 认知 内耗 能量 磁场
```

这些词在文字里显得高级，在耳朵里是空的。

⚠ **这批跟各线原有的「鸡汤腔」黑名单是两类，别合并。**
鸡汤腔是「愿你／余生／温柔以待／一切都会过去」那批（`chan-check` / `xinli-check` 里已有），
**书面概念词是这一批** —— 一个是滥情，一个是空。两类都禁，但报的时候要分得开。

### 4.2 比喻之后必须跟人话

比喻可以留，下一句必须把它说成结论。半睡状态的人不会自己翻译。

```
✗ 他说的时候一点也不硬，就是陈述
✓ 他说的时候一点劲儿都没使，就跟说今天有点冷似的
```

后者本身就是人话，不需要再翻译一遍。

## 五、句子

### 5.1 长度

| | 上限 |
|---|---|
| 单句 | **20 字**（比说书线更严） |
| 台词／对白 | **10 字** |
| 硬伤线 | 26 字 |

治愈线比说书线严四个字，因为听众更困，句子更长就散了。

### 5.2 长短要错开

```
我说还行。                          （4 字）
我端起杯子喝了一口，杯子是空的。      （15 字）
```

全是等长句会催眠。**一段里至少一次明显落差。**

### 5.3 一句一件事

一条 line 只承载一个信息点。line 内部出现句号或破折号，说明该拆。

## 六、人称

### 6.1 按性质分开算，不按次数一刀切

| 类型 | 例 | 额度 |
|---|---|---|
| **指认型** | 「你其实在等一个评价」「你不是不够努力」 | **≤5 次**，多了像审问 |
| **陪伴型** | 「如果你也有过这样的下午」「陪你把心带回来」 | **不限**，这类「你」是温度的来源 |

判据：这个「你」后面跟的是**对听众的判断**，还是**对听众的陪同**？

### 6.2 现实场景一律无人称

不许出现「你是不是也」「有没有那么一刻」。

```
✗ 你有没有过这种时候，明明很累却还在刷手机
✓ 晚上十一点，说了要睡，然后摸出手机
```

### 6.3 各线的差别

- **方案二道理向**：陪伴型「你」随便用，这条线靠它建立亲近
- **禅佛典故事段**：一次都不许有，故事段是纯第三人称
- **清单体法则档**：只在「落点」那一句用

## 七、语气词

| 位置 | 允许 |
|---|---|
| 台词、对白 | 啊 / 呗 / 嘛 / 吧 —— **允许，而且要有** |
| 旁白、叙述 | **一个都不许有** |

这条同时解决两件事：给台词加人味，以及**让旁白和台词在同一个音色下也能分辨**
（长短句 + 语气词 + 停顿包裹，三条一起就够了，不需要第二档参数）。

## 八、量词与口语词

### 8.1 量词各归各的

```
拧瓶盖用「下」   喝水用「回」   按开关用「次」
这瓶水我拧了四下       我喝了四回空杯子
```

**量词选错，白话就变成了假白话。**

### 8.2 能用口语词就不用书面词

> **黑名单抓不住书面腔的主体。** §4.1 那张 `书面概念词` 表抓的是扎眼的那一类
> （机制／维度／底层逻辑／内耗／磁场），可 2026-08-26 拿四期已出稿量了一遍，
> 真正漏出来的是这些 —— **每个字都是常用字，书面的是搭配**：
>
> | 期 | 逃逸的 |
> |---|---|
> | 治愈《不归你管》 | 关于×3 在于 因此 前者 后者 · 做决定×2 · 的选择 的判决 |
> | 心理《已读不回》 | 在于 并且 · 存在 形成 来自 产生×2 发生×2 · 的反应 的评价 |
> | 禅佛典《第七个饼》 | 关于 以及 另外 其中 前者 后者 之所以 · 构成×2 来自×3 发生×8 |
>
> 所以 `zhiyu-diction.ts` 里另立了**四张表**：
> `书面虚词`（关于／在于／因此／之所以…，各带一个换法）·
> `双音动词`（做决定→定，把动作说成了词）·
> `回指词`（前者／后者 —— **不是不许用，是用了就得把那个东西再说一遍**）·
> `名词化`（「的判决」「的选择」—— **句子里没人在动了**）。
>
> **总判据：这句话能不能在电话里对朋友说出口？**
> 「我们把那句话当成了关于自己的判决」不会 ／「我们把那句话当真了」会。



| ✗ | ✓ |
|---|---|
| 他没说话 | 他没吭声 |
| 他不是为了结果干的 | 他不图什么 |
| 他不是不确定 | 他不是没主意 |
| 我不是看破了 | 我那不叫看得开 |
| 这段对话我们重复过十几次 | 这话我俩来回说过十来次 |

### 8.3 判断句改成认输句

```
✗ 我是不敢          （给自己下定义）
✓ 我就是没敢试      （承认）
```

**角色不给自己下定义。**

## 九、翻转必须被证明

治愈线的核心动作是「不是 A，是 B」。听众凭什么信？

**唯一有效的证明方式是对照：把 A 真的发生一次，看结果有没有不同。**

```
假设三点十三分对方就回了，回的是「周五不行」。
事情到这儿就结束了。答案是否定的，但那个下午不会被占掉。
真正让人一遍遍切回屏幕的，是另一种：他看到了，然后没有说话。
```

没有对照段的翻转，听众只能选择相信或者发懵。

**而且翻转句本身不许靠重音。** 见 §三。

## 十、每期必须先写出中心思想句

**写不出这一句，不许开写。**

它写在稿头元信息里，正文出现两次：前段预告一次，收束段坐实一次。

```
E01 中心思想句：那四十九分钟，你等的不是回复，是他心里怎么想你。
```

判断办法：**这句话能不能原样对一个朋友说出口。** 说不出口的，说明还是书面话。

## 十二、可以脚本化的检查

| 项 | 判据 |
|---|---|
| 超长句 | `len > 26` |
| 台词超长 | `who != 旁白 && len > 12` |
| line 内标点 | 含 `。；——` |
| 书面概念词 | 正则匹配黑名单 |
| 高危字 | 正则匹配字表，输出上下文 |
| 语气词位置 | 旁白句含「啊呗嘛吧」 |
| 指认型「你」 | 需人工判定，脚本只统计总数并列出 |
| 长短交替 | 连续 5 句字数差 <3 则报警　⚠ **依赖「相邻」，见下** |
| 词边界 | `词边界坑` 那张「踩一个记一个」的表（§二之二） |
| 现代词坑 | `现代词坑`（§2.2 那五行的机器实现） |
| **书面虚词** | `书面虚词` 表，各带一个换法（§8.2） |
| **双音动词** | `双音动词` 表（做决定→定）。有的搭配是地道口语，带 `skip` 排除 |
| **回指词** | 前者／后者／其中 —— 报出来，提醒「把那个东西再说一遍」 |
| **名词化** | 句尾「的+抽象名词」（的判决／的选择／的反应） |

> ⚠ **「长短交替」这一条依赖「相邻」，改了断句粒度它会静默失效。**
>
> 说书线 2026-08-26 亲眼见过一次：那边有一条「连续三句同提示语」，
> 后来为了对齐字幕行宽把每条 line 砍到 24 字以内，
> **三个提示语中间各隔了一条续句，「连续」这个判据当场不成立** —— 而且不报错，
> 是人听出来的。后来改成「六句窗口」才修好。
>
> **元教训：切碎表示形式，会让依赖那个形式的判据静默失效。**
>
> 这条线哪天要是也改断句粒度（比如为了文字版的字号把长句拆开），
> **「长短交替」这一条要第一个回来重看。**

**人只需要看剩下这些** —— 它们印在 `zhiyu-diction.ts` 的**必答清单**里，
三支 check 每期各印一遍（见 §十五.4 那条 ⚠：**这张清单以前从来没印出来过**）：

口语两条（§8.2）· **温情三条（§十五）** · 原有五条
（中心思想句是不是人话 · 翻转有没有对照 · 抽象词是不是提前了 ·
「你」是指认还是陪伴 · 量词对不对）。

**温情那三条是这份规范里唯一的加法**，也是反复失守的那一条 —— 排在清单最上面。

## 十三、落地（2026-08-26）

### 13.1 一份实现，三条线共用

```
joke-video/src/zhiyu-diction.ts   ← §十二 那八项全在这儿
        ↑            ↑            ↑
   zhiyu-check   xinli-check   chan-check
```

⚠ **没有第四个脚本。** 新开一支就得靠人记得跑，
而这仓库的教训是**靠人记着就每次都会漏**（短片那张自检表当年正是因为
「没有代码在守」才漏掉四条）。所以接进三条线**已经在跑的那三支**。

跑法不变：

```bash
npx tsx src/chan-check.ts  --ep e01-第七个饼
npx tsx src/xinli-check.ts --ep e01-已读不回
npx tsx src/zhiyu-check.ts --ep taoan-E01
```

### 13.2 ⚠ 判据分两级，不是一刀切 error

| 级 | 哪些 | 为什么 |
|---|---|---|
| **error** | 硬伤线 >26 字 · 书面概念词 · line 内句号破折号 | 这几条没有例外，写了就是错 |
| **warn** | 单句 >20 · 台词 >10 · 高危字 · 旁白语气词 · 长短不交替 · 「你」计数 | **可能是对的** —— 高危字在明确语境里没歧义，「你」要分指认／陪伴 |

**一刀切 error 的下场这仓库见过**：天天报错的闸门只会教人加 `--anyway`，
那样连有用的那几条也一起失效。

### 13.3 ⚠ 旁白／台词怎么分

这三条线的稿件**没有说话人标记** —— 全是段落，对白裹在引号里。
所以脚本按**引号**分：`「…」` / `"…"` 里的算台词，外面的算旁白。

**判得出来的**：旁白里的语气词（引号外的「啊呗嘛吧」）。
⚠ **判不出来的**：不加引号的引述。长片那条线撞过同一个坑
（「我问过他，你不累啊」那个「啊」是引述，排除不掉）。**所以这一项是 warn。**

### 13.4 跟各线原有黑名单的关系

各线本来就有一份「鸡汤腔」黑名单（`愿你` `余生` `温柔以待` `一切都会过去` …）。
**§4.1 那批是另一类** —— 一个是滥情，一个是空。

**两批都留，分开报**：`[鸡汤腔]` 归各线自己那份，`[书面词]` 归这一份。
合成一张表的话，改的时候分不清哪条是哪条线的。

## 十四、审稿：三层，靠「拿走信息」分工（2026-08-26 立）

> **判据、元教训、审稿方法这三样是跨线共有的，正文在
> [`../稿件审查通则.md`](../稿件审查通则.md)。** 这儿只写这条线自己的部分 ——
> 各写一份迟早漂移，而那种不一致没人核得出是哪边错的。

### 为什么需要第二个审者

说书线 E06 有四处「看着没问题、听着有问题」，机器没抓到，**写的人也没抓到**。

原因不是不仔细，是**他知道自己想说什么** —— 读到「千万颗心里头」，
脑子里自动是正确切分。**这个先验删不掉。**

所以第二个审者的价值**不在多看一遍，在拿走信息**。
派「审一下这稿子」给它，回来的一定是「建议加强画面感」那类
（＝《治愈系稿件规范》第十一节说的 AI 味儿）。
要派**机械的、可枚举的、答案唯一的**活。

### 三个 brief，各自缺一块

| 审者 | 拿走什么 | 抓什么 |
|---|---|---|
| **A · 二读** | **作者的意图**（只给逐条句子，不给篇名、幕名、中心思想句） | 词边界 ／ 多音字 ／ 单音节裸奔 ／ 同音词 ／ 两个语域 |
| **B · 一遍懂** | **回看的机会** | §一 第三条自查「需要回想的句子」 |
| **C · 只读一段** | **上下文**（只给一个段落） | 通用模板段 —— **脱离上下文也成立的那种** |

### B 为什么是「一遍懂」，不是说书线那个

说书线的 B 是「只读冷开场和收束，查收束的论断有没有在正文演过」。
**这条线没有那个结构** —— 说破层在这条线上是反着来的，没有「收束的论断」这一说。

换成「一遍懂」，是因为 §一 第三条自查（**念给没看过稿的人听，问他刚才那句什么意思**）
是这条线的核心判据，**而它现在只能靠人**。

brief 的做法：要求审者**顺着读、逐句即时作答、不许用后面的句子回头修正前面的理解**。
凡是它答不上来或者答错的，就是「需要回想」的句子。

⚠ **这是软约束** —— 模型其实能回看。所以 **答错了是证据，答对了不算证明。**
要更硬就一次只喂一句，代价贵很多。

### C 为什么在这条线上最该跑

《治愈系稿件规范》第十一节那四条「人味儿」判据，
**就是心理洞察 E01《已读不回》「通用模板段」那次翻车长出来的** —— 这条线是这个病的原产地。

而模板段的特征就是**脱离上下文也成立**，所以**给了上下文就看不出来**。
只有拿走上下文的审者看得见。

### ⚠ brief 里必须一开始就写的两条收窄

说书线头一次跑 A，**577 条报了 112 条（20%）**，八成是噪声，两个来源：

1. **把「单音节」当成「单音节裸奔」** —— 句尾单字是节奏，不是毛病。
   要的是「单字 content word **而且有歧义**」
2. **把引文当成语域混杂** —— 前面有「原话是这么写的」垫着的，是故意的

⚠ **这条线的引文比说书线更多**（方丈记／陶庵梦忆／心经／信心铭），
**第二条在这儿会更凶，必须一开始就写进 brief，不能等踩了再改。**

### 两条纪律

- **审者只报，不改。** 定稿权在写的人手里 —— 审者没有全局，它的改写一定会破坏别处
- **驳回要写理由，落进稿件头部**。不写的话下一期同一处会被再报一次，
  几期之后就没人看它了

### 头一次跑的实测（治愈 E01《不归你管》，2026-08-26）

**89 条报 6 条 —— 6.7%，六条里五条是真的。**

对照说书线头一次跑：**577 条报 112 条（20%），八成是噪声**。
差别只有一件事：**这次那两条收窄一开始就写进 brief 了。**

五条真的：

| | 病 |
|---|---|
| 「路上的事**得**他自己受着」 | 得 dé／děi。**§2.2 那张表里本来就有这一行，机器一直没查** |
| 「**分辨**的办法很简单」 | ≡「分辩」（为自己辩解）。上文全在讲「解释／说清楚」，听众更容易听成后者 |
| 「饭桌**上一句话**不讲」 | 「上一句话」是高频固定词 → 听众回头找「上一句」是哪句 |
| 「跟**真正在**乎你的人」 | 「真正」和「正在」都要中间那个「正」→ 切成「真 / 正在 / 乎」 |
| 「还在心里**转**」 | zhuàn（打转）／zhuǎn（转变）都成立，后半句「放一放」只对得上前者 |

**第一条最值得记**：§2.2 那五行**在文档里躺了很久，机器一直只有「一段 ≥3 个高危字」那条粗筛**，
而「事得他自己受着」只有两个高危字，**够不着阈值**。
又一次「规范写在文档里、机器不查，等于只防君子」。现在补成了 `现代词坑` 那张表。

**顺带**：审者报的两条新坑（上一句话／真正在）已经进 `词边界坑`，
**机器现在独立复现了这五条中的五条** —— 这就是「踩一个记一个」跑起来的样子。

⚠ **从说书线搬来的那批通用款里，「东西」那条首跑 2/2 误报**（在已发布的 taoan-E01 上），
当场撤掉。**搬过来的表不能照单全收，要在自己的稿子上量一遍。**

### 命中率是要盯的数

20% 意味着人要读 112 条才捞到 20 条 —— 再高一点这一层就会被跳过，
跟那些永远为假的警告一个下场。**目标 5% 上下。**

## 十五、温情：这一节是加法（2026-08-26 加）

⚠ **这是这份规范里第一条「该写什么」。**

前面十四节全是禁令 —— 不许靠重音、不许抽象词、不许语气词、不许超长句。
禁令能把稿子改**干净**，可**干净不等于有人味**。
「用语太书面、太机械，要多用口语词和温情用语」这条反复失守，
一半的原因就在这儿：**照着规范改，改出来的是「挑不出毛病的稿子」。**

### 15.1 温情不是形容词，是「具体的人在做具体的事」

| | |
|---|---|
| 「朋友难过的时候你陪着」 | **暖** —— 有人，有动作 |
| 「这叫在场」 | **冷** —— 这是个命名 |
| 「他难过」 | **冷** —— 形容词 |
| 「他把碗筷摆正了」 | **暖** —— 动词 ＋ 物件 |

**规律：温度在动词和物件上，不在形容词上。**

想说一个人难受，别写「他很难受」，写他那天做了什么反常的小动作。
听众自己会得出「他难受」，而**他自己得出来的那一下，才是温度**。

### 15.2 三条判据

1. **这一段里，有没有一个人在做一件看得见的事？** 没有，这一段就是冷的
2. **落点不许停在命名上。** 「这叫在场」之后必须回到画面 ——
   命名是给听众一个把手，但把手不是东西本身
3. **抽象一次，具体一次。** 说完一句判断，下一句必须落回一个能看见的东西

### 15.3 跟 §四「抽象词三层」的关系

§四 是**减法**（把抽象词拿掉），这一节是**加法**（把具体的东西放进去）。
**两条要一起用** —— 只做减法，得到的是一篇没有抽象词、也没有画面的稿子，
那种稿子读起来「没毛病」，听起来是空的。

### 15.4 机器帮不上忙

温度判不了。§十二 那张表里一条都没有这一节的东西 ——
它只在 [`zhiyu-diction.ts`](../joke-video/src/zhiyu-diction.ts) 的**必答清单**里，
每期跑体检的时候印一遍。

⚠ **这张清单 2026-08-26 之前从来没印出来过。**
`printDiction` 里本来有一句「剩下五样只有人能看」，可**三支 check 都没调用它** ——
它们各自 import `checkDiction` 自己打印。那个函数长期是死代码。
**清单写了、但没有任何一个时刻会出现在眼前** —— 这是这条规则反复失守的第三个机制。
