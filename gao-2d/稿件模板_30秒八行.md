# 稿件模板 · 30 秒八行（Stated Figures）

日期：2026-09-09　　状态：**新稿一律按这份写**，跟方案 §4 并行（方案是通则，这份是当前采用的具体格式）

---

## 一 频道人格

**Stated Figures** —— 冷面英式讽刺。参照系是「BBC 主播一本正经念一份荒谬报告」：
完全严肃，但底下全是嘲讽。**100% 中立、客观、冷**，情绪判断一个字都不加。

---

## 二 四条硬规则

| # | 规则 | 跟方案的关系 |
|---|---|---|
| 1 | **不涉及中国**，提都不提，暗示也不行 | 方案 §1 已有，唯一的硬边界 |
| 2 | **不加形容词**（horrible / shocking / disastrous 一类）。只陈述原始数据，让数字自己说话 | 方案 §12 第一项已有 |
| 3 | **数字全部拼成英文单词**：写 `seven hundred and sixty million pounds`，不写 `£760m` | 方案 §4.5 已有，那儿还有一张对照表，照它走 |
| 4 | **不用任何方括号标记**（`[uv_break]` / `[sigh]` 一类）—— 引擎会把字母念出来。节奏全靠标点：连字符、句号、逗号 | 方案 §4.5 已有，措辞更狠：「整条音频作废」 |

## 三 词数预算：30 秒 ＝ **约 57 词**

这是这份模板最容易翻车的地方，先把账算清楚。

**实测数据**（坑洞篇，Kokoro `bm_george` @ `speed 0.9`）：

```
成片 48.447s ＝ 净语音 39.05s ＋ 硬插停顿 9.40s
92 词 / 39.05s ＝ 2.36 词/秒（trim 掉首尾静音之后的净语速）
```

⚠ 方案 §5.1 表里那个 **1.71 词/秒**是**单句 12 词**的测量值，整篇算下来是 **2.36**。
写稿按 2.36 算，按 1.71 算会写短一半。

**30 秒怎么分**：

| 项 | 秒 |
|---|---|
| 八处停顿（0.3–1.2s，均值约 0.7） | ≈ 5.5s |
| 净语音 | ≈ 24.5s |
| **词数上限 24.5 × 2.36** | **≈ 57 词** |

⚠ **`出声.mjs` 报的时长不是成片长度。** 它量的是**未修剪**的分段（首尾各带一截静音），
坑洞篇按它算是 51.2s、《一个词干的活》是 37.6s，而两条成片分别是 48.4s 和 31.4s ——
`配音.mjs` 会把首尾静音剪掉（后者剪了 6.2s，八段平均 0.77s/段）。
**成片长度以 `配音.mjs` 那张表为准**，出声那个数只用来看每段读得顺不顺。

**八行平均每行 7 词。** 这个数正好顺手解决了另一件事 ——
方案 §6.6 要求字幕每屏 3–5 词，坑洞篇 7 条字幕全部超标（最长 12 词排了 5 行，压住角标）。
**每行 7 词排 2 行，安全。** 写的时候就按「一行能不能拆成两屏字幕」自检。

## 四 四段节奏

| 段 | 时间 | 要什么 |
|---|---|---|
| **Hook** | 0–3s | 一个反直觉的数字或陈述，**零铺垫**。第一个词就是钩子 |
| **Escalation** | 3–15s | **三条**原始数据，来自官方审计／议会文件。一条比一条荒谬 |
| **Twist** | 15–25s | **至少一条反面事实**，或者「支持这项政策的人为什么支持」。⚠ 这一段同时是**法务护栏**（方案 §13）——它证明你没有单边指控；而且它比直接骂更讽刺 |
| **Cold Outro** | 25–30s | 冷收 ＋ 一个开放问题。**问题必须指向观众自己的数据或日常经验**，不指向党派立场 —— 这是防评论区污染的闸（方案 §8.2） |

Twist 那一段是整条片子的支点。坑洞篇的「预算确实涨了 17%，路况确实改善了——三个百分点」
就是它起作用的样子：前面所有的钱，被这一句自己压塌。

## 五 输出格式：两部分，缺一不可

### Part 1 — 纯文本块

一整块连续英文，直接粘进 Kokoro / ElevenLabs。**块里不能有**：阿拉伯数字、货币符号、
方括号、任何标记。只有单词和标点。

### Part 2 — 八行对齐表

| 列 | 内容 |
|---|---|
| ID | 1–8 |
| English line | 这一行的台词 |
| Pause after | 该行读完后的静音，写成 `0.8s` / `1.2s` 这种 |
| 中文 | 校对用，**不进音频不进字幕** |
| Layer A 字卡 | 卡型 ＋ 卡面内容；不用时写 `none` |
| Layer B 主讲人 | 帧组名；不用时写 `none` |

**字放哪儿**（2026-09-09 拆掉 A 层之后）：

- **句子** → `punch` 强调字幕，叠在画面上（大字 ＋ 红底扫开）
- **数字** → `lower` 数据条，叠在主讲人胸口
- **画面** 永远是 B / C / DOC —— **不再有「纯字占满一屏」这种块**

⚠ 带 punch 的块**用 MS 不用 MCU**（特写会被字盖住眼睛），而且**不配字幕**
（punch 已经把整句摆上去了）。punch 和 lower **不能同块**，纵向会叠。

⚠ **A / B 互斥**：A 在用时 B 必须是 `none`，反之亦然。
这条在仓库里**已经是数据结构保证的** —— `时间表.mjs` 的 `layer` 是单值字段，
不是 `layerA/layerB` 并列（方案 §7.3：「从数据结构上就不可能同时给两层分配内容」），
而且 `自检.mjs` 第 2 项会拦住残留的旧字段。写表时照 A/B/C/DOC 四选一填。

## 六 写完之后

八行表不是终点，落进管线还要三步：

1. 拆 `分句.mjs` —— 每一处停顿是一个段边界（坑洞篇 16 段，15 处停顿全靠硬插静音实现）
2. 跑 `出声.mjs` → `配音.mjs`，**拿实测时长回填时间码**（方案 §7.3；`--check` 有时长闸盯着）
3. 写 `时间表.mjs`，每块 C / DOC 填 `素材` 字段，上屏英文填 `中` 字段

⚠ **别在八行表阶段就填死时间码。** 表里的 `Pause after` 是设计值，
块的起止秒数必须等音频出来之后按实测算 —— 这是今天踩过的坑（差了 6.45 秒）。

## 七 引擎

方案 §5.1 定的是 **Kokoro-82M v1.0 ONNX，音色 `bm_george`，`speed: 0.9`**，本地跑。
提示词里提到的「Kokoro v3」在仓库里没有对应版本，**以方案 §5.1 为准**；
