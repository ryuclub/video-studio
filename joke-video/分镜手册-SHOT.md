重跑一次就同步——手写的图和表会过期，过期的参考比没有更费时间。

写新稿件时先翻这份：**有现成的就别新做**，不够用再加，加完记得重跑。

## 三、镜头类型

### 双人同框

- **怎么写**：`stage` 不写（默认全部在场）
- **什么时候用**：两个角色你来我往、需要看到彼此反应时。A 类段子的默认
- 镜头会左右摇跟随说话者，笑点句推近到 1.34

### 单人镜头

- **怎么写**：`"stage": ["kid"]`
- **什么时候用**：分镜是「镜头1 只有小龟，镜头2 只有龟妈妈」这种交替时
- 角色自动居中，镜头不再左右摇、只做推近。定格沿用笑点那一镜的名单

### 爬入 / 走入

- **怎么写**：`"enter": "right"`
- **什么时候用**：角色这一镜才登场，要「慢悠悠爬过来」
- 从画外开始，用整句时长爬完、最后 20% 落位；期间四肢做走路循环。只在这一句前后生效

### 缩壳登场（乌龟专属）

- **怎么写**：`"neckEmerge": true`
- **什么时候用**：「远处一块石头缓缓抬起头」这种揭示
- 开口前 0.5s 才把头伸出来。要梗成立，角色配色得跟背景礁石接近

### 定格去色

- **怎么写**：`freeze`（秒）
- **什么时候用**：笑点抖完，画面冻住 + BGM 骤停
- 整帧去色 85%。`hook` 尾字幕**跟定格同时出现**且不去色，会在灰调里跳出来。别等定格快结束才出——中间那段纯灰画面没信息，白占时长

### 开场空镜

- **怎么写**：`intro`（秒）
- **什么时候用**：每条片子开头，交代环境
- 镜头从 1.06 缓推到 1.0；角色从画外滑入。**先出人、滑到位了才开口**

### 开场大字 · 场景（出场档 ②）

- **怎么写**：`opening: { style: "voice-first" }`
- **什么时候用**：老马线的第二档出场风格。首帧要对比度、要一个数把人钩住的时候用
- **场景照常出，人不出，第 1 句里那个数压成大字盖在场景上**；**音轨从 0.0 起**（`intro` 强制归零）。第 1 句一停字就撤，角色在那半秒静音里滑进来。入场动画本身没改，只改了它跟音轨的对齐关系。**角色的出场变成一个兑现** —— 观众先被那句话钩住，才看到说话的人是谁。⚠ 做过一版整幅黑底的，黑得太久（第 1 句要念三四秒），而且场景这条信息白白晚到四秒

### 开场物件特写（出场档 ③）

- **怎么写**：`opening: { style: "object-first", frameSubject, frameText }`
- **什么时候用**：物件是画得出特写的实物，而且要抢信息流里那 120px 缩略图
- **只有物件，没有场景没有人**（首帧规范 §五 把「整幅场景图」列成禁令：信息量太散，观众要花半秒扫画面，同时声音在讲第一句，注意力分裂）。字在物件正下方 y=0.72H，**其中的数字标朱红** —— 首帧唯一的一点红，跟收尾卡「第 N 天」一红一黑开合对上。⚠ 验收看 `npm run frame` 出的 **120px 缩略图**：物件认得出吗？数字看得见吗？⚠ 抽象物件（系统、群）画不了特写，那种稿子走 ②


### 平滑度红线

改完镜头逻辑必须自查：

```bash
ffmpeg -v error -i <成片>.mp4 -vf "select='gt(scene,0.06)',metadata=print:file=-" -an -f null -
```

**检出的每一处都要能说出是哪个设计动作。** 合法的只有两类：

- `0.033s` —— 封面帧切到开场，设计如此
- **分镜切换点** —— `stage` 名单变了，那本来就是一次切镜头

除此之外的检出都是 bug。早先 `camera()` 按当前时刻直接算目标值时，
14 秒的片子能检出 5 次，全在台词首尾——那是镜头一推一拉在抽。

两条规矩：镜头必须走**关键帧插值**，不能按当前时刻直接算目标值；
**句间停顿不要把镜头拉回原位**，保持上一句的构图直到下一句起范儿。

### 单人镜要给不同景别

两个单人镜构图一模一样时，切换看着不像切镜头，**像角色原地瞬移**——
场景没变，只有主体换了。所以 solo 镜按角色错开 zoom（1.10 / 1.22）和高度，
切换才读得出是两个机位。

## 五、做新场景/新角色的流程

```bash
npm run shotdoc                    # 先看有什么现成的
npm run scene -- <名字>            # 新场景做完，单看空场
npm run still -- <cfg> 1.0 4.0     # 放进角色，看指定时刻的构图
npm run build -- <cfg>             # 出片（起手会跑 preflight 体检）
```

`preflight` 会拦住这些：场景/骨架/音色不存在、两个角色撞音色、punch 数量不对、
台词为空、highlight 不在台词里。**有问题一帧都不渲就停**，不会等你看到成片才发现。
