风格基调跟 E01 一样：**极简古典**。不用感叹号、不用「震惊」「细思极恐」。
检索词该带的一个不少，但要**长在句子里**。

**这一期跟 E01 有个分别要拿捏**：《画皮》卖的是恐怖，《聂小倩》卖的不是。
它的芯是后三分之一那段日常——扫地、挑水、守夜。
文案要把恐怖当**入口**，别当卖点，不然点进来的人在第 12 分钟就走了。

## 一、标题

**主选**

```
聊斋志异·聂小倩｜她杀过两个人，没人要她偿命
```

- 「聊斋志异」放最前：搜索量最大的词，也是频道的锚
- 「聂小倩」是篇名，独立检索词，认知度仅次于画皮
- 后半句是钩子，走的是**故事里最反常的那件事**，跟封面同一句
- 全长 23 字，手机端列表两行显示得完

**刻意避开的**：没有沿用 E01「他明知她是鬼，还是带她回家」那个句式。
同一个构造用第二次就成了套路，第二期还不到用套路的时候。

**备选**（换封面或做 A/B 时用）

| | 标题 | 侧重 |
|---|---|---|
| 备 1 | `聊斋·聂小倩全本｜他没要她，也没要那锭金子` | 「全本」吸引找完整版的人；点出两次拒绝 |
| 备 2 | `有声书·聊斋志异《聂小倩》｜女鬼自己承认杀过人` | 「有声书」是另一个大流量入口 |
| 备 3 | `深夜说书·聂小倩｜荒寺，孤灯，门外站着一个不肯走的人` | 场景型，配「孤灯」封面 |

**不要用的写法**：`【最美女鬼】`、`倩女幽魂原著`、`看完睡不着`。
前两个把片子推给影视二创的池子（那里比的是剪辑不是讲述），第三个跟调子不合。

## 二、内容简介

### 前两行（列表页只显示这些，最要紧）

```
荒寺里连死两个人，脚心上都有一个针眼大的孔，血被抽干了。
第三夜，那个姑娘敲开了宁采臣的门——她带着一锭金子来。
```

### 完整版

```
荒寺里连死两个人，脚心上都有一个针眼大的孔，血被抽干了。
第三夜，那个姑娘敲开了宁采臣的门——她带着一锭金子来。

《聂小倩》是《聊斋志异》里最动人的一篇。这一期按原文讲全本：
兰若寺借宿、两条人命、夜叩、掷金、小倩自陈、燕赤霞剑光、归葬，一段不删。

这个故事狠的地方不在鬼。小倩杀过两个人，是她自己跪在门外承认的，
没有哭，也没有替自己分辩一句。而蒲松龄自始至终没有安排她赎罪、立功、
以死谢过——他只是让一个人不占她的便宜，然后让她活了过来。

宁采臣做的事说穿了只有一件：夜里有人送上门，他没要；有人送金子，他扔了出去。
这两件都不算英雄行为，只是没有伸手。
而这个故事里死掉的那些人，都是伸了手的。

后三分之一没有鬼，只有扫地、挑水、做饭、守夜。那才是这一篇的芯。

原文出处：《聊斋志异》卷二（公有领域）。
```

## 三、关键字 / 标签

**核心（必带，按权重排）**

```
聊斋志异, 聂小倩, 聊斋, 有声书, 说书, 中国志怪, 蒲松龄, 民间故事, 睡前故事, 古典文学
```

跟 E01 的核心标签比，**「恐怖故事」从核心挪到了长尾**，位置让给「古典文学」。
这一篇的留存靠后三分之一的日常，把它推进恐怖池会拉低完播。

**长尾（搜索友好，覆盖不同说法）**

```
聊斋志异全集, 聂小倩原文, 倩女幽魂原著, 聊斋有声书, 中文有声小说, 恐怖故事,
鬼故事, 志怪小说, 燕赤霞, 宁采臣, 国风, 深夜电台, 助眠故事, 长篇有声书
```

**说明**

- 「倩女幽魂原著」放长尾**不放标题**：它带流量，但点进来的多半是找电影的，
  期望对不上，完播会差。放在标签里让搜的人能找到就够了
- 「燕赤霞 / 宁采臣」是这一篇特有的人名词，E01 没有对应的
- 不要堆无关热词，平台现在对标签堆砌的惩罚比奖励大
