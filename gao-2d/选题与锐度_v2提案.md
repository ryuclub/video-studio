# 选题与锐度 v2 —— 提案

日期：2026-09-09　　状态：**提案，未并入正文**

这份是对「内容太平淡、话题性冲突性不够」的回应。改的是方案 §1 边界和 §3 选题，
是频道的根本设定，所以先写成提案，方向确认后再并进 `英文频道出片方案.md`。

## 1. 诊断：平淡的病根不在选题，在结构里没有对手

拿已经做完的坑洞篇当样本。数字都在，而且都硬：

> 97 年重铺一次 · 190 万个坑 · £18.62bn 积压 · 12 年清完 · 预算涨了 17%

**但整条片子从头到尾没有一个「他们」。** 没有人做错什么，没有人说过什么后来被打脸，
没有两笔钱可以并排。观众看完点个头就走了 —— 因为没有什么东西需要他有反应。

对比方案 §3.4 那个超市锁柜的例子：同一家公司的财务高管先说「我们哭得太凶」、
损耗在回落、保安「基本无效」，两年后同一家公司又说这是「系统性问题」。
**一个字不评论，柜子还锁着。** 这条狠得多 —— 而且它一句主观话都没有。

所以病根是：**选题选的是「一个坏状况」，不是「一场还在进行的冲突」。**
坏状况只能陈述，冲突可以展开。

## 2. 必须先分开的一件事：不中立 ≠ 不讲理

你说「不讲中立，甚至可能不太逻辑或理性」。前半句我完全同意，后半句要分开看，
因为这两件事在这条频道上的后果完全相反。

**不中立 —— 应该，而且现在做得远远不够。**
有立场、有态度、有讽刺、有明确的攻击对象。立场表现在**选什么、怎么排、说到哪儿停**。
现在的稿子在这一点上是软的，该硬起来。

**不讲理 —— 这条会把频道做死，而且是唯一能做死它的东西。**
这个频道的护城河只有一条：**每句话都能指回一个公开来源**（方案 §0 的元规则）。
放弃它之后，它就变成了 YouTube 上几万个愤怒吐槽频道里的一个，而且是没有事实撑腰的那种。
那类频道的天花板是几万订阅，然后被算法归进「低质量争议内容」限流。

**关键在于：最狠的讽刺恰恰是事实密度最高的。**
Last Week Tonight、Some More News 这类立场鲜明到不能再鲜明的节目，
每个数字都有来源，而且把来源打在屏幕上 —— 他们的攻击性**恰恰建立在「你没法反驳我引的东西」上**。
一旦开始编，对手只要抓住一处，整条片子连同频道的可信度一起塌。

所以 v2 的方向是：**锐度全面提高，事实链一寸不让。**
锐度从选题和结构来（§4），不从形容词和立场宣言来。

## 3. 你列的十六项，分三档

### A 档 —— 直接做，而且能做得比现在狠得多

这几项的共同点：**冲突是现成的，而且冲突双方都在公开档案里留了字。**

| 方向 | 能做的角度 | 档案在哪 |
|---|---|---|
| **战争** | 军购超支、装备计划资金缺口、退伍军人索赔积压、援助里的旧库存折价 | 美国 GAO 年度报告、国防部监察长；英国 NAO《装备计划》年报 |
| **移民** | 庇护积压案件数 × 平均等待月数、拘留与安置的日均成本、加急签证费买的是「本该有的速度」 | 内政部 / USCIS 季度统计、NAO 对酒店安置的审计 |
| **选举** | 选区形状 vs 人口分布、投票排队时长的地区差、选票设计错误、计票设备采购合同 | 选举委员会数据、法庭记录、公开采购库 |
| **贸易壁垒 / 民族主义** | 税则表里的荒谬分类、「本国优先」采购条款的溢价、报复性关税清单的选择性、脱欧边境检查的成本 vs 承诺 | HTS/UK Tariff 原文、GAO/NAO 成本测算 |
| **衰败** | 基础设施评级、下水道溢流小时数、结构缺陷桥梁数与修复速度、图书馆与泳池关闭数 | ASCE report card、Environment Agency、地方政府年报 |
| **灾害** | 响应时间线 vs 预案承诺、洪水保险拒赔率、重建资金到账时间、预警系统失效记录 | FEMA、事后独立调查报告、议会质询记录 |

### A+ 档 —— 末日 / 外星人 / 阴谋论：这条是宝藏，建议当重点线做

这一组你可能是随手列的，但它**同时满足话题性拉满和全是官方档案**，
而且没有党派对立面 —— 不会像移民、选举那样撕评论区。视觉上还是 DOC 层的富矿。

| 选题 | 为什么狠 |
|---|---|
| **政府自己的末日准备** —— Continuity of Government 预算、地堡维护费、应急接班序列 | 他们真的在准备。**只是不准备你。** 这一句就是整条片子 |
| **国家风险登记册**（英国 National Risk Register 是公开的） | 政府自己排序的「最可能杀死你的东西」。排第几名往往出人意料 |
| **UAP 国会听证 + 国防部 AARO 报告** | 全是官方记录，话题性极强，而且官方措辞本身的闪烁就是内容 |
| **已解密的真实荒谬项目**（MKUltra、Paperclip 一类） | 档案馆有原件可调。不需要任何阴谋论，原件比阴谋论离谱 |
| **官方辟谣文件本身** | 政府专门发文说「这不是真的」—— 这份文件存在，本身就说明有人问过、而且问的人不少 |

这条线的做法是：**不站在阴谋论那边，也不站在辟谣那边，只念档案。**
方案 §3.2 的 C 级纪律在这儿反而是最大的武器 —— 什么都不裁定，只把文件摊开。

### B 档 —— 能做，但只做「数字层」，死守 §1 那张三层表

| 方向 | 只做这一层 | 绝不碰 |
|---|---|---|
| **民主** | 法案页数与投票前阅读时间、议员出勤率、游说支出、修正案数量 | 「民主是否失败」这类价值判断 |
| **多元化 / 国际化** | 合规培训工时成本、多语言标识预算与翻译错误、欧盟 24 种官方语言的翻译账单、国际组织差旅支出 | 政策该不该存在 |
| **多民族** | 只做预算与行政流程 | 任何关于群体特征的陈述 |

这三项做数字层完全够狠 —— 欧盟每年的翻译预算是个真实的大数字，
念出来就有效果，而且没有任何人能反驳你，因为那是他们自己公布的。

### C 档 —— 两项不做：伊斯兰教、黑人

不是道德判断，是四条实操理由：

1. **跟频道自己的边界直接冲突。** §1 写着「骂制度，不骂人」。把一个宗教或一个族群
   当成选题，主语就从制度变成了人群 —— 这是频道设定的反面。
2. **平台风险是频道级的，不是单条级的。** YouTube 对「针对受保护属性的群体」的处理
   是砍频道，不是限流单条。做了十条好片，一条踩线全归零。
3. **§13 法务那四条在这里全部失效。** 第一条要求「主语转嫁给公开文本」——
   但不存在「the regulator's decision notice states [某族群]…」这种文件。
   没有可转嫁的主语，就没有防线。
4. **而且没有必要绕这一圈。** 这两项想要的话题性，A 档里全都拿得到，而且更狠：
   庇护积压的等待月数、拘留成本 vs 酒店成本、宗教场所的规划许可争议
   （planning permission 是纯行政记录，可以点名、可以调原件）。

**换句话说：想做的效果照做，只是主语必须是部门、预算、法条、判决书。**

## 4. 锐度从哪来 —— 五个结构手法

这一节是 v2 的核心。**这五个手法一个形容词都不用，但每一个都比现在的写法狠。**

### 手法一：让机构自己打架

同一个机构、同一家公司，在两个时间点的两套官方说法，并排放，不评论。

```
2023：内政部说积压「将在年底前清零」。
2026：同一个部门说积压是「历史遗留的结构性问题」。
积压数字：从 X 涨到 Y。
```

§3.4 已经写了这个手法，但六个模板里没有一个是专门用它的。建议升级成 T7（见 §5）。

### 手法二：两笔钱并排

两个都是真数字，来源都硬，放一起就是暴击。不需要说「这很荒谬」。

```
清理积压需要：£18.62bn
同年花在 ___ 上：£___
```

⚠ 这个手法最容易滑进 C 级 —— 并排暗示了「本该花那笔而不是这笔」。
安全做法：**两笔钱必须来自同一个预算主体、同一财年**，否则就是在做因果暗示。

### 手法三：承诺 vs 兑现的时间线

官方原话 + 日期 + 现状。T5 已经是这个骨架，但现在只用来排数字，没用来排**原话**。
引原话的杀伤力比引数字大一个量级，而且完全安全 —— 那是他们自己说的。

### 手法四：念官方定义

法规原文里的定义本身就是笑话。这个手法零风险、零成本，因为你只是在朗读法条。

```
「临时」在该条例中的定义是：不超过 ___ 年。
```

### 手法五：点名 —— 但只点文件点过的名

§13 明确允许引用**公司自己的公开表态、监管机构的正式决定书、议会文件、法庭记录**。
这是可以点名的合法路径，而现在的稿子一个名字都不敢点，锐度自然上不去。

```
✅ The regulator's final notice names the company and sets out the penalty.
✅ The chief executive told analysts on the company's own earnings call: "…"
❌ Everyone knows this company has been…
```

**点名是这次提锐度最大的一块空间，而且它不需要任何规则松动 —— §13 本来就允许。**

## 5. 模板扩充：T7–T9

现有六个模板（§4.2）里，T1/T4/T5 是「排列事实」型，T3/T6 是「扮演」型。
缺的正是「冲突展开」型。补三个：

| 编号 | 名称 | 骨架 |
|---|---|---|
| **T7** | **Their Own Words** | 同一主体两个时间点的两套官方说法并排 → 中间那个数字反而涨了 → 不评论 |
| **T8** | **The Definition** | 念一条法规定义 → 念它在现实中对应的东西 → 停 |
| **T9** | **The File** | 全程只调阅一份档案（风险登记册、听证记录、解密文件），逐页念，念到最离谱那一条停 |

T9 是给 A+ 档那条线专门设计的，而且它天然满足 DOC ≥15%（多半会到 60% 以上），
出片成本极低 —— 一份 PDF 就是全部素材。**建议第一条 v2 稿件就走 T9。**

## 6. 结尾引导问题也要跟着改

§8.1 现在是「经历征集」型（「你家那个坑在那儿多久了？」）。
这类问题安全但没劲。A+ 档和 A 档适合的是**站队型**，因为它们本来就有冲突：

- 站队型：「Which of these did your government actually plan for?」
- 打赌型：「Guess which one ranks higher on their own list.」

⚠ 但 §8.2 那条「评论区党派化」的风险要一起管：站队型问题**只针对文件内容**，
不针对党派立场。问「猜猜哪个排名更高」安全，问「你还信任他们吗」不安全。

## 8. 一句话

**锐度不来自骂得更凶，来自让对方自己说过的话互相打架。**
现在缺的不是立场，是对手 —— 而对手一直都在公开档案里，只是还没去调。
