# 频道 · 碎嘴老马

---

## 一、先把「碎嘴」定义清楚

**这个名字和人设有张力，必须在简介第一句化解掉。**

「碎嘴」在中文里默认读作话痨、絮叨、密集输出。但老马是陈述句、不喊不骂、三十秒只讲一个梗，是惜字如金那一路。观众看到名字预期一个话密的角色，点进来发现是个闷葫芦，预期就错位了。

**唯一能圆过去的读法：碎嘴指的是频率，不是密度。**

他每天都在嘀咕，但每次只嘀咕一句。就是办公室里那个会小声念叨的人——你听不太清他说什么，但他确实一直在说。

这个读法一旦立住，名字反而是加分的：**"碎嘴"是老马给自己的贬称**，符合他自嘲的底色；而"每天一句"又天然承诺了更新频率。

**Slogan（简介第一行，不要改）**

> 每天嘀咕一句，说完就走。

## 三、头像

三个尺寸档，源文件由 `avatar.mjs` 生成。

| 文件 | 用途 |
|---|---|
| `avatar_full.svg` | 400px 以上：频道主页、个人页 |
| `avatar_simple.svg` | 96px 左右：评论区、列表 |
| `avatar_mark.svg` | 48px 以下、水印、favicon |

**几条硬要求，改头像时别破坏：**

**留白 1.34 倍头高。** 平台一律圆形裁切，这个留白量保证耳朵尖不会被切。实测头部外接框的四角距中心 234px，内切圆半径 249px，安全余量 15px。

**必须有底色。** 用纸白 `#F1ECE0`，不要透明。透明头像在深色主题下会糊成一团。

**48px 下要能认出来。** 老马的辨识点是**超大眼白配极小瞳孔**，缩到 48px 这一点仍然成立——这是这个形象能当头像的根本原因。鬃毛的细线会糊，所以有简化版。

**不要在头像里放咖啡杯或身体。** 圆形裁切后只剩一团棕色，认不出是什么。

## 四、频道横幅

- **主页横幅**用「工位」场景，老马站左侧三分，右侧留空放频道名
- 横幅上只放频道名和 Slogan，不放二维码、不放更新时间
- 配色沿用素材包：纸白底 `#F1ECE0`，字用 `#3B322B`
- **不要用黄色爆炸符号做装饰**。那个符号在片子里是落点专用的强调手段，横幅上滥用会稀释它

## 五、固定标签

发布时前四个必带，后面按栏目补：

```
#碎嘴老马  #碎嘴  #老马  #打工人
```

`#碎嘴` 是 2026-08-21 加的：搜「碎嘴」的人比搜全名的多，
而这个词的读法已经在 §一 里拧成了「频率高、密度低」，带上它不会招错人。

| 栏目 | 补充标签 |
|---|---|
| 工位 | #职场 #上班这件事 |
| 出租屋 | #独居 #一个人生活 |
| 人堆里 | #社恐 #成年人的世界 |
| 老家 | #父母 #回家 |

**不要堆二十个标签。** 三到五个，和内容真实相关的。堆标签在几个平台都会降权，而且看着像营销号。

## 五之二、收尾卡：日子牌

每条片子最后定格，字幕打出一张卡：

```
老马的第 1847 天
```

**2026-08-21 改。** 原来这张卡是固定的一句「老马，今天也没辞职。」——
那是**段子的 CTA**，一往不是段子的片子后面贴，就成了「刚才那是个段子」。
换成日子牌之后这个毛病没有了：它不表态、不俏皮，只是一个刻度。

**起点 1847。** 约五年，跟人设的「三十出头、干了几年」对得上。
数字本身就是内容：观众第一次看见 1847 会愣一下，然后自己算出这是多久。

**一稿一天，按稿件顺序 +1** —— **不管那一条出不出收尾卡**。
家庭类的条目不出这张卡（见 horse_standup_plan.md「固定收尾」），但日子照样占一格。
不占的话，中间哪天补了一张，后面全部要平移。

| 片子 | 日子 | 收尾卡 |
|---|---|---|
| 置顶介绍视频 | 第 1846 天 | 出 |
| `laoma-001` 回「收到」，我练了三年 | 第 1847 天 | 出 |
| `laoma-002` 我妈的天气预报 | 第 1848 天 | **不出**（家庭类） |
| `laoma-003` 决定看哪儿 | 第 1849 天 | 出 |
| `laoma-004` 从来不备注 | 第 1850 天 | 出 |
| `laoma-005` 对齐了三次 | 第 1851 天 | 出 |
| `laoma-006` 按时不去 | 第 1852 天 | 出 |
| `laoma-007` 优化以后 | 第 1853 天 | 出 |

**字样**：`老马的第 N 天`，数字前后各一个空格，**结尾不加标点**
（频道的屏幕字规矩：屏上的字尾巴不留标点）。
数字写在稿件的 `hook` 字段里，`npm run laoma:check` 会核格式。

## 六、置顶介绍视频（稿）

25–28 秒。**不要做成"大家好欢迎关注"式的自我介绍**——那是营销号的做法，和人设冲突。让老马用他自己的方式介绍自己。

「老马」这个名字的解释就在题材里：**牛马**。这一条必须还清，不能开了悬念不填。

> **钩子**（hook，近景半身）
> 我叫老马。不是姓马。
>
> **铺垫**（setup，全身）
> 是牛马的马。
> 牛马两个字，牛那半边我早就干不动了。
> 剩下半边，将就用着。
>
> **铺垫**（setup，全身）
> 至于这个"老"，是我自己加的。
>
> **转折**（turn，扭头）
> 公司里没人叫我老马。
>
> **落点**（punch，正视镜头，定格）
> 他们叫我"老师"。

落点的最后一个词是"老师"——中国公司里最客气也最疏远的那个称呼。
观众自己会想明白：连个外号都没有的人，只能自己给自己起一个。

**功能性交代另起一段**，不要塞进落点：

> 这个号没什么别的，就是每天嘀咕一句。
> 你要是也嘀咕过同一句，那咱俩就算认识了。

**收尾卡**：老马的第 1846 天

置顶片是唯一允许出现两段落点的场合——它要同时承担"讲个笑话"和"说明这是什么号"。
做法是：让笑话先落地、静半拍，再用平稳的语气交代功能。硬塞进一个落点会两头不讨好。

## 七、一致性清单

开号前对一遍，这几处不一致最容易让人觉得"这号不专业"：

1. 头像、横幅、片子里的老马，是**同一个配色**吗？（棕 `#C2793C` / 纸白 `#F1ECE0` / 墨 `#3B322B`）
2. 各平台的简介第一行都是那句 Slogan 吗？
3. 收尾卡的字样统一吗？（`老马的第 1847 天`：数字前后各一个空格、**结尾不加标点**、数字照 §五之二 的分配表，不手写）
4. 栏目名在简介、标签、视频标题里用的是同一套词吗？
5. 用户名各平台一致吗？拿不到「碎嘴老马」就统一退到同一个备选，不要各平台各叫各的

## 八、两个提醒

**名字可能被占用。** 开号前先把几个平台的用户名都查一遍，能一次全占下最好。占不下就现在换，别等发了三十条再换名。

**「碎嘴」在部分平台的审核里偏口语化，一般没问题，但如果遇到昵称审核不过，备选按这个顺序退**：碎嘴老马 → 老马嘀咕 → 老马今天也没辞职。第三个最长但辨识度最高。（它原来跟收尾卡是同一句话，2026-08-21 收尾卡换成日子牌之后不再呼应，但作为备选名仍旧成立。）
